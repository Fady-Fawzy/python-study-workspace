# 043 — Ternary Conditional Operator

A ternary expression shortens a simple choice between two values into one line. It is an **expression that produces a value**, not a replacement for every long `if` structure.

## The regular form

```python
age = 20

if age >= 18:
    print("Allowed")
else:
    print("Not Allowed")
```

```output
Allowed
```

Age 20 satisfies the condition of 18 or more, so the `if` branch runs.

## The same choice as a ternary

```python
age = 20

print("Allowed" if age >= 18 else "Not Allowed")
```

```output
Allowed
```

Read it as: use `"Allowed"` **if** the condition is true; **otherwise**, use `"Not Allowed"`.

The general form is:

```python
value_if_true if condition else value_if_false
```

## Store the result in a variable

```python
age = 17

message = "Adult" if age >= 18 else "Not Adult"

print(message)
```

```output
Not Adult
```

The condition is False because 17 is less than 18, so the expression returns the value after `else` and stores it in `message`.

> [!COMPARISON]
> Use a ternary to choose a **simple value** between two possibilities.
> Use regular `if/elif/else` when there are several steps or branches; clarity matters more than fewer lines.

> [!WARNING]
> Python's ternary order starts with the true value, then the condition, then `else` and the other value. Do not import the order from another language.

## Quick mental model

`A if condition else B` = if the condition is True, take A; otherwise, take B.
