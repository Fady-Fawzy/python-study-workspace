# 043 — Ternary Conditional Operator

الـ Ternary Expression تختصر اختيارًا بسيطًا بين قيمتين في سطر واحد. هي **Expression تُنتج قيمة**، مش بديلًا لكل أشكال `if` الطويلة.

## الشكل العادي

```python
age = 20

if age >= 18:
    print("Allowed")
else:
    print("Not Allowed")
```

```output
Allowed
```

العمر 20 يحقق شرط 18 أو أكثر، لذلك نُفذ فرع `if`.

## نفس الاختيار بصيغة Ternary

```python
age = 20

print("Allowed" if age >= 18 else "Not Allowed")
```

```output
Allowed
```

اقرأها: استخدم `"Allowed"` **إذا** كان الشرط صحيحًا، **وإلا** استخدم `"Not Allowed"`.

الصيغة العامة:

```python
value_if_true if condition else value_if_false
```

## تخزين النتيجة في متغير

```python
age = 17

message = "Adult" if age >= 18 else "Not Adult"

print(message)
```

```output
Not Adult
```

الشرط False لأن 17 أقل من 18، لذلك الـ Expression أعادت القيمة بعد `else` وخُزنت في `message`.

> [!COMPARISON]
> استخدم Ternary لاختيار **قيمة بسيطة** بين احتمالين.
> استخدم `if/elif/else` العادية عندما عندك عدة خطوات أو فروع كثيرة؛ الوضوح أهم من تقليل عدد السطور.

> [!WARNING]
> ترتيب Ternary في Python يبدأ بالقيمة الصحيحة، ثم الشرط، ثم `else` والقيمة الأخرى. لا تنقل ترتيب لغات أخرى ذهنيًا.

## الصورة الذهنية السريعة

`A if condition else B` = لو الشرط True خذ A، وإلا خذ B.
