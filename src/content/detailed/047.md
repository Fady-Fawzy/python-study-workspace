# 047 — While Loop And Else

`while` repeats a block while a condition is True. It is useful when the number of repetitions depends on a condition that changes during execution.

## Parts of a while loop

```python
a = 0

while a < 5:
    print(a)
    a += 1
```

```output
0
1
2
3
4
```

On each cycle, Python checks `a < 5`, prints the value, and increases it by one. After printing 4, `a = 5`, so the condition is False and the loop stops. 5 is not printed because the check happens before entering the cycle.

## `while` with `else`

```python
a = 0

while a < 5:
    print(a)
    a += 1

else:
    print("Loop Is Done")
```

```output
0
1
2
3
4
Loop Is Done
```

`else` runs when the loop finishes normally because the condition becomes False. Later, `break` can end a loop early and prevent its associated `else` from running.

## The danger of an infinite loop

If you forget `a += 1`, `a` stays zero and `a < 5` stays True, so the loop continues forever.

> [!WARNING]
> Before writing `while`, ask: what value will make the condition False, and where is it updated? Without a clear answer, you probably have an infinite loop.

## Quick mental model

`while condition` = check, run, update the state, and check again. `else` = the loop reached its natural end.
