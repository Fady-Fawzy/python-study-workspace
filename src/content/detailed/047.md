# 047 — While Loop And Else

`while` تكرر Block طالما Condition تساوي True. هي مناسبة لما عدد التكرارات مرتبط بشرط يتغير أثناء التنفيذ.

## أجزاء الـ While Loop

```python
a = 0

while a < 5:
    print(a)
    a += 1
```

```output
0
1
2
3
4
```

في كل دورة: Python تفحص `a < 5`، تطبع القيمة، ثم تزيدها واحدًا. بعد طباعة 4 تصبح `a = 5`، فيكون الشرط False وتتوقف الـ Loop. الرقم 5 لا يُطبع لأن الفحص يحدث قبل دخول الدورة.

## `while` مع `else`

```python
a = 0

while a < 5:
    print(a)
    a += 1

else:
    print("Loop Is Done")
```

```output
0
1
2
3
4
Loop Is Done
```

`else` تنفذ عندما تنتهي الـ Loop طبيعيًا لأن الشرط أصبح False. لاحقًا، `break` يمكن أن ينهي Loop مبكرًا ويمنع `else` المرتبطة بها.

## خطر الـ Infinite Loop

لو نسيت `a += 1`، ستظل `a` صفرًا والشرط `a < 5` يظل True، فتستمر الـ Loop بلا نهاية.

> [!WARNING]
> قبل كتابة `while` اسأل: ما القيمة التي تجعل الشرط يصبح False؟ وأين يتم تحديثها؟ لو مفيش إجابة واضحة، غالبًا عندك Infinite Loop.

## الصورة الذهنية السريعة

`while condition` = افحص، نفّذ، حدّث الحالة، وارجع افحص من جديد. `else` = وصلنا للنهاية الطبيعية.
