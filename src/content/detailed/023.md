# 023 — Lists Methods Part 2

Part two of List Methods focuses on clearing a List, copying it, counting and locating values, inserting at a specific position, and deleting an item while keeping the deleted value. Always notice whether a method changes the List and whether it returns a useful value.

## `clear()` — empty the same List

`clear()` deletes every item from the current List. The List still exists, but its length becomes zero.

```python
numbers = [1, 2, 3, 4]

numbers.clear()

print(numbers)
```

```output
[]
```

The empty brackets `[]` mean that `numbers` is still a List, but it has no items. The operation happened **in place** on that same List.

> [!MENTAL-MODEL]
> `clear()` does not say “forget the variable”; it says “empty the same box of all its contents.”

## `copy()` — an independent shallow copy

`copy()` creates a new **shallow copy** of the List. At the outer level, there are two separate objects, so adding an item to the original does not add it to the copy.

```python
original = [1, 2, 3, 4]

copied = original.copy()

original.append(5)

print(original)
print(copied)
```

```output
[1, 2, 3, 4, 5]
[1, 2, 3, 4]
```

`copied` received the items that existed at copy time. Then `original.append(5)` changed only the original List, so the copy remains `[1, 2, 3, 4]`.

> [!IMPORTANT]
> The name **shallow copy** matters: the outer Lists are separate, but mutable objects inside them, such as nested Lists, may still be shared. Deeper shallow-versus-deep-copy details can come later; for now, focus on outer-level independence.

## `count()` — count matching values

`count(value)` returns how many times a value equal to the requested value appears, without changing the List.

```python
numbers = [1, 2, 1, 3, 1, 5]

print(numbers.count(1))
```

```output
3
```

Python checks the items and finds the number `1` in three positions, so the returned integer is `3`.

## `index()` — position of the first match

`index(value)` searches for a value and returns the index of its first occurrence.

```python
names = ["Ahmed", "Ali", "Omar", "Khaled"]

print(names.index("Omar"))
```

```output
2
```

`"Omar"` is the third item when read normally, but indexes start at zero: `"Ahmed"` is at `0`, `"Ali"` at `1`, and `"Omar"` at `2`.

If the value is missing, Python raises an error instead of returning a made-up index:

```python
names.index("Sara")
```

```error
ValueError: 'Sara' is not in list
```

> [!WARNING]
> Before using `index()` with a value that may be absent, remember that it raises `ValueError`. Do not expect it to return `-1` automatically.

## `insert()` — insert before a specific index

The syntax is `list.insert(index, value)`. The new value is inserted **before** the item currently at that index.

```python
items = [1, 2, 3, 4]

items.insert(0, "Start")
items.insert(-1, "Test")

print(items)
```

```output
['Start', 1, 2, 3, 'Test', 4]
```

`insert(0, "Start")` places `"Start"` before the item that was at index `0`. After that step, `4` is still the last item. Then `insert(-1, "Test")` interprets `-1` as the position of the last item and inserts `"Test"` **before it**, so `4` remains at the end.

> [!IMPORTANT]
> `insert()` does not replace the existing item. It opens a new position before it and shifts the following items one step.

## `pop()` — remove and return an item

`pop(index)` removes the item at a position **and returns its value**, so we can store the deleted item in a variable.

```python
items = ["A", "B", "C", "D"]

deleted_item = items.pop(2)

print(deleted_item)
print(items)
```

```output
C
['A', 'B', 'D']
```

Index `2` pointed to `"C"`. Python removed it from `items` and returned it to `deleted_item` at the same time, leaving `"A"`, `"B"`, and `"D"`.

If you call `pop()` without an argument, it uses the last item automatically:

```python
letters = ["A", "B"]
last_item = letters.pop()

print(last_item)
print(letters)
```

```output
B
['A']
```

> [!COMPARISON]
> `remove(value)` means: “I know the **value** I want to delete,” and it removes the first match. `pop(index)` means: “I know the **position**, and I may need the deleted value afterward.”

## Quick selection map

| Method | The question it answers |
| --- | --- |
| `clear()` | How do I empty the same List? |
| `copy()` | How do I make an independent outer copy? |
| `count(value)` | How many times did the value appear? |
| `index(value)` | Where did the first match appear? |
| `insert(index, value)` | How do I add before a position? |
| `pop(index)` | How do I delete by position and receive the value? |

> [!MENTAL-MODEL]
> `count()` counts, `index()` locates, `insert()` adds before a position, and `pop()` deletes from a position and returns the value. `clear()` and `copy()` work with the List as a whole.
