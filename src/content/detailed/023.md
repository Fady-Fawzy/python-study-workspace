# 023 — Lists Methods Part 2

الجزء الثاني من List Methods يركز على تفريغ الـ List، نسخها، البحث والعد، الإدخال في مكان محدد، وحذف عنصر مع الاحتفاظ بالقيمة المحذوفة. راقب دائمًا هل الـ Method تعدّل الـ List، وهل ترجع قيمة مفيدة.

## `clear()` — تفريغ نفس الـ List

الـ `clear()` تحذف كل العناصر من الـ List الحالية، فتظل الـ List موجودة لكن طولها يصبح صفرًا.

```python
numbers = [1, 2, 3, 4]

numbers.clear()

print(numbers)
```

```output
[]
```

الأقواس الفارغة `[]` تعني أن `numbers` ما زالت List، لكنها لا تحتوي أي عنصر. العملية تمت **in place** على نفس الـ List.

> [!MENTAL-MODEL]
> `clear()` لا تقول «انسَ المتغير»، بل تقول «أفرغ الصندوق نفسه من كل محتوياته».

## `copy()` — نسخة سطحية مستقلة

الـ `copy()` تنشئ **shallow copy** جديدة من الـ List. على المستوى الخارجي يصبح عندنا كائنان منفصلان، لذلك إضافة عنصر إلى الأصل لا تضيف العنصر إلى النسخة.

```python
original = [1, 2, 3, 4]

copied = original.copy()

original.append(5)

print(original)
print(copied)
```

```output
[1, 2, 3, 4, 5]
[1, 2, 3, 4]
```

`copied` أخذت العناصر الموجودة وقت النسخ. بعد ذلك `original.append(5)` عدّلت الـ List الأصلية فقط، فبقيت النسخة `[1, 2, 3, 4]`.

> [!IMPORTANT]
> اسم **shallow copy** مهم: الـ List الخارجية منفصلة، لكن لو كانت بداخلها Objects قابلة للتعديل مثل Lists متداخلة، فقد تظل هذه العناصر الداخلية مشتركة. التفاصيل الأعمق تخص موضوع النسخ السطحي والعميق لاحقًا؛ حاليًا ركّز على استقلال المستوى الخارجي.

## `count()` — عدّ القيم المطابقة

الـ `count(value)` ترجع عدد مرات ظهور قيمة مساوية للقيمة المطلوبة، من غير ما تعدّل الـ List.

```python
numbers = [1, 2, 1, 3, 1, 5]

print(numbers.count(1))
```

```output
3
```

Python مرّت على العناصر ووجدت الرقم `1` عند ثلاثة مواقع، لذلك القيمة المرجعة هي العدد الصحيح `3`.

## `index()` — موقع أول قيمة مطابقة

الـ `index(value)` تبحث عن القيمة وترجع Index أول ظهور لها.

```python
names = ["Ahmed", "Ali", "Omar", "Khaled"]

print(names.index("Omar"))
```

```output
2
```

`"Omar"` هو العنصر الثالث في ترتيب القراءة، لكن الـ Index يبدأ من الصفر: `"Ahmed"` عند `0`، و`"Ali"` عند `1`، و`"Omar"` عند `2`.

لو القيمة غير موجودة، سترفع Python خطأ بدل إرجاع Index وهمي:

```python
names.index("Sara")
```

```error
ValueError: 'Sara' is not in list
```

> [!WARNING]
> قبل الاعتماد على `index()` مع قيمة قد تكون غائبة، تذكّر أنها ترفع `ValueError`. لا تتوقع أن ترجع `-1` تلقائيًا.

## `insert()` — إدخال قبل Index محدد

الصيغة هي `list.insert(index, value)`. القيمة الجديدة تدخل **قبل** العنصر الموجود حاليًا عند الـ Index المحدد.

```python
items = [1, 2, 3, 4]

items.insert(0, "Start")
items.insert(-1, "Test")

print(items)
```

```output
['Start', 1, 2, 3, 'Test', 4]
```

`insert(0, "Start")` وضعت `"Start"` قبل العنصر الذي كان عند Index `0`. بعد هذه الخطوة أصبح `4` هو آخر عنصر. ثم `insert(-1, "Test")` فسّرت `-1` كموقع آخر عنصر وأدخلت `"Test"` **قبله**، لذلك ظل `4` في النهاية.

> [!IMPORTANT]
> الـ `insert()` لا تستبدل العنصر الموجود؛ هي تفتح مكانًا جديدًا قبله وتحرك العناصر التالية خطوة.

## `pop()` — حذف وإرجاع عنصر

الـ `pop(index)` تحذف العنصر عند موقع محدد **وترجع قيمته**، ولذلك نقدر نخزن العنصر المحذوف في متغير.

```python
items = ["A", "B", "C", "D"]

deleted_item = items.pop(2)

print(deleted_item)
print(items)
```

```output
C
['A', 'B', 'D']
```

Index `2` كان يشير إلى `"C"`. حذفتها Python من `items`، وفي الوقت نفسه رجعتها إلى `deleted_item`، فبقيت العناصر `"A"` و`"B"` و`"D"`.

لو استدعيت `pop()` من غير Argument، فهي تستخدم آخر عنصر تلقائيًا:

```python
letters = ["A", "B"]
last_item = letters.pop()

print(last_item)
print(letters)
```

```output
B
['A']
```

> [!COMPARISON]
> `remove(value)` معناها: «أنا أعرف **القيمة** التي أريد حذفها»، وتحذف أول تطابق. `pop(index)` معناها: «أنا أعرف **الموقع**، وقد أحتاج القيمة المحذوفة بعد الحذف».

## خريطة الاختيار السريعة

| Method | السؤال الذي تجيب عنه |
| --- | --- |
| `clear()` | كيف أفرغ نفس الـ List؟ |
| `copy()` | كيف أصنع نسخة خارجية مستقلة؟ |
| `count(value)` | كم مرة ظهرت القيمة؟ |
| `index(value)` | أين ظهر أول تطابق؟ |
| `insert(index, value)` | كيف أضيف قبل موقع معين؟ |
| `pop(index)` | كيف أحذف بالموقع وأستلم القيمة؟ |

> [!MENTAL-MODEL]
> `count()` تعدّ، و`index()` تحدد الموقع، و`insert()` تضيف قبل الموقع، و`pop()` تحذف من الموقع وتعيد القيمة. أما `clear()` و`copy()` فتتعاملان مع الـ List ككل.
