# 034 — Boolean Operators

لما عندك أكثر من شرط، Operators مثل `and` و`or` و`not` تسمح بتركيبهم في نتيجة منطقية واحدة.

```python
age = 25
country = "Egypt"
level = 8
```

المتغير `level` جزء من بيانات المثال، لكن العمليات التالية تعتمد على `age` و`country`.

## `and` — كل الشروط لازم تكون صحيحة

```python
print(age >= 18 and country == "Egypt")
print(age >= 18 and country == "USA")
```

```output
True
False
```

في السطر الأول: العمر 25 فعلًا أكبر من أو يساوي 18، والبلد Egypt، فالشرطان True. في الثاني شرط العمر True لكن البلد ليست USA، و`and` تحتاج الاثنين، فالنتيجة False.

## `or` — يكفي شرط واحد صحيح

```python
print(age > 30 or country == "Egypt")
print(age > 30 or country == "USA")
```

```output
True
False
```

العمر ليس أكبر من 30، لكن شرط Egypt صحيح في السطر الأول، وده يكفي مع `or`. في السطر الثاني الشرطان خطأ، لذلك النتيجة False.

## `not` — عكس النتيجة المنطقية

```python
print(age > 18)

print(not age > 18)
```

```output
True
False
```

`age > 18` نتيجتها True. `not` قلبتها إلى False. لزيادة الوضوح يمكن قراءتها `not (age > 18)`.

## مقارنة سريعة

| Operator | السؤال | متى تكون النتيجة True؟ |
|---|---|---|
| `and` | هل كل الشروط صحيحة؟ | عندما تكون كلها True |
| `or` | هل يوجد شرط صحيح؟ | عندما يكون واحد على الأقل True |
| `not` | ما عكس النتيجة؟ | عندما تكون القيمة الأصلية Falsy |

> [!IMPORTANT]
> Python تستخدم Short-circuit evaluation: مع `and` قد تتوقف عند أول قيمة Falsy، ومع `or` عند أول قيمة Truthy. الصورة الذهنية الأساسية: البرنامج لا يقيّم ما لا يحتاجه للوصول للنتيجة.

## الصورة الذهنية السريعة

- `and` = بوابتان لازم يفتحوا.
- `or` = باب واحد مفتوح يكفي.
- `not` = اقلب نعم إلى لا والعكس.
