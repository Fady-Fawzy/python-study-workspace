# 034 — Boolean Operators

When you have more than one condition, operators such as `and`, `or`, and `not` combine them into one logical result.

```python
age = 25
country = "Egypt"
level = 8
```

The variable `level` is part of the sample data, but the following operations use `age` and `country`.

## `and` — every condition must be true

```python
print(age >= 18 and country == "Egypt")
print(age >= 18 and country == "USA")
```

```output
True
False
```

In the first line, age 25 is at least 18 and the country is Egypt, so both conditions are True. In the second, the age condition is True but the country is not USA; `and` needs both, so the result is False.

## `or` — one true condition is enough

```python
print(age > 30 or country == "Egypt")
print(age > 30 or country == "USA")
```

```output
True
False
```

The age is not greater than 30, but the Egypt condition is true in the first line, which is enough for `or`. In the second line both conditions are false, so the result is False.

## `not` — reverse the logical result

```python
print(age > 18)

print(not age > 18)
```

```output
True
False
```

`age > 18` produces True. `not` flips it to False. For clarity, read it as `not (age > 18)`.

## Quick comparison

| Operator | Question | When is the result True? |
|---|---|---|
| `and` | Are all conditions true? | When all are True |
| `or` | Is any condition true? | When at least one is True |
| `not` | What is the opposite result? | When the original value is Falsy |

> [!IMPORTANT]
> Python uses short-circuit evaluation: `and` may stop at the first Falsy value, and `or` at the first Truthy value. The core idea is that the program does not evaluate what it does not need to reach the result.

## Quick mental model

- `and` = two gates must open.
- `or` = one open door is enough.
- `not` = flip yes to no and vice versa.
