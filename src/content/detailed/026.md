# 026 — Set

الـ **Set** نوع بيانات بيجمع عناصر **unique**: لو القيمة اتكررت أكتر من مرة، الـ Set بتحتفظ بنسخة واحدة منها. فكّر فيها كـ "مجموعة عناصر" مش كصف عناصر له ترتيب ثابت.

> [!MENTAL-MODEL]
> **Set = مجموعة قيم فريدة، غير مرتبة، ولا تعتمد على Index.** استخدمها لما يهمك وجود القيمة ومنع التكرار، مش مكانها.

## إنشاء Set

بننشئ Set باستخدام الأقواس `{}` ونفصل العناصر بفواصل:

```python
my_set = {"Ahmed", "Mohamed", "Ali"}

print(my_set)
```

```example-output
{'Mohamed', 'Ali', 'Ahmed'}
```

ده **Example Output** لأن Python لا تضمن ترتيب عرض عناصر الـ Set. ممكن تشوف نفس الأسماء بترتيب مختلف، لكن المحتوى نفسه يفضل: `Ahmed` و`Mohamed` و`Ali`.

> [!IMPORTANT]
> `{}` لوحدها بتعمل Dictionary فاضية، مش Set فاضية. لإنشاء Set فاضية استخدم `set()`.

## الـ Set غير مرتبة ولا تدعم Indexing

الـ List والـ Tuple ليهم Index لأن العناصر محفوظة في ترتيب sequence. الـ Set مختلفة؛ مفيش عنصر نقدر نقول عليه دائمًا "العنصر رقم صفر".

```python
my_set = {"Ahmed", "Mohamed", "Ali"}

print(my_set[0])
```

```error
TypeError: 'set' object is not subscriptable
```

الخطأ حصل لأن `my_set[0]` بيحاول يعمل Indexing لنوع لا يدعم العملية دي. لنفس السبب، Slicing زي `my_set[1:3]` غير متاح.

## العناصر Unique والتكرار يختفي

```python
numbers = {1, 2, 3, 1, 2, 3}

print(numbers)
```

```example-output
{1, 2, 3}
```

كل من `1` و`2` و`3` اتكتب مرتين، لكن الـ Set خزّنت كل قيمة مرة واحدة. ترتيب العرض قد يختلف، إنما عدد القيم الفريدة هنا ثابت ويساوي `3`.

دي خاصية مفيدة مثلًا لو عندك أسماء أو IDs مكررة وعايز تعرف القيم المختلفة فقط.

## العناصر لازم تكون Immutable

العنصر الموجود داخل Set لازم يكون **hashable**، وبصورة تمهيدية ده معناه إن قيمته لا تتغير وهو مستخدم كعنصر فيها. لذلك الأرقام والـ String والـ Tuple التي تحتوي قيمًا ثابتة مناسبة:

```python
data = {
    10,
    "Python",
    (1, 2, 3)
}

print(data)
```

```example-output
{10, 'Python', (1, 2, 3)}
```

الـ Tuple مقبولة لأنها Immutable. أما List مثل `[1, 2, 3]` فلا تصلح كعنصر داخل Set لأنها Mutable.

```python
data = {10, [1, 2, 3]}
```

```error
TypeError: unhashable type: 'list'
```

> [!COMPARISON]
> **List:** مرتبة، تدعم Index وSlice، تسمح بالتكرار، وMutable.
> **Tuple:** مرتبة، تدعم Index وSlice، تسمح بالتكرار، وImmutable.
> **Set:** غير مرتبة، لا تدعم Index أو Slice، وتزيل التكرار.

## الصورة الذهنية السريعة

- محتاج ترتيب ومواقع عناصر؟ استخدم sequence مثل List أو Tuple.
- محتاج قيمًا فريدة واختبار وجودها؟ الـ Set اختيار طبيعي.
- لا تعتمد على ترتيب طباعة الـ Set.
- لا تضع List أو Dictionary كعنصر مباشر داخل Set.
