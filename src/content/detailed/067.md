# 067 — Files Handling Part 3 — Write And Append

الكتابة تغيّر محتوى الملفات. الفرق الأساسي: `w` تبدأ محتوى جديدًا، بينما `a` تضيف بعد الموجود.

## `write()` في Mode `w`

```python
file = open("data.txt", "w")

file.write("Hello Python")

file.close()
```

```example-output
Contents of data.txt:
Hello Python
```

ده أثر على الملف، مش Console output. `w` فرّغت المحتوى السابق ثم `write()` كتبت الـ String كما هي.

## كتابة عدة سطور

```python
file = open("names.txt", "w")

file.write("Ahmed\n")
file.write("Ali\n")
file.write("Omar\n")

file.close()
```

```example-output
Contents of names.txt:
Ahmed
Ali
Omar
```

`write()` لا تضيف newline تلقائيًا؛ `\n` هي التي فصلت الأسماء إلى سطور.

## `writelines()` — كتابة Iterable من Strings

```python
names = [
    "Ahmed\n",
    "Ali\n",
    "Omar\n"
]

file = open("names.txt", "w")

file.writelines(names)

file.close()
```

```example-output
Contents of names.txt:
Ahmed
Ali
Omar
```

`writelines()` كتبت العناصر بالترتيب، لكنها أيضًا لا تخترع فواصل؛ الـ `\n` موجودة داخل كل عنصر.

## Append باستخدام `a`

```python
file = open("names.txt", "a")

file.write("Mohamed\n")

file.close()
```

```example-output
Contents of names.txt after append:
Ahmed
Ali
Omar
Mohamed
```

Mode `a` حافظت على الأسماء القديمة وكتبت `Mohamed` في النهاية.

> [!COMPARISON]
> `w` → يمسح القديم ويكتب من البداية.
> `a` → يحافظ على القديم ويضيف في النهاية.

> [!WARNING]
> راجع الـ Path والـ Mode قبل التشغيل؛ خطأ بسيط مع `w` قد يستبدل ملفًا مهمًا.

## الصورة الذهنية السريعة

Mode تحدد مصير القديم، و`write`/`writelines` تحددان البيانات الجديدة. newline مسؤوليتك داخل النص.
