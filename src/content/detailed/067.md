# 067 — Files Handling Part 3 — Write And Append

Writing changes file contents. The key difference is that `w` starts fresh content, while `a` adds after what already exists.

## `write()` in mode `w`

```python
file = open("data.txt", "w")

file.write("Hello Python")

file.close()
```

```example-output
Contents of data.txt:
Hello Python
```

This affects the file, not console output. `w` clears the previous content, then `write()` writes the String exactly as provided.

## Write several lines

```python
file = open("names.txt", "w")

file.write("Ahmed\n")
file.write("Ali\n")
file.write("Omar\n")

file.close()
```

```example-output
Contents of names.txt:
Ahmed
Ali
Omar
```

`write()` does not add a newline automatically; `\n` is what separates the names into lines.

## `writelines()` — write an iterable of Strings

```python
names = [
    "Ahmed\n",
    "Ali\n",
    "Omar\n"
]

file = open("names.txt", "w")

file.writelines(names)

file.close()
```

```example-output
Contents of names.txt:
Ahmed
Ali
Omar
```

`writelines()` writes the items in order, but it does not invent separators; each `\n` is already inside an item.

## Append with `a`

```python
file = open("names.txt", "a")

file.write("Mohamed\n")

file.close()
```

```example-output
Contents of names.txt after append:
Ahmed
Ali
Omar
Mohamed
```

Mode `a` keeps the old names and writes `Mohamed` at the end.

> [!COMPARISON]
> `w` → erase the old content and write from the beginning.
> `a` → keep the old content and add at the end.

> [!WARNING]
> Check the path and mode before running; a small mistake with `w` can replace an important file.

## Quick mental model

The mode determines the fate of old content, while `write`/`writelines` determine the new data. Newlines are your responsibility inside the text.
