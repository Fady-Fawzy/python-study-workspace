# 065 — Files Handling Part 1 — Intro

File handling connects a Python program to a file on storage. `open()` returns a file object that we read or write through, depending on the mode.

## Open a file for reading

```python
my_file = open("data.txt")
```

Omitting the mode means `"r"` by default, so the line is equivalent to:

```python
my_file = open("data.txt", "r")
```

The relative path `data.txt` is resolved against the current working directory from which the program was run. If the file is missing in read mode, `FileNotFoundError` occurs.

## Common file modes

| Mode | Name | Main meaning |
|---|---|---|
| `r` | Read | Read an existing file |
| `w` | Write | Write from the beginning; create if missing |
| `a` | Append | Add at the end; create if missing |
| `x` | Create | Create a new file only; fail if it exists |

## Open a file for writing

```python
file = open("test.txt", "w")
```

If `test.txt` is missing, an empty file is created. If it exists, mode `w` clears its content when opened, before writing.

> [!WARNING]
> `w` is destructive and may erase existing content. Choose the mode before opening the file, not after.

## Close the resource

After finishing, use `file.close()` to release system resources and ensure written data is flushed. The common Python pattern later is `with open(...) as file:` because it closes automatically, but these lesson examples use explicit open and close calls.

## Quick mental model

`open(path, mode)` = choose a file and set its permission/behavior. The path answers “where”; the mode answers “what will you do?”
