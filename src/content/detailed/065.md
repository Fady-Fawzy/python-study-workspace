# 065 — Files Handling Part 1 — Intro

File Handling يربط برنامج Python بملف موجود على التخزين. `open()` تُرجع File object نقرأ أو نكتب من خلالها حسب الـ Mode.

## فتح ملف للقراءة

```python
my_file = open("data.txt")
```

عدم كتابة Mode يعني `"r"` افتراضيًا، لذلك السطر مكافئ لـ:

```python
my_file = open("data.txt", "r")
```

المسار النسبي `data.txt` يُبحث عنه بالنسبة إلى Current Working Directory التي شغّلت منها البرنامج. لو الملف غير موجود في Read Mode، يحدث `FileNotFoundError`.

## أشهر File Modes

| Mode | الاسم | المعنى الأساسي |
|---|---|---|
| `r` | Read | اقرأ ملفًا موجودًا |
| `w` | Write | اكتب من البداية، وأنشئ الملف لو غير موجود |
| `a` | Append | أضف في النهاية، وأنشئ الملف لو غير موجود |
| `x` | Create | أنشئ ملفًا جديدًا فقط، واخطئ لو موجود |

## فتح ملف للكتابة

```python
file = open("test.txt", "w")
```

لو `test.txt` غير موجود، ينشأ ملف فارغ. لو موجود، Mode `w` تفرّغ محتواه عند الفتح قبل الكتابة.

> [!WARNING]
> `w` عملية مؤثرة وقد تمسح محتوى موجودًا. اختار Mode قبل فتح الملف، مش بعده.

## إغلاق المورد

بعد الانتهاء استخدم `file.close()` حتى تُحرر موارد النظام وتضمن دفع البيانات المكتوبة. في Python العملية العملية الشائعة لاحقًا هي `with open(...) as file:` لأنها تغلق الملف تلقائيًا، لكن أمثلة الدروس تستخدم الفتح والإغلاق الصريحين.

## الصورة الذهنية السريعة

`open(path, mode)` = اختر ملفًا وحدد نوع الصلاحية/السلوك. الـ Path يحدد "فين" والـ Mode تحدد "هتعمل إيه".
