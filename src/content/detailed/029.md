# 029 — Set Methods Part 3

These methods do not return new Set items; they answer logical questions and return `True` or `False` about the relationship between two Sets.

## `issuperset()` — does the first Set fully contain the second?

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(a.issuperset(b))
print(b.issuperset(a))
```

```output
True
False
```

`a` is a superset of `b` because every item in `b`, `1` and `2`, is also in `a`. The reverse is False because `b` does not contain `3` or `4`.

Read the expression as: **“Does `a` contain everything in `b`?”**

## `issubset()` — is the first Set fully inside the second?

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(b.issubset(a))
print(a.issubset(b))
```

```output
True
False
```

`b` is a subset of `a` because it contains no item outside `a`. `a` is not a subset of `b` because of `3` and `4`.

> [!COMPARISON]
> `a.issuperset(b)` and `b.issubset(a)` look at the same relationship from opposite directions.
> First: is `a` the larger container?
> Second: is `b` fully inside it?

## `isdisjoint()` — are there no shared items?

```python
a = {1, 2, 3}
b = {4, 5, 6}
c = {2, 10, 20}

print(a.isdisjoint(b))
print(a.isdisjoint(c))
```

```output
True
False
```

`a` and `b` are completely separate, with no shared value, so the result is True. `a` and `c` both contain `2`, and one shared item is enough for `isdisjoint()` to return False.

You can imagine the test asking whether `a.intersection(other)` is empty, but `isdisjoint()` is clearer when the required answer is a Boolean.

## Practical relationship examples

- Are all required user permissions present? Use subset logic.
- Does an administrator's permission group contain an employee's permissions? Use superset logic.
- Do two ID groups have no overlap at all? Use `isdisjoint()`.

> [!WARNING]
> Call direction matters for `issubset()` and `issuperset()`. Read the variable before the dot, then ask the full question. `a.issubset(b)` does not mean the same as `b.issubset(a)`.

## Quick mental model

- `issuperset()` = do I fully contain the other Set?
- `issubset()` = am I fully inside the other Set?
- `isdisjoint()` = do we share no items?
- All three return a Boolean and do not change either Set.
