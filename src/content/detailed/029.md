# 029 — Set Methods Part 3

الميثودز هنا لا تُرجع عناصر Set جديدة؛ هي تجاوب بأسئلة منطقية وتُرجع `True` أو `False` عن العلاقة بين مجموعتين.

## `issuperset()` — هل الأولى تحتوي الثانية بالكامل؟

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(a.issuperset(b))
print(b.issuperset(a))
```

```output
True
False
```

`a` Superset من `b` لأن كل عناصر `b`، وهي `1` و`2`، موجودة داخل `a`. العكس False لأن `b` لا تحتوي `3` ولا `4`.

السؤال الذي تقرأ به التعبير هو: **هل `a` تحتوي كل ما في `b`؟**

## `issubset()` — هل الأولى موجودة بالكامل داخل الثانية؟

```python
a = {1, 2, 3, 4}
b = {1, 2}

print(b.issubset(a))
print(a.issubset(b))
```

```output
True
False
```

`b` Subset من `a` لأنها لا تحتوي أي عنصر خارج `a`. لكن `a` ليست Subset من `b` بسبب `3` و`4`.

> [!COMPARISON]
> `a.issuperset(b)` و`b.issubset(a)` ينظران لنفس العلاقة من اتجاهين مختلفين.
> الأولى: هل `a` هي الحاوية الأكبر؟
> الثانية: هل `b` موجودة بالكامل داخلها؟

## `isdisjoint()` — هل لا يوجد أي عنصر مشترك؟

```python
a = {1, 2, 3}
b = {4, 5, 6}
c = {2, 10, 20}

print(a.isdisjoint(b))
print(a.isdisjoint(c))
```

```output
True
False
```

`a` و`b` منفصلتان تمامًا؛ لا توجد قيمة مشتركة، لذلك النتيجة True. أما `a` و`c` ففيهما القيمة `2`، ومجرد عنصر مشترك واحد يجعل `isdisjoint()` ترجع False.

تقدر تتخيل الاختبار كأنه بيسأل هل `a.intersection(other)` فاضية، لكن `isdisjoint()` أوضح لما المطلوب إجابة Boolean مباشرة.

## أمثلة عملية للعلاقات

- صلاحيات المستخدم المطلوبة كلها موجودة؟ استخدم منطق Subset.
- مجموعة صلاحيات المدير تحتوي صلاحيات الموظف؟ منطق Superset.
- مجموعتا IDs لا تتقاطعان إطلاقًا؟ `isdisjoint()`.

> [!WARNING]
> اتجاه الاستدعاء مهم في `issubset()` و`issuperset()`. ابدأ بقراءة اسم المتغير قبل النقطة ثم اسأل السؤال كاملًا. `a.issubset(b)` لا تعني نفس `b.issubset(a)`.

## الصورة الذهنية السريعة

- `issuperset()` = هل أنا أحتوي المجموعة الأخرى بالكامل؟
- `issubset()` = هل أنا موجود بالكامل داخل المجموعة الأخرى؟
- `isdisjoint()` = هل لا نشارك أي عنصر؟
- كلهم يرجعوا Boolean ولا يعدّلوا أي Set.
