# 057 — Function Parameters And Arguments

Parameters make a function flexible: instead of one fixed value, it can receive different data on every call.

## One parameter

```python
def say_hello(name):
    print(f"Hello {name}")


say_hello("Ahmed")
say_hello("Ali")
say_hello("Omar")
```

```output
Hello Ahmed
Hello Ali
Hello Omar
```

`name` is a parameter in the definition. On each call, the supplied argument is temporarily bound to `name`.

## Multiple parameters

```python
def user_info(name, age, country):
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"Country: {country}")


user_info("Ahmed", 25, "Egypt")
```

```output
Name: Ahmed
Age: 25
Country: Egypt
```

With positional arguments, order determines the binding: `Ahmed → name`, `25 → age`, and `Egypt → country`.

## Parameters versus arguments

> [!COMPARISON]
> `num1`, `num2` in the definition = parameters, the named slots that receive data.
> `10`, `20` in the call = arguments, the actual values sent.

## `return` with inputs

```python
def addition(num1, num2):
    return num1 + num2


result = addition(10, 20)

print(result)
```

```output
30
```

The function receives the two numbers, adds the values bound to the parameters, and returns the result.

> [!WARNING]
> If you omit a required argument or send positional arguments in the wrong order, the call does not match the function definition. Python may raise `TypeError`, or the code may receive an unintended meaning.

## Quick mental model

Parameters are slots in a recipe definition, and arguments are the ingredients placed in those slots at runtime.
