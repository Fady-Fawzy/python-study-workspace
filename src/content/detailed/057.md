# 057 — Function Parameters And Arguments

Parameters تجعل Function مرنة: بدل قيمة ثابتة، الدالة تستقبل بيانات مختلفة في كل Call.

## Parameter واحد

```python
def say_hello(name):
    print(f"Hello {name}")


say_hello("Ahmed")
say_hello("Ali")
say_hello("Omar")
```

```output
Hello Ahmed
Hello Ali
Hello Omar
```

`name` Parameter داخل التعريف. في كل Call، الـ Argument المرسلة تُربط بـ `name` مؤقتًا.

## أكثر من Parameter

```python
def user_info(name, age, country):
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"Country: {country}")


user_info("Ahmed", 25, "Egypt")
```

```output
Name: Ahmed
Age: 25
Country: Egypt
```

بالـ Positional Arguments، الترتيب هو الربط: `Ahmed → name`، و`25 → age`، و`Egypt → country`.

## Parameters مقابل Arguments

> [!COMPARISON]
> `num1`, `num2` في التعريف = Parameters، أسماء الأماكن التي تستقبل البيانات.
> `10`, `20` في الاستدعاء = Arguments، القيم الفعلية المرسلة.

## `return` مع المدخلات

```python
def addition(num1, num2):
    return num1 + num2


result = addition(10, 20)

print(result)
```

```output
30
```

الدالة استقبلت الرقمين، جمعت القيم المرتبطة بالـ Parameters، ثم أعادت النتيجة.

> [!WARNING]
> لو نسيت Argument مطلوبة، أو أرسلت Positional Arguments بترتيب خاطئ، الاستدعاء لا يطابق تعريف الدالة. Python قد ترفع `TypeError` أو تحصل على معنى غير مقصود.

## الصورة الذهنية السريعة

Parameters هي فتحات في تعريف الوصفة، وArguments هي المكونات التي تضعها في الفتحات عند التشغيل.
