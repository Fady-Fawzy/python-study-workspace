# 072 — Built In Functions Part 4 — Map

`map()` تطبق Function على **كل عنصر** في Iterable وتنتج قيمًا محوّلة بنفس ترتيب العناصر.

## Function التحويل

```python
numbers = [1, 2, 3, 4]


def double_number(number):
    return number * 2
```

Function تستقبل عنصرًا واحدًا وتعيد ضعفه. `map()` ستستدعيها تلقائيًا لكل رقم.

## `map(function, iterable)`

```python
result = map(double_number, numbers)

print(list(result))
```

```output
[2, 4, 6, 8]
```

التطبيق كان `1→2`, `2→4`, `3→6`, `4→8`. `map()` ترجع Map object كسولة، لذلك حولناها إلى List لرؤية النتائج.

> [!IMPORTANT]
> الـ Map object تُستهلك عند المرور عليها. بعد `list(result)` مرة، محاولة تحويل نفس object مرة ثانية غالبًا تعطي List فارغة لأنها وصلت للنهاية.

## Map مع Lambda

```python
numbers = [1, 2, 3, 4]

result = map(lambda number: number * 2, numbers)

print(list(result))
```

```output
[2, 4, 6, 8]
```

Lambda استبدلت Function المسماة لأن العملية Expression قصيرة. النتيجة نفسها؛ الاختلاف في طريقة كتابة الـ Callable.

## الشكل العام

```python
map(function, iterable)
```

`map` لا تختار عناصر ولا تعدّل List الأصلية؛ هي تنتج قيمة محوّلة لكل عنصر.

## الصورة الذهنية السريعة

Map = خط إنتاج: كل عنصر يدخل نفس Function، ويخرج عنصر مقابل له بعد التحويل.
