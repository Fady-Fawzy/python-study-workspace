# 072 — Built In Functions Part 4 — Map

`map()` applies a function to **every item** in an iterable and produces transformed values in the same order.

## The transformation function

```python
numbers = [1, 2, 3, 4]


def double_number(number):
    return number * 2
```

The function receives one item and returns its double. `map()` calls it automatically for every number.

## `map(function, iterable)`

```python
result = map(double_number, numbers)

print(list(result))
```

```output
[2, 4, 6, 8]
```

The transformations are `1→2`, `2→4`, `3→6`, and `4→8`. `map()` returns a lazy map object, so we convert it to a List to see the results.

> [!IMPORTANT]
> A map object is consumed as you iterate over it. After one `list(result)`, converting the same object again usually gives an empty List because it has reached the end.

## Map with a Lambda

```python
numbers = [1, 2, 3, 4]

result = map(lambda number: number * 2, numbers)

print(list(result))
```

```output
[2, 4, 6, 8]
```

The Lambda replaces the named function because the operation is a short expression. The result is the same; only the callable's syntax differs.

## General form

```python
map(function, iterable)
```

`map` does not choose items or change the original List; it produces one transformed value for each item.

## Quick mental model

Map = a production line: every item enters the same function and one corresponding transformed item comes out.
