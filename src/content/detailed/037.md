# 037 — Type Conversion

Type Conversion يعني تحويل القيمة من نوع لنوع آخر عندما يكون شكل البيانات مناسبًا. التحويل لا يغيّر "الحقيقة" وحده؛ أنت تنشئ قيمة جديدة بالنوع المطلوب ثم تحفظها لو محتاج.

## من Integer إلى String

```python
age = 25

print(type(age))

age = str(age)

print(type(age))
print(age)
```

```output
<class 'int'>
<class 'str'>
25
```

في البداية `age` رقم Integer. `str(age)` أنشأت النص `"25"`، وبعد إسناده للمتغير أصبح نوعه String. `print(age)` تعرض 25 من غير اقتباسات، لكن `type()` تؤكد النوع.

## من String إلى Integer

```python
number = "100"

number = int(number)

print(number)
print(type(number))
```

```output
100
<class 'int'>
```

النص يتكوّن من أرقام صحيحة، لذلك `int()` قدرت تحوله إلى العدد 100 الذي يصلح للحساب.

## من String إلى Float

```python
number = "10.5"

number = float(number)

print(number)
print(type(number))
```

```output
10.5
<class 'float'>
```

وجود العلامة العشرية يناسب `float()`.

> [!WARNING]
> التحويل لازم يكون منطقيًا. `int("Python")` يرفع `ValueError`، وكذلك `int("10.5")` لأن النص ليس تمثيلًا مباشرًا لـ Integer. استخدم `float("10.5")` للعدد العشري.

## من String إلى List

```python
name = "Python"

print(list(name))
```

```output
['P', 'y', 't', 'h', 'o', 'n']
```

الـ String iterable؛ `list()` أخذت كل Character كعنصر مستقل وبنفس الترتيب.

## من List إلى Tuple

```python
numbers = [1, 2, 3]

print(tuple(numbers))
```

```output
(1, 2, 3)
```

العناصر والترتيب ظلوا كما هم، لكن الـ container الجديدة Tuple Immutable.

## من List إلى Set

```python
numbers = [1, 1, 2, 2, 3]

print(set(numbers))
```

```example-output
{1, 2, 3}
```

`set()` أزالت التكرار لأن الـ Set تحتفظ بالقيم الفريدة. ترتيب عرض عناصرها غير مضمون، لذلك ده Example Output.

## الصورة الذهنية السريعة

- `str()` → تمثيل نصي.
- `int()` → عدد صحيح صالح.
- `float()` → عدد عشري صالح.
- `list()` و`tuple()` و`set()` → container جديدة من عناصر iterable.
- نجاح التحويل يعتمد على شكل القيمة، مش مجرد طلبك للنوع.
