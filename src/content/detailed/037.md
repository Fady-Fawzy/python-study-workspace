# 037 — Type Conversion

Type conversion means changing a value from one type to another when its representation is suitable. Conversion does not change the “truth” by itself; it creates a value in the requested type, which you can store if needed.

## From Integer to String

```python
age = 25

print(type(age))

age = str(age)

print(type(age))
print(age)
```

```output
<class 'int'>
<class 'str'>
25
```

At first, `age` is an Integer. `str(age)` creates the String `"25"`; after assigning it back, the variable's type is String. `print(age)` displays 25 without quotes, but `type()` confirms the type.

## From String to Integer

```python
number = "100"

number = int(number)

print(number)
print(type(number))
```

```output
100
<class 'int'>
```

The String contains a whole-number representation, so `int()` can convert it to the number 100, which is ready for arithmetic.

## From String to Float

```python
number = "10.5"

number = float(number)

print(number)
print(type(number))
```

```output
10.5
<class 'float'>
```

The decimal point makes the value suitable for `float()`.

> [!WARNING]
> The conversion must make sense. `int("Python")` raises `ValueError`, as does `int("10.5")` because the String is not a direct Integer representation. Use `float("10.5")` for the decimal value.

## From String to List

```python
name = "Python"

print(list(name))
```

```output
['P', 'y', 't', 'h', 'o', 'n']
```

The String is iterable; `list()` takes each Character as a separate item in the same order.

## From List to Tuple

```python
numbers = [1, 2, 3]

print(tuple(numbers))
```

```output
(1, 2, 3)
```

The items and order stay the same, but the new container is an immutable Tuple.

## From List to Set

```python
numbers = [1, 1, 2, 2, 3]

print(set(numbers))
```

```example-output
{1, 2, 3}
```

`set()` removes duplicates because Sets keep unique values. Display order is not guaranteed, so this is example output.

## Quick mental model

- `str()` → a text representation.
- `int()` → a valid integer.
- `float()` → a valid decimal number.
- `list()`, `tuple()`, and `set()` → a new container from iterable items.
- Conversion succeeds based on the value's shape, not simply because you requested a type.
