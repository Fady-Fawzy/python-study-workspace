# 041 — Control Flow: If, Elif, Else

Control flow lets a program choose a different path based on a condition. Python checks branches from top to bottom and runs **only the first branch whose condition is True**.

## `if` — the first question

```python
name = "Ahmed"
country = "Egypt"
price = 100

if country == "Egypt":
    print(f"Hello {name}")
    print(f"The Price Is {price - 20}")
```

The condition `country == "Egypt"` is True, so the two indented lines run, and the 20-unit discount makes the price 80.

## `elif` — an additional possibility

```python
elif country == "KSA":
    print(f"Hello {name}")
    print(f"The Price Is {price - 10}")
```

`elif` is checked only if the previous branch fails. With these sample values, Python never reaches it because the Egypt condition already succeeds.

## `else` — the default path

```python
else:
    print(f"Hello {name}")
    print(f"The Price Is {price}")
```

`else` needs no condition; it is the final option when every earlier `if` and `elif` condition is False.

## Run the complete example

```python
name = "Ahmed"
country = "Egypt"
price = 100

if country == "Egypt":
    print(f"Hello {name}")
    print(f"The Price Is {price - 20}")

elif country == "KSA":
    print(f"Hello {name}")
    print(f"The Price Is {price - 10}")

else:
    print(f"Hello {name}")
    print(f"The Price Is {price}")
```

```output
Hello Ahmed
The Price Is 80
```

Only the Egypt branch appears. `elif` and `else` do not run because the choice ends at the first true condition.

## General shape and indentation

```python
if condition:
    # Code

elif another_condition:
    # Code

else:
    # Code
```

The `:` starts a block, and indentation identifies the lines that belong to it. Four spaces are the usual convention.

> [!WARNING]
> Indentation is not decoration; it is part of the syntax. A line with the wrong indentation can cause `IndentationError` or leave a branch unexpectedly.

## Quick mental model

- `if` = try the first condition.
- `elif` = try an alternative if the previous one failed.
- `else` = run the default if all previous branches failed.
- The first successful branch ends the chain.
