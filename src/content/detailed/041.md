# 041 — Control Flow: If, Elif, Else

Control Flow يخلّي البرنامج يختار مسارًا مختلفًا حسب شرط. Python تفحص الفروع من أعلى لأسفل وتنفذ **أول فرع شرطه True فقط**.

## `if` — أول سؤال

```python
name = "Ahmed"
country = "Egypt"
price = 100

if country == "Egypt":
    print(f"Hello {name}")
    print(f"The Price Is {price - 20}")
```

الشرط `country == "Egypt"` True، لذلك السطران المزاحان للداخل ينفذان، والخصم 20 يجعل السعر 80.

## `elif` — احتمال إضافي

```python
elif country == "KSA":
    print(f"Hello {name}")
    print(f"The Price Is {price - 10}")
```

`elif` لا تُفحص إلا لو فشل الفرع السابق. في بيانات المثال لن تصل لها Python لأن شرط Egypt نجح بالفعل.

## `else` — المسار الافتراضي

```python
else:
    print(f"Hello {name}")
    print(f"The Price Is {price}")
```

`else` لا تحتاج Condition؛ هي الحل الأخير عندما تكون كل شروط `if` و`elif` السابقة False.

## تشغيل المثال كاملًا

```python
name = "Ahmed"
country = "Egypt"
price = 100

if country == "Egypt":
    print(f"Hello {name}")
    print(f"The Price Is {price - 20}")

elif country == "KSA":
    print(f"Hello {name}")
    print(f"The Price Is {price - 10}")

else:
    print(f"Hello {name}")
    print(f"The Price Is {price}")
```

```output
Hello Ahmed
The Price Is 80
```

ظهر فرع Egypt فقط. `elif` و`else` لم ينفذا لأن الاختيار انتهى عند أول شرط صحيح.

## الشكل العام وIndentation

```python
if condition:
    # Code

elif another_condition:
    # Code

else:
    # Code
```

الـ `:` تبدأ Block، والـ Indentation تحدد السطور التابعة لها. عادة نستخدم أربع مسافات.

> [!WARNING]
> الـ Indentation ليست تجميلًا؛ هي جزء من Syntax. سطر غير مزاح في المكان الصحيح قد يسبب `IndentationError` أو يخرج من الفرع في وقت غير مقصود.

## الصورة الذهنية السريعة

- `if` = جرّب الشرط الأول.
- `elif` = جرّب بديلًا لو السابق فشل.
- `else` = نفّذ الافتراضي لو الكل فشل.
- أول Branch ناجح ينهي السلسلة.
