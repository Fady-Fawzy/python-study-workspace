# 055 — Loop Advanced Dictionary

الـ Dictionary توفر أكثر من طريقة للدوران حسب هل تحتاج Keys، Values، أم الاثنين معًا.

```python
user = {
    "name": "Ahmed",
    "age": 25,
    "country": "Egypt"
}
```

## الدوران الافتراضي يعطي Keys

```python
for item in user:
    print(item)
```

```output
name
age
country
```

`for item in user` تمر على المفاتيح، بنفس فكرة `for item in user.keys()`.

## استخدام المفتاح للوصول للقيمة

```python
for key in user:
    print(user[key])
```

```output
Ahmed
25
Egypt
```

في كل دورة `key` تحمل اسم المفتاح، و`user[key]` تقرأ القيمة المقابلة.

## الدوران على `user.values()`

```python
for value in user.values():
    print(value)
```

```output
Ahmed
25
Egypt
```

لو لا تحتاج المفاتيح، `user.values()` أوضح لأنها تعطي القيم مباشرة.

## Keys وValues مع `user.items()`

```python
for key, value in user.items():
    print(f"{key} => {value}")
```

```output
name => Ahmed
age => 25
country => Egypt
```

كل عنصر من `user.items()` عبارة عن Tuple `(key, value)`. الـ Unpacking يوزع الجزأين على `key, value` في رأس الـ Loop.

> [!COMPARISON]
> `for key in user` عندما تحتاج Keys.
> `for value in user.values()` عندما تحتاج Values فقط.
> `for key, value in user.items()` عندما تحتاج العلاقة كاملة.

## الصورة الذهنية السريعة

اختار View تناسب البيانات المطلوبة بدل ما تعمل وصولًا إضافيًا بلا داعٍ: Keys، Values، أو Items.
