# 055 — Loop Advanced Dictionary

A Dictionary offers several loop views depending on whether you need keys, values, or both together.

```python
user = {
    "name": "Ahmed",
    "age": 25,
    "country": "Egypt"
}
```

## The default loop gives keys

```python
for item in user:
    print(item)
```

```output
name
age
country
```

`for item in user` visits keys, just like `for item in user.keys()`.

## Use the key to access the value

```python
for key in user:
    print(user[key])
```

```output
Ahmed
25
Egypt
```

On each cycle, `key` holds the key name and `user[key]` reads its corresponding value.

## Loop over `user.values()`

```python
for value in user.values():
    print(value)
```

```output
Ahmed
25
Egypt
```

If you do not need keys, `user.values()` is clearer because it gives values directly.

## Keys and values with `user.items()`

```python
for key, value in user.items():
    print(f"{key} => {value}")
```

```output
name => Ahmed
age => 25
country => Egypt
```

Each item from `user.items()` is a Tuple `(key, value)`. Unpacking assigns the two parts to `key` and `value` in the loop header.

> [!COMPARISON]
> `for key in user` when you need keys.
> `for value in user.values()` when you need values only.
> `for key, value in user.items()` when you need the full relationship.

## Quick mental model

Choose the view that matches the data you need instead of doing unnecessary extra lookups: keys, values, or items.
