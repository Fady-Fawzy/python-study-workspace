# 022 — Lists Methods Part 1

A **method** is a function attached to a List and called with dot notation, such as `friends.append("Mahmoud")`. This lesson covers five methods. More important than memorizing their names is knowing whether each adds one item or many, removes by value, or changes versus sorts the order.

## `append()` — add one object

The syntax is `list.append(value)`. `append()` adds **one object** to the end of the List, regardless of that object's type.

```python
friends = ["Ahmed", "Mohamed", "Ali"]
old_friends = ["Hassan", "Omar", "Khaled"]

friends.append("Mahmoud")
friends.append(100)
friends.append(old_friends)

print(friends)
print(friends[-1])
print(friends[-1][1])
```

```output
['Ahmed', 'Mohamed', 'Ali', 'Mahmoud', 100, ['Hassan', 'Omar', 'Khaled']]
['Hassan', 'Omar', 'Khaled']
Omar
```

The first call adds a String and the second adds an Integer. The third call does not open `old_friends` and add its items; it adds the entire List as one item, so `friends` ends with a **nested List**.

`friends[-1]` reaches the last item, which is the complete inner List. Then `friends[-1][1]` indexes that inner List and gets item `1`, which is `"Omar"`.

> [!WARNING]
> `append(list)` creates a nesting level because the passed List is treated as one object. If you want to add its items one by one, use `extend()`.

## `extend()` — add iterable items

The syntax is `list.extend(iterable)`. `extend()` walks through the iterable and adds each of its items to the end of the original List.

```python
numbers = [1, 2, 3]
letters = ["A", "B", "C"]

numbers.extend(letters)

print(numbers)
```

```output
[1, 2, 3, 'A', 'B', 'C']
```

Python takes `"A"`, then `"B"`, then `"C"` from `letters` and adds them as separate items. No inner List appears in the result.

> [!COMPARISON]
> `append([3, 4])` adds `[3, 4]` as one nested item, producing something like `[1, 2, [3, 4]]`. `extend([3, 4])` adds `3` and `4` as two items, producing `[1, 2, 3, 4]`.

> [!MENTAL-MODEL]
> `append()` says: “put this object at the end of the List.” `extend()` says: “open this iterable and add its items one by one.”

## `remove()` — remove the first matching value

The syntax is `list.remove(value)`. `remove()` searches for a **value** and deletes only its first matching occurrence.

```python
names = ["Ahmed", "Ali", "Ahmed", "Omar"]

names.remove("Ahmed")

print(names)
```

```output
['Ali', 'Ahmed', 'Omar']
```

The value `"Ahmed"` appears twice, but `remove()` stops after deleting the first match. The second occurrence therefore remains in the List.

If we request a value that is not present, Python does not silently ignore it:

```python
names.remove("Sara")
```

```error
ValueError: list.remove(x): x not in list
```

> [!IMPORTANT]
> Use `remove()` when you know the value to delete. It does not remove every duplicate, and it expects a value rather than an index.

## `sort()` — sort the List in place

`sort()` orders the List's own items **in place**. It changes the original List instead of creating a sorted List.

```python
nums = [10, 5, 100, -5, 20]

nums.sort()
print(nums)

nums.sort(reverse=True)
print(nums)
```

```output
[-5, 5, 10, 20, 100]
[100, 20, 10, 5, -5]
```

The first call sorts the numbers in ascending order. With `reverse=True`, the order is descending.

`sort()` returns `None` because it modifies the List itself:

```python
nums = [3, 1, 2]
result = nums.sort()

print(result)
print(nums)
```

```output
None
[1, 2, 3]
```

> [!WARNING]
> Do not write `new_list = nums.sort()` expecting `new_list` to contain the sorted List; it will contain `None`. Call `nums.sort()` and then use `nums` itself.

## `reverse()` — reverse the current order

`reverse()` flips the current item sequence from end to beginning. It does not compare values or sort them by size or alphabetic order.

```python
items = [10, 1, "Python", True]

items.reverse()

print(items)
```

```output
[True, 'Python', 1, 10]
```

The last item, `True`, becomes first, and the previous item, `"Python"`, becomes second. Mixed types work because this is only a positional flip, not a sorting operation.

> [!COMPARISON]
> `sort()` arranges items according to an ordering rule. `reverse()` flips the existing order. For `[3, 1, 2]`, `sort()` produces `[1, 2, 3]`, while `reverse()` produces `[2, 1, 3]`.

## Key differences at a glance

| Method | Mental model |
| --- | --- |
| `append(value)` | Add one object at the end |
| `extend(iterable)` | Add iterable items one by one |
| `remove(value)` | Remove the first matching value |
| `sort()` | Sort the original List and return `None` |
| `reverse()` | Flip the current order without sorting |
