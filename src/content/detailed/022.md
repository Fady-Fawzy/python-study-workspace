# 022 — Lists Methods Part 1

الـ **Method** هي وظيفة مرتبطة بالـ List ونستدعيها باستخدام النقطة، مثل `friends.append("Mahmoud")`. في الدرس ده هنفهم خمس Methods، والأهم من حفظ أسمائها هو معرفة: هل تضيف عنصرًا أم عناصر؟ هل تحذف بالقيمة؟ وهل تغيّر ترتيب الـ List أم ترتبها؟

## `append()` — إضافة Object واحد

الصيغة هي `list.append(value)`. الـ `append()` تضيف **Object واحدًا** في نهاية الـ List، مهما كان نوع هذا الـ Object.

```python
friends = ["Ahmed", "Mohamed", "Ali"]
old_friends = ["Hassan", "Omar", "Khaled"]

friends.append("Mahmoud")
friends.append(100)
friends.append(old_friends)

print(friends)
print(friends[-1])
print(friends[-1][1])
```

```output
['Ahmed', 'Mohamed', 'Ali', 'Mahmoud', 100, ['Hassan', 'Omar', 'Khaled']]
['Hassan', 'Omar', 'Khaled']
Omar
```

أول استدعاء أضاف String، والثاني أضاف Integer. الاستدعاء الثالث لم يفتح `old_friends` ويضيف عناصرها؛ بل أضاف الـ List كلها كعنصر واحد، لذلك أصبح عندنا **nested List** في آخر `friends`.

`friends[-1]` تصل إلى آخر عنصر، وهو الـ List الداخلية كاملة. وبعدها `friends[-1][1]` تبدأ من هذه الـ List الداخلية وتأخذ العنصر عند Index `1`، وهو `"Omar"`.

> [!WARNING]
> `append(list)` تنشئ مستوى nesting لأن الـ List المرسلة تُعامل كـ Object واحد. لو هدفك إضافة عناصرها واحدًا واحدًا، استخدم `extend()`.

## `extend()` — إضافة عناصر Iterable

الصيغة هي `list.extend(iterable)`. الـ `extend()` تمشي على عناصر الـ iterable وتضيف كل عنصر منها إلى نهاية الـ List الأصلية.

```python
numbers = [1, 2, 3]
letters = ["A", "B", "C"]

numbers.extend(letters)

print(numbers)
```

```output
[1, 2, 3, 'A', 'B', 'C']
```

Python أخذت `"A"` ثم `"B"` ثم `"C"` من `letters` وأضافتها كعناصر مستقلة. لم تظهر List داخلية في النتيجة.

> [!COMPARISON]
> `append([3, 4])` تضيف `[3, 4]` كعنصر واحد nested، فتكون النتيجة مثل `[1, 2, [3, 4]]`. أما `extend([3, 4])` فتضيف `3` و`4` كعنصرين، فتكون النتيجة `[1, 2, 3, 4]`.

> [!MENTAL-MODEL]
> `append()` تقول: «ضع هذا الشيء في آخر الـ List». `extend()` تقول: «افتح هذا الـ iterable وأضف عناصره واحدًا واحدًا».

## `remove()` — حذف أول قيمة مطابقة

الصيغة هي `list.remove(value)`. الـ `remove()` تبحث عن **القيمة** وتحذف أول ظهور مطابق فقط.

```python
names = ["Ahmed", "Ali", "Ahmed", "Omar"]

names.remove("Ahmed")

print(names)
```

```output
['Ali', 'Ahmed', 'Omar']
```

القيمة `"Ahmed"` موجودة مرتين، لكن `remove()` توقفت بعد حذف أول تطابق. لذلك ظل الظهور الثاني موجودًا في الـ List.

لو طلبنا حذف قيمة غير موجودة، Python لا تتجاهل الطلب بصمت:

```python
names.remove("Sara")
```

```error
ValueError: list.remove(x): x not in list
```

> [!IMPORTANT]
> استخدم `remove()` لما تعرف القيمة المراد حذفها. هي لا تحذف كل القيم المتكررة، ولا تستقبل Index بدل القيمة.

## `sort()` — ترتيب الـ List في مكانها

الـ `sort()` ترتب عناصر الـ List نفسها **in place**؛ أي تعدّل الـ List الأصلية بدل إنشاء List مرتبة جديدة.

```python
nums = [10, 5, 100, -5, 20]

nums.sort()
print(nums)

nums.sort(reverse=True)
print(nums)
```

```output
[-5, 5, 10, 20, 100]
[100, 20, 10, 5, -5]
```

الاستدعاء الأول رتب الأرقام تصاعديًا من الأصغر إلى الأكبر. ومع `reverse=True` انعكس اتجاه الترتيب فأصبح تنازليًا.

القيمة التي ترجعها `sort()` هي `None` لأنها تعدّل الـ List نفسها:

```python
nums = [3, 1, 2]
result = nums.sort()

print(result)
print(nums)
```

```output
None
[1, 2, 3]
```

> [!WARNING]
> لا تكتب `new_list = nums.sort()` وأنت متوقع أن `new_list` تحتوي الـ List المرتبة؛ المتغير سيحمل `None`. استدعِ `nums.sort()` ثم استخدم `nums` نفسها.

## `reverse()` — قلب الترتيب الحالي

الـ `reverse()` تقلب تسلسل العناصر الحالي من النهاية للبداية. هي لا تقارن القيم ولا ترتبها حسب الحجم أو الحروف.

```python
items = [10, 1, "Python", True]

items.reverse()

print(items)
```

```output
[True, 'Python', 1, 10]
```

العنصر الأخير `True` أصبح الأول، والذي قبله `"Python"` أصبح الثاني، وهكذا. نجاح العملية مع أنواع مختلفة يؤكد أنها مجرد قلب للمواقع الحالية، وليست عملية sorting.

> [!COMPARISON]
> `sort()` ترتب العناصر وفق قاعدة ترتيب. `reverse()` تقلب الترتيب الموجود بالفعل. لو كانت الـ List `[3, 1, 2]`، فإن `sort()` تجعلها `[1, 2, 3]`، بينما `reverse()` تجعلها `[2, 1, 3]`.

## الفروق المهمة في سطر واحد

| Method | الصورة الذهنية |
| --- | --- |
| `append(value)` | أضف Object واحدًا في النهاية |
| `extend(iterable)` | أضف عناصر الـ iterable واحدًا واحدًا |
| `remove(value)` | احذف أول قيمة مطابقة |
| `sort()` | رتّب الـ List الأصلية وارجع `None` |
| `reverse()` | اقلب الترتيب الحالي من غير sorting |
