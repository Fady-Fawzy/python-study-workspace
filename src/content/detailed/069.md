# 069 — Built In Functions Part 1

Built-in Functions جاهزة داخل Python من غير Import. المجموعة دي تختبر Truthiness وتحوّل للأرقام الثنائية وتعرض هوية object أثناء التشغيل.

## `all()` — هل كل العناصر Truthy؟

```python
numbers = [1, 2, 3, 4]

print(all(numbers))
```

```output
True
```

كل الأرقام غير صفرية، لذلك كلها Truthy والنتيجة True.

```python
numbers = [1, 2, 0, 4]

print(all(numbers))
```

```output
False
```

وجود `0` واحد، وهو Falsy، يكفي لجعل `all()` False.

## `any()` — هل يوجد عنصر Truthy؟

```python
numbers = [0, False, "", 10]

print(any(numbers))
```

```output
True
```

أول ثلاثة عناصر Falsy، لكن `10` Truthy، و`any()` تحتاج عنصرًا صحيحًا واحدًا فقط.

> [!COMPARISON]
> `all()` = كلهم لازم Truthy.
> `any()` = واحد Truthy يكفي.

## `bin()` — التمثيل الثنائي

```python
print(bin(10))
```

```output
0b1010
```

العدد العشري 10 يساوي `1010` بالنظام Binary. Prefix `0b` يوضح أن النص الناتج تمثيل ثنائي.

## `id()` — هوية object أثناء التشغيل

```python
x = 100

print(id(x))
```

```example-output
140234567890000
```

`id()` ترجع Integer فريدة لهوية الـ object خلال عمرها الحالي. الرقم المعروض مجرد Example Output؛ القيمة الفعلية تعتمد على تشغيل Python والبيئة وستختلف غالبًا.

> [!WARNING]
> لا تستخدم قيمة `id()` كمعرّف دائم في ملف أو Database؛ معناها مؤقت داخل عملية Python الحالية.

## الصورة الذهنية السريعة

- `all` = الجميع.
- `any` = أي واحد.
- `bin` = شكل Binary.
- `id` = هوية Runtime مؤقتة.
