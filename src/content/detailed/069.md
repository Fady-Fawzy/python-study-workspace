# 069 — Built In Functions Part 1

Built-in functions are available inside Python without an import. This group tests truthiness, converts numbers to binary, and exposes an object's identity during runtime.

## `all()` — are all items Truthy?

```python
numbers = [1, 2, 3, 4]

print(all(numbers))
```

```output
True
```

All numbers are non-zero, so they are all Truthy and the result is True.

```python
numbers = [1, 2, 0, 4]

print(all(numbers))
```

```output
False
```

One `0`, which is Falsy, is enough to make `all()` False.

## `any()` — is any item Truthy?

```python
numbers = [0, False, "", 10]

print(any(numbers))
```

```output
True
```

The first three items are Falsy, but `10` is Truthy, and `any()` needs only one true item.

> [!COMPARISON]
> `all()` = every item must be Truthy.
> `any()` = one Truthy item is enough.

## `bin()` — binary representation

```python
print(bin(10))
```

```output
0b1010
```

The decimal number 10 is `1010` in binary. The `0b` prefix shows that the returned text is a binary representation.

## `id()` — an object's runtime identity

```python
x = 100

print(id(x))
```

```example-output
140234567890000
```

`id()` returns an integer identifying the object during its current lifetime. The displayed number is example output; the actual value depends on the Python process and environment and will usually differ.

> [!WARNING]
> Do not use an `id()` value as a permanent identifier in a file or database; it is meaningful only inside the current Python process.

## Quick mental model

- `all` = everyone.
- `any` = at least one.
- `bin` = binary form.
- `id` = temporary runtime identity.
