# 039 — Practical Email Slice

المثال يطبّق `input()` وString Methods وSlicing لاستخراج أجزاء عنوان Email بسيط بالشكل `username@website.domain`.

## تجهيز البريد الإلكتروني

```python
email = input("Enter Your Email: ").strip().lower()
```

`strip()` تزيل المسافات الخارجية، و`lower()` توحّد الحروف إلى lowercase. ده يجعل النتيجة أسهل في المقارنة والعرض.

## استخراج Username

```python
username = email[:email.index("@")]
```

`email.index("@")` تعيد مكان علامة `@`. الـ Slice تبدأ من أول النص وتتوقف قبل العلامة لأن Stop في Slicing غير included.

لو البريد `ahmed@gmail.com`، فالجزء قبل `@` هو `ahmed`.

## استخراج Website

```python
website = email[email.index("@") + 1:email.index(".")]
```

البداية بعد `@` مباشرة بسبب `+ 1`، والنهاية قبل أول نقطة. كده لا تدخل `@` ولا `.` ضمن القيمة.

## استخراج Domain

```python
domain = email[email.index(".") + 1:]
```

الـ Slice تبدأ بعد النقطة وتستمر للنهاية لأن Stop غير مكتوبة.

## تشغيل المثال كاملًا

```python
email = input("Enter Your Email: ").strip().lower()

username = email[:email.index("@")]

website = email[email.index("@") + 1:email.index(".")]

domain = email[email.index(".") + 1:]

print(f"Username: {username}")
print(f"Website: {website}")
print(f"Domain: {domain}")
```

```example-run
Enter Your Email: ahmed@gmail.com
Username: ahmed
Website: gmail
Domain: com
```

النتيجة اتكوّنت من ثلاث مناطق يفصل بينها `@` والنقطة.

> [!WARNING]
> المثال تدريب على Slice، ويفترض صيغة بسيطة صحيحة وبها `@` ونقطة واحدة مناسبة. لو علامة مفقودة، `index()` ترفع `ValueError`. عناوين Email الأكثر تعقيدًا تحتاج Validation أقوى، وده خارج هدف الدرس.

## الصورة الذهنية السريعة

- اعثر على الفاصل باستخدام `index()`.
- استخدم مكان الفاصل كحد للـ Slice.
- `+ 1` يتجاوز الفاصل نفسه.
- Stop غير included، لذلك الحد الأخير لا يدخل في النتيجة.
