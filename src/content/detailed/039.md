# 039 — Practical Email Slice

This example combines `input()`, String methods, and slicing to extract parts of a simple email address in the form `username@website.domain`.

## Prepare the email address

```python
email = input("Enter Your Email: ").strip().lower()
```

`strip()` removes outer spaces, and `lower()` normalizes letters to lowercase. This makes the result easier to compare and display.

## Extract the username

```python
username = email[:email.index("@")]
```

`email.index("@")` returns the position of `@`. The slice starts at the beginning and stops before the mark because the slice stop is excluded.

For `ahmed@gmail.com`, the part before `@` is `ahmed`.

## Extract the website

```python
website = email[email.index("@") + 1:email.index(".")]
```

The start is immediately after `@` because of `+ 1`, and the end is before the first dot. Neither separator enters the value.

## Extract the domain

```python
domain = email[email.index(".") + 1:]
```

The slice starts after the dot and continues to the end because no stop is written.

## Run the complete example

```python
email = input("Enter Your Email: ").strip().lower()

username = email[:email.index("@")]

website = email[email.index("@") + 1:email.index(".")]

domain = email[email.index(".") + 1:]

print(f"Username: {username}")
print(f"Website: {website}")
print(f"Domain: {domain}")
```

```example-run
Enter Your Email: ahmed@gmail.com
Username: ahmed
Website: gmail
Domain: com
```

The result is made of three regions separated by `@` and the dot.

> [!WARNING]
> This is a slicing exercise. It assumes a simple valid form containing `@` and a suitable dot. If a separator is missing, `index()` raises `ValueError`. More complex email addresses need stronger validation, which is outside this lesson.

## Quick mental model

- Find a separator with `index()`.
- Use the separator position as a slice boundary.
- `+ 1` skips the separator itself.
- The stop is excluded, so the final boundary is not part of the result.
