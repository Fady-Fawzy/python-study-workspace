# 071 — Built In Functions Part 3

هنا Functions للحساب والحدود، ومعها `slice()` التي تصنع وصف Slice قابل لإعادة الاستخدام.

## `abs()` — القيمة المطلقة

```python
print(abs(-100))
```

```output
100
```

القيمة المطلقة هي المسافة عن الصفر بلا إشارة، لذلك سالب 100 تصبح 100.

## `pow()` — الأس

```python
print(pow(2, 5))
```

```output
32
```

`pow(2, 5)` تعادل `2 ** 5`: ضرب 2 في نفسها خمس مرات.

## `min()` و`max()` مع الأرقام

```python
numbers = [10, 30, 5, 100]

print(min(numbers))
print(max(numbers))
```

```output
5
100
```

`min()` تختار أصغر عنصر و`max()` تختار الأكبر.

## المقارنة مع Strings

```python
print(min("Ahmed", "Mohamed", "Ali"))
print(max("Ahmed", "Mohamed", "Ali"))
```

```output
Ahmed
Mohamed
```

Strings تُقارن Lexicographically حسب ترتيب الحروف، مش حسب طول الاسم. `Ahmed` تأتي قبل `Ali` لأن المقارنة تنتقل للحرف المختلف، و`M` تجعل `Mohamed` الأكبر هنا.

## `slice()` — Slice object قابلة لإعادة الاستخدام

```python
name = "Programming"

print(name[0:5])

my_slice = slice(0, 5)

print(name[my_slice])
```

```output
Progr
Progr
```

`slice(0, 5)` تمثل نفس حدود `[0:5]`: Start included وStop excluded. تخزينها مفيد لو ستستخدم نفس Slice أكثر من مرة.

## الصورة الذهنية السريعة

- `abs` تزيل الإشارة.
- `pow` ترفع للقوة.
- `min/max` تختار الحدود حسب قواعد مقارنة النوع.
- `slice` تحفظ وصف Start/Stop/Step.
