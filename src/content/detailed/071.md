# 071 — Built In Functions Part 3

This lesson covers functions for calculations and boundaries, plus `slice()`, which creates a reusable slice description.

## `abs()` — absolute value

```python
print(abs(-100))
```

```output
100
```

Absolute value is the distance from zero without a sign, so negative 100 becomes 100.

## `pow()` — powers

```python
print(pow(2, 5))
```

```output
32
```

`pow(2, 5)` is equivalent to `2 ** 5`: multiplying 2 by itself five times.

## `min()` and `max()` with numbers

```python
numbers = [10, 30, 5, 100]

print(min(numbers))
print(max(numbers))
```

```output
5
100
```

`min()` selects the smallest item and `max()` selects the largest.

## Comparing Strings

```python
print(min("Ahmed", "Mohamed", "Ali"))
print(max("Ahmed", "Mohamed", "Ali"))
```

```output
Ahmed
Mohamed
```

Strings are compared lexicographically by character order, not by name length. `Ahmed` comes before `Ali` because comparison reaches their differing character, and `M` makes `Mohamed` the largest here.

## `slice()` — a reusable slice object

```python
name = "Programming"

print(name[0:5])

my_slice = slice(0, 5)

print(name[my_slice])
```

```output
Progr
Progr
```

`slice(0, 5)` represents the same bounds as `[0:5]`: Start is included and Stop is excluded. Storing it is useful when you will reuse the same slice more than once.

## Quick mental model

- `abs` removes the sign.
- `pow` raises to a power.
- `min/max` choose boundaries using the type's comparison rules.
- `slice` stores a Start/Stop/Step description.
