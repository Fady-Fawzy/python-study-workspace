# 045 — Membership Operators

Membership operators ask whether a value exists inside a container. `in` tests presence, `not in` tests absence, and the result is a Boolean.

## `in` with a List

```python
name = "Ahmed"

friends = ["Ahmed", "Mohamed", "Ali"]

print(name in friends)
```

```output
True
```

Python compares `name` with the List items and finds `"Ahmed"`, so the result is True.

## `not in` with a List

```python
name = "Omar"

friends = ["Ahmed", "Mohamed", "Ali"]

print(name not in friends)
```

```output
True
```

`"Omar"` is absent, so the question “is it not present?” has the answer True.

## Membership inside a String

```python
word = "Python"

print("P" in word)
print("z" in word)
```

```output
True
False
```

A String is treated as a sequence of Characters. The test is case-sensitive: uppercase `P` is present, while `z` is not.

## Membership inside a Dictionary

```python
user = {
    "name": "Ahmed",
    "age": 25
}

print("name" in user)
print("country" in user)
```

```output
True
False
```

With a Dictionary, `in` tests **keys** by default, not values. The key `name` exists, while `country` does not.

If you mean values, write it explicitly as `"Ahmed" in user.values()`.

> [!COMPARISON]
> `value in sequence` searches the items.
> `key in dictionary` searches the keys.
> `value in dictionary.values()` searches the values.

## Quick mental model

- `in` = is the value present?
- `not in` = is the value absent?
- The result is always a Boolean.
- Searching a Dictionary means keys unless you explicitly use `values()` or `items()`.
