# 045 — Membership Operators

Membership Operators تسأل هل قيمة موجودة داخل Container. `in` تختبر الوجود، و`not in` تختبر الغياب، والناتج Boolean.

## `in` مع List

```python
name = "Ahmed"

friends = ["Ahmed", "Mohamed", "Ali"]

print(name in friends)
```

```output
True
```

Python قارنت `name` بعناصر الـ List ووجدت `"Ahmed"`، فكانت النتيجة True.

## `not in` مع List

```python
name = "Omar"

friends = ["Ahmed", "Mohamed", "Ali"]

print(name not in friends)
```

```output
True
```

`"Omar"` غير موجود، لذلك سؤال "هل هو غير موجود؟" إجابته True.

## Membership داخل String

```python
word = "Python"

print("P" in word)
print("z" in word)
```

```output
True
False
```

String تُعامل كـ sequence من Characters. الاختبار Case-sensitive: الحرف Capital `P` موجود، و`z` غير موجود.

## Membership داخل Dictionary

```python
user = {
    "name": "Ahmed",
    "age": 25
}

print("name" in user)
print("country" in user)
```

```output
True
False
```

مع Dictionary، `in` تختبر **المفاتيح** افتراضيًا، مش القيم. المفتاح `name` موجود، و`country` غير موجود.

لو كنت تقصد القيم، اكتب بوضوح `"Ahmed" in user.values()`.

> [!COMPARISON]
> `value in sequence` يبحث بين العناصر.
> `key in dictionary` يبحث بين المفاتيح.
> `value in dictionary.values()` يبحث بين القيم.

## الصورة الذهنية السريعة

- `in` = هل القيمة موجودة؟
- `not in` = هل القيمة غائبة؟
- الناتج دائمًا Boolean.
- البحث في Dictionary يعني Keys إلا لو حددت `values()` أو `items()`.
