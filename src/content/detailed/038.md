# 038 — User Input

`input()` pauses the program, shows a prompt, and waits for the user to type a value and press Enter. Its return value is **always a String**.

## Reading text from the user

```python
name = input("What's Your Name? ")

print(name)
```

```example-run
What's Your Name? Ahmed
Ahmed
```

The user typed `Ahmed`, so `input()` returned that text and stored it in `name`. Then `print(name)` displayed the same value.

## Cleaning and formatting input

```python
name = input("What's Your Name? ")

name = name.strip().capitalize()

print(f"Hello {name}")
```

```example-run
What's Your Name?   ahmed
Hello Ahmed
```

`strip()` removes leading and trailing spaces, then `capitalize()` makes the first character uppercase and the rest lowercase. The f-string places the value inside the message.

> [!IMPORTANT]
> Method order matters from left to right: first clean the spaces, then format the letters, then store the result.

## `input()` returns a String

```python
age = input("Enter Your Age: ")

print(type(age))
```

```example-run
Enter Your Age: 25
<class 'str'>
```

Even when the user types `25`, the type is String. The keyboard supplied characters, and Python does not automatically assume that you want a number.

## Convert input to an Integer

```python
age = int(input("Enter Your Age: "))

print(age)
print(type(age))
```

```example-run
Enter Your Age: 25
25
<class 'int'>
```

Evaluation starts inside: `input()` returns `"25"`, `int()` converts it to `25`, and the result is stored in `age`.

> [!WARNING]
> If the user types text that is not a valid number, `int()` raises `ValueError`. Handling invalid input will need control flow and exception handling later.

## Quick mental model

- `input(prompt)` = show a question and wait for a String.
- Clean the text before using it when needed.
- Convert the type explicitly before arithmetic.
- An example run changes based on what the user types.
