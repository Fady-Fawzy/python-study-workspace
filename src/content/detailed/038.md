# 038 — User Input

`input()` توقف البرنامج مؤقتًا، تعرض Prompt للمستخدم، وتنتظر منه كتابة قيمة ثم الضغط على Enter. القيمة الراجعة **String دائمًا**.

## قراءة نص من المستخدم

```python
name = input("What's Your Name? ")

print(name)
```

```example-run
What's Your Name? Ahmed
Ahmed
```

المستخدم كتب `Ahmed`، فـ `input()` رجّعت النص وخزنته في `name`. بعد كده `print(name)` عرض نفس القيمة.

## تنظيف وتنسيق الإدخال

```python
name = input("What's Your Name? ")

name = name.strip().capitalize()

print(f"Hello {name}")
```

```example-run
What's Your Name?   ahmed
Hello Ahmed
```

`strip()` حذفت المسافات من البداية والنهاية، ثم `capitalize()` جعلت أول حرف Capital وباقي الحروف Lowercase. الـ f-string وضعت القيمة داخل الرسالة.

> [!IMPORTANT]
> ترتيب الـ Methods من الشمال لليمين مهم: أولًا ننظف المسافات، ثم ننسّق الحروف، ثم نحفظ الناتج.

## `input()` ترجع String

```python
age = input("Enter Your Age: ")

print(type(age))
```

```example-run
Enter Your Age: 25
<class 'str'>
```

حتى مع كتابة `25`، النوع String. لوحة المفاتيح أعطت البرنامج حروفًا، وPython لا تفترض تلقائيًا إنك تريد رقمًا.

## تحويل الإدخال إلى Integer

```python
age = int(input("Enter Your Age: "))

print(age)
print(type(age))
```

```example-run
Enter Your Age: 25
25
<class 'int'>
```

التنفيذ يبدأ من الداخل: `input()` ترجع `"25"`، ثم `int()` تحولها إلى `25`، ثم تُحفظ في `age`.

> [!WARNING]
> لو المستخدم كتب نصًا لا يصلح كعدد، `int()` ترفع `ValueError`. معالجة الإدخال غير الصحيح هتحتاج Control Flow وException Handling في مراحل لاحقة.

## الصورة الذهنية السريعة

- `input(prompt)` = اعرض سؤالًا وانتظر String.
- نظّف النص قبل استخدامه عند الحاجة.
- حوّل النوع صراحة قبل الحساب.
- Example Run يتغير حسب ما يكتبه المستخدم.
