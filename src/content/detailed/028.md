# 028 — Set Methods Part 2

الدرس ده مبني على سؤال بسيط: لما عندي مجموعتين، عايز العناصر المختلفة، المشتركة، ولا الموجودة في جانب واحد فقط؟ كل عملية لها نسخة تُرجع Set جديدة، ونسخة `_update` تعدّل الـ Set الأصلية.

## `difference()` — الموجود في الأولى فقط

```python
a = {1, 2, 3, 4}
b = {1, 2, "Ahmed"}

print(a.difference(b))

print(a - b)
```

```example-output
{3, 4}
{3, 4}
```

بدأنا من `a` وحذفنا ذهنيًا كل قيمة موجودة أيضًا في `b`. القيمتان `1` و`2` مشتركتان، فالمتبقي من `a` هو `3` و`4`.

`a.difference(b)` و`a - b` نفس الفكرة، والعملية **اتجاهية**: نتيجة `b - a` ستكون العناصر الموجودة في `b` فقط، أي `"Ahmed"`.

## `difference_update()` — احتفظ بالاختلاف داخل الأصل

```python
a = {1, 2, 3, 4}
b = {1, 2}

a.difference_update(b)

print(a)
```

```example-output
{3, 4}
```

النتيجة تشبه `a.difference(b)`، لكن هنا `a` نفسها اتعدّلت. الميثود لا تصنع Set نستخدمها كقيمة جديدة؛ هي تنفذ التغيير in-place.

> [!COMPARISON]
> `a.difference(b)` تُرجع Set جديدة وتترك `a` كما هي.
> `a.difference_update(b)` تعدّل `a` نفسها.

## `intersection()` — العناصر المشتركة

```python
a = {1, 2, 3, 4, "Python"}
b = {2, 3, "Python"}

print(a.intersection(b))

print(a & b)
```

```example-output
{2, 3, 'Python'}
{2, 3, 'Python'}
```

الـ Intersection يسأل: "إيه القيم الموجودة في المجموعتين معًا؟" الإجابة هي `2` و`3` و`"Python"`. الرمز `&` اختصار لنفس العملية بين Sets.

## `intersection_update()` — عدّل الأصل إلى المشترك

```python
a = {1, 2, 3, 4}
b = {2, 3}

a.intersection_update(b)

print(a)
```

```example-output
{2, 3}
```

بعد العملية، `a` لم تعد تحتوي إلا القيم المشتركة مع `b`.

## `symmetric_difference()` — الموجود في جانب واحد فقط

```python
a = {1, 2, 3, 4}
b = {1, 2, 5, 6}

print(a.symmetric_difference(b))

print(a ^ b)
```

```example-output
{3, 4, 5, 6}
{3, 4, 5, 6}
```

القيم `1` و`2` مشتركة، فتم استبعادها. المتبقي هو القيم الموجودة في `a` أو `b` لكن **ليست في الاثنين معًا**: `3, 4, 5, 6`.

الرمز `^` اختصار للـ Symmetric Difference.

## `symmetric_difference_update()` — خزّن الاختلاف المتناظر في الأصل

```python
a = {1, 2, 3, 4}
b = {1, 2, 5, 6}

a.symmetric_difference_update(b)

print(a)
```

```example-output
{3, 4, 5, 6}
```

هنا `a` نفسها أصبحت نتيجة الاختلاف المتناظر.

## مقارنة العمليات الثلاث

لو `a = {1, 2, 3}` و`b = {3, 4}`:

| العملية | السؤال | النتيجة |
|---|---|---|
| `a - b` | ما الموجود في `a` وليس في `b`؟ | `{1, 2}` |
| `a & b` | ما الموجود في الاثنين؟ | `{3}` |
| `a ^ b` | ما الموجود في جانب واحد فقط؟ | `{1, 2, 4}` |

> [!WARNING]
> لا تخلط بين `difference` و`symmetric_difference`. الأولى تبدأ من الجهة اليسرى فقط، أما الثانية فتجمع اختلاف الجهتين وتستبعد المشترك.

## الصورة الذهنية السريعة

- `difference` = الأولى ناقص الثانية.
- `intersection` = المنطقة المشتركة.
- `symmetric_difference` = الأطراف من غير المنطقة المشتركة.
- الاسم بدون `_update` يرجع Set جديدة؛ الاسم مع `_update` يغيّر الأصل.
