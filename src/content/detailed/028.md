# 028 — Set Methods Part 2

This lesson starts with a simple question: with two Sets, do you need the different items, the shared items, or the items found on only one side? Each operation has a version that returns a new Set and an `_update` version that changes the original Set.

## `difference()` — items only in the first Set

```python
a = {1, 2, 3, 4}
b = {1, 2, "Ahmed"}

print(a.difference(b))

print(a - b)
```

```example-output
{3, 4}
{3, 4}
```

We start with `a` and mentally remove every value that also appears in `b`. `1` and `2` are shared, so `3` and `4` remain from `a`.

`a.difference(b)` and `a - b` express the same idea, and the operation is **directional**: `b - a` would contain the items found only in `b`, namely `"Ahmed"`.

## `difference_update()` — keep the difference in the original

```python
a = {1, 2, 3, 4}
b = {1, 2}

a.difference_update(b)

print(a)
```

```example-output
{3, 4}
```

The result resembles `a.difference(b)`, but here `a` itself is changed. The method does not create a Set for a new value; it performs the change in place.

> [!COMPARISON]
> `a.difference(b)` returns a new Set and leaves `a` unchanged.
> `a.difference_update(b)` changes `a` itself.

## `intersection()` — shared items

```python
a = {1, 2, 3, 4, "Python"}
b = {2, 3, "Python"}

print(a.intersection(b))

print(a & b)
```

```example-output
{2, 3, 'Python'}
{2, 3, 'Python'}
```

Intersection asks: “Which values are present in both Sets?” The answer is `2`, `3`, and `"Python"`. The `&` symbol is shorthand for the same Set operation.

## `intersection_update()` — change the original to the shared items

```python
a = {1, 2, 3, 4}
b = {2, 3}

a.intersection_update(b)

print(a)
```

```example-output
{2, 3}
```

After the operation, `a` contains only the values shared with `b`.

## `symmetric_difference()` — items on one side only

```python
a = {1, 2, 3, 4}
b = {1, 2, 5, 6}

print(a.symmetric_difference(b))

print(a ^ b)
```

```example-output
{3, 4, 5, 6}
{3, 4, 5, 6}
```

The values `1` and `2` are shared, so they are excluded. What remains is found in `a` or `b` but **not in both**: `3, 4, 5, 6`.

The `^` symbol is shorthand for symmetric difference.

## `symmetric_difference_update()` — store the symmetric difference in the original

```python
a = {1, 2, 3, 4}
b = {1, 2, 5, 6}

a.symmetric_difference_update(b)

print(a)
```

```example-output
{3, 4, 5, 6}
```

Here, `a` itself becomes the symmetric-difference result.

## Comparing the three operations

If `a = {1, 2, 3}` and `b = {3, 4}`:

| Operation | Question | Result |
|---|---|---|
| `a - b` | What is in `a` but not in `b`? | `{1, 2}` |
| `a & b` | What is in both? | `{3}` |
| `a ^ b` | What is on one side only? | `{1, 2, 4}` |

> [!WARNING]
> Do not confuse `difference` with `symmetric_difference`. The first starts from the left side only; the second combines differences from both sides and excludes shared items.

## Quick mental model

- `difference` = the first Set minus the second.
- `intersection` = the shared region.
- `symmetric_difference` = both outer regions without the shared region.
- A name without `_update` returns a new Set; a name with `_update` changes the original.
