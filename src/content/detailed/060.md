# 060 — Packing & Unpacking Keyword Arguments

Two stars, `**`, work with keyword arguments: named data is packed into a Dictionary or unpacked from one.

## Packing with `**skills`

```python
def show_skills(**skills):
    print(skills)


show_skills(
    Python="90%",
    HTML="80%",
    CSS="75%"
)
```

```output
{'Python': '90%', 'HTML': '80%', 'CSS': '75%'}
```

The keyword names become keys and the values become values, so `skills` is a Dictionary inside the function.

## Loop over keyword arguments

```python
def show_skills(**skills):
    for skill, progress in skills.items():
        print(f"{skill} => {progress}")


show_skills(Python="90%", HTML="80%", CSS="75%")
```

```output
Python => 90%
HTML => 80%
CSS => 75%
```

`items()` provides `(key, value)`, and unpacking assigns them to `skill` and `progress`.

## Unpacking a Dictionary

```python
my_skills = {
    "Python": "90%",
    "HTML": "80%",
    "CSS": "75%"
}

show_skills(**my_skills)
```

```output
Python => 90%
HTML => 80%
CSS => 75%
```

`**my_skills` expands each pair into a keyword argument. Keys must be Strings. If a function has explicitly named parameters, the keys must match those names; `**skills` itself can collect any String key.

> [!COMPARISON]
> `*args` packs positional arguments into a Tuple.
> `**kwargs` packs keyword arguments into a Dictionary.

## Quick mental model

One star is for positions, two stars are for names: `*` handles positional items, while `**` handles name/value pairs.
