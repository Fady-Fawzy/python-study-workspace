# 060 — Packing & Unpacking Keyword Arguments

نجمتان `**` تتعاملان مع Keyword Arguments: بيانات لها أسماء، فتُجمع في Dictionary أو تُفك منها.

## Packing باستخدام `**skills`

```python
def show_skills(**skills):
    print(skills)


show_skills(
    Python="90%",
    HTML="80%",
    CSS="75%"
)
```

```output
{'Python': '90%', 'HTML': '80%', 'CSS': '75%'}
```

أسماء الـ Keywords أصبحت Keys، والقيم أصبحت Values. لذلك `skills` Dictionary داخل Function.

## Loop على Keyword Arguments

```python
def show_skills(**skills):
    for skill, progress in skills.items():
        print(f"{skill} => {progress}")


show_skills(Python="90%", HTML="80%", CSS="75%")
```

```output
Python => 90%
HTML => 80%
CSS => 75%
```

`items()` تعطي `(key, value)`، والـ Unpacking يوزعهما على `skill` و`progress`.

## Unpacking Dictionary

```python
my_skills = {
    "Python": "90%",
    "HTML": "80%",
    "CSS": "75%"
}

show_skills(**my_skills)
```

```output
Python => 90%
HTML => 80%
CSS => 75%
```

`**my_skills` فكّت كل زوج إلى Keyword Argument. المفاتيح لازم تكون Strings. لو الدالة تستقبل Parameters مسماة صراحة، لازم المفاتيح تطابق أسماءها؛ أما `**skills` نفسها فتقدر تجمع أي String key.

> [!COMPARISON]
> `*args` تجمع Positional Arguments في Tuple.
> `**kwargs` تجمع Keyword Arguments في Dictionary.

## الصورة الذهنية السريعة

نجمة واحدة للترتيب، ونجمتان للأسماء: `*` عناصر موضعية، `**` أزواج اسم وقيمة.
