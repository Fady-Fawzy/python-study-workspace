# 073 — Built In Functions Part 5 — Filter

`filter()` تمر على العناصر وتحتفظ فقط بالعناصر التي تجعل Function الاختبار ترجع Truthy.

## Function اختبار الأعداد الزوجية

```python
numbers = [1, 2, 3, 4, 5, 6]


def even_number(number):
    return number % 2 == 0
```

Function لا تعيد رقمًا جديدًا؛ تعيد Boolean يقرر هل الرقم يمر من الفلتر.

## تطبيق `filter()`

```python
result = filter(even_number, numbers)

print(list(result))
```

```output
[2, 4, 6]
```

الأرقام الزوجية فقط جعلت الشرط True، فاحتفظت `filter()` بالقيم الأصلية `2, 4, 6`.

## Filter مع Lambda

```python
numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda number: number % 2 == 0,
    numbers
)

print(list(result))
```

```output
[2, 4, 6]
```

Lambda تعبّر عن نفس Predicate. زي `map()`, الناتج Filter object كسولة ونحوّلها إلى List للعرض.

## فلترة أسماء تبدأ بحرف A

```python
names = [
    "Ahmed",
    "Ali",
    "Omar",
    "Mohamed"
]

result = filter(
    lambda name: name.startswith("A"),
    names
)

print(list(result))
```

```output
['Ahmed', 'Ali']
```

`startswith("A")` True لاسمي Ahmed وAli فقط، لذلك احتفظ بهما بنفس ترتيبهما الأصلي.

> [!COMPARISON]
> `map()` تُنتج قيمة محوّلة لكل عنصر.
> `filter()` تختار بعض العناصر الأصلية حسب Condition.

## الصورة الذهنية السريعة

Filter = بوابة: Function الاختبار تقول True فيمر العنصر، أو False فيُستبعد.
