# 073 — Built In Functions Part 5 — Filter

`filter()` visits items and keeps only those for which the test function returns a Truthy value.

## A function that tests even numbers

```python
numbers = [1, 2, 3, 4, 5, 6]


def even_number(number):
    return number % 2 == 0
```

The function does not return a new number; it returns a Boolean deciding whether the number passes the filter.

## Apply `filter()`

```python
result = filter(even_number, numbers)

print(list(result))
```

```output
[2, 4, 6]
```

Only even numbers make the condition True, so `filter()` keeps the original values `2, 4, 6`.

## Filter with a Lambda

```python
numbers = [1, 2, 3, 4, 5, 6]

result = filter(
    lambda number: number % 2 == 0,
    numbers
)

print(list(result))
```

```output
[2, 4, 6]
```

The Lambda expresses the same predicate. Like `map()`, the result is a lazy filter object, which we convert to a List for display.

## Filter names that start with A

```python
names = [
    "Ahmed",
    "Ali",
    "Omar",
    "Mohamed"
]

result = filter(
    lambda name: name.startswith("A"),
    names
)

print(list(result))
```

```output
['Ahmed', 'Ali']
```

`startswith("A")` is True only for Ahmed and Ali, so they are kept in their original order.

> [!COMPARISON]
> `map()` produces a transformed value for every item.
> `filter()` selects some original items according to a condition.

## Quick mental model

Filter = a gate: when the test function says True, the item passes; when it says False, the item is excluded.
