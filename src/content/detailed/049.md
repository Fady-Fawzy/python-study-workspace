# 049 — Bookmark Manager

المشروع الصغير يجمع مواقع من المستخدم في List، يحدد عدد الأماكن المتاحة، ثم يعرض الـ Bookmarks المخزنة.

## تهيئة الحالة

```python
bookmarks = []

maximum_bookmarks = 5
```

الـ List تبدأ فارغة، والعداد 5 يمثل عدد المواقع المتبقية، مش عدد المواقع المضافة.

## إضافة المواقع داخل `while`

```python
while maximum_bookmarks > 0:
    website = input("Enter Website Without https://: ").strip().lower()

    bookmarks.append(f"https://{website}")

    maximum_bookmarks -= 1

    print(f"Website Added, {maximum_bookmarks} Places Left")

else:
    print("Bookmarks List Is Full")
```

كل دورة تنظف الإدخال، تضيف Prefix `https://`، تخزن الرابط، ثم تقلل المكان المتبقي. عندما يصل العداد لصفر يصبح الشرط False وتنفذ `else`.

```example-run
Enter Website Without https://: google.com
Website Added, 4 Places Left
Enter Website Without https://: github.com
Website Added, 3 Places Left
Enter Website Without https://: python.org
Website Added, 2 Places Left
Enter Website Without https://: youtube.com
Website Added, 1 Places Left
Enter Website Without https://: example.com
Website Added, 0 Places Left
Bookmarks List Is Full
```

ده Example Run؛ أسماء المواقع تتغير حسب المستخدم، لكن العداد ينقص بنفس المنطق.

## عرض المواقع المخزنة

```python
index = 0

while index < len(bookmarks):
    print(bookmarks[index])
    index += 1
```

```example-run
https://google.com
https://github.com
https://python.org
https://youtube.com
https://example.com
```

الـ Loop الثانية مستقلة: تستخدم `len(bookmarks)` الفعلية وتعرض العناصر بالترتيب الذي أضيفت به.

> [!WARNING]
> البرنامج يفترض أن المستخدم يكتب الموقع بدون `https://`. لو كتبه بالفعل، سينتج Prefix مكرر؛ Validation الروابط خطوة لاحقة.

## الصورة الذهنية السريعة

- List تخزن البيانات.
- Counter يتحكم في عدد مرات الإدخال.
- كل دورة تغيّر الاثنين: تضيف Bookmark وتقلل المكان.
- Loop ثانية تعرض ما تم تخزينه.
