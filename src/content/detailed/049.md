# 049 — Bookmark Manager

This small project collects websites from the user in a List, tracks the available slots, and displays the stored bookmarks.

## Initialize the state

```python
bookmarks = []

maximum_bookmarks = 5
```

The List starts empty, and the counter 5 represents remaining slots, not the number of sites already added.

## Add websites inside `while`

```python
while maximum_bookmarks > 0:
    website = input("Enter Website Without https://: ").strip().lower()

    bookmarks.append(f"https://{website}")

    maximum_bookmarks -= 1

    print(f"Website Added, {maximum_bookmarks} Places Left")

else:
    print("Bookmarks List Is Full")
```

Each cycle cleans the input, adds the `https://` prefix, stores the link, and decreases the remaining slots. When the counter reaches zero, the condition becomes False and `else` runs.

```example-run
Enter Website Without https://: google.com
Website Added, 4 Places Left
Enter Website Without https://: github.com
Website Added, 3 Places Left
Enter Website Without https://: python.org
Website Added, 2 Places Left
Enter Website Without https://: youtube.com
Website Added, 1 Places Left
Enter Website Without https://: example.com
Website Added, 0 Places Left
Bookmarks List Is Full
```

This is an example run; website names change with the user input, but the counter decreases by the same logic.

## Display the stored websites

```python
index = 0

while index < len(bookmarks):
    print(bookmarks[index])
    index += 1
```

```example-run
https://google.com
https://github.com
https://python.org
https://youtube.com
https://example.com
```

The second loop is independent: it uses the actual `len(bookmarks)` and displays items in the order they were added.

> [!WARNING]
> The program assumes that the user omits `https://`. If it is already included, the prefix is duplicated; URL validation is a later step.

## Quick mental model

- The List stores data.
- The counter controls how many entries are accepted.
- Each cycle changes both: it adds a bookmark and reduces the remaining space.
- A second loop displays what was stored.
