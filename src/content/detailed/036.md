# 036 — Comparison Operators

Comparison operators compare two values and return a Boolean: either `True` or `False`. They are the foundation for the conditions used later.

```python
a = 20
b = 10
```

## `==` and `!=`

```python
print(a == b)
print(a != b)
```

```output
False
True
```

`a == b` asks whether 20 equals 10, so the answer is False. `a != b` asks whether the values are different, so the answer is True.

## `>` and `<`

```python
print(a > b)
print(a < b)
```

```output
True
False
```

20 is greater than 10, so the first comparison is True. It is not less than 10, so the second is False.

## `>=` and `<=`

```python
print(a >= 20)
print(b <= 10)
```

```output
True
True
```

`>=` means “greater than **or equal to**”; equality alone is enough here. The same idea applies to `<=`: the value 10 equals the limit 10.

## Assignment versus comparison

```python
x = 10
print(x == 10)
```

```output
True
```

> [!COMPARISON]
> `=` stores a value in a variable: assignment.
> `==` compares two values and returns a Boolean: comparison.

> [!WARNING]
> Writing `if x = 10` later is a syntax error. A condition needs the comparison `x == 10`; assignment has a different purpose.

## Quick mental model

- `==` equal to
- `!=` not equal to
- `>` greater than
- `<` less than
- `>=` greater than or equal to
- `<=` less than or equal to
