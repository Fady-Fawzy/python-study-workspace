# 036 — Comparison Operators

Comparison Operators تقارن قيمتين وتُرجع Boolean: إما `True` أو `False`. هي الأساس الذي ستستخدمه الشروط لاحقًا.

```python
a = 20
b = 10
```

## `==` و`!=`

```python
print(a == b)
print(a != b)
```

```output
False
True
```

`a == b` تسأل هل 20 تساوي 10، والإجابة False. `a != b` تسأل هل القيمتان مختلفتان، والإجابة True.

## `>` و`<`

```python
print(a > b)
print(a < b)
```

```output
True
False
```

20 أكبر من 10، لذلك المقارنة الأولى True. وليست أصغر منها، لذلك الثانية False.

## `>=` و`<=`

```python
print(a >= 20)
print(b <= 10)
```

```output
True
True
```

`>=` تعني "أكبر من **أو يساوي**"؛ المساواة وحدها كافية هنا. ونفس الفكرة مع `<=`: القيمة 10 تساوي الحد 10.

## Assignment مقابل Comparison

```python
x = 10
print(x == 10)
```

```output
True
```

> [!COMPARISON]
> `=` يحفظ قيمة في متغير: Assignment.
> `==` يقارن قيمتين ويُرجع Boolean: Comparison.

> [!WARNING]
> كتابة `if x = 10` لاحقًا خطأ Syntax؛ الشرط يحتاج مقارنة `x == 10`، بينما التعيين له مكان مختلف.

## الصورة الذهنية السريعة

- `==` يساوي
- `!=` لا يساوي
- `>` أكبر من
- `<` أصغر من
- `>=` أكبر من أو يساوي
- `<=` أصغر من أو يساوي
