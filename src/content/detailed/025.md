# 025 — Tuples And Methods Part 2

بعد ما عرفنا أن Tuple مرتبة وimmutable، نكمّل بأهم التفاصيل العملية: Tuple بعنصر واحد، دمج وتكرار الـ sequences، `count()` و`index()`، ثم توزيع قيم Tuple على متغيرات باستخدام **unpacking**.

## Tuple بعنصر واحد — الفاصلة هي الأساس

الأقواس وحدها لا تصنع **single-item Tuple**. التعبير `("Python")` مجرد String داخل أقواس تنظيمية، أما `("Python",)` فهو Tuple لأن الفاصلة موجودة.

```python
not_a_tuple = ("Python")
tuple_one = ("Python",)
tuple_two = "Python",

print(type(not_a_tuple))
print(tuple_one)
print(tuple_two)
print(type(tuple_one))
print(type(tuple_two))
print(len(tuple_one))
```

```output
<class 'str'>
('Python',)
('Python',)
<class 'tuple'>
<class 'tuple'>
1
```

`not_a_tuple` نوعها `str` لأن الأقواس لم تغيّر نوع القيمة. في `tuple_one` و`tuple_two` الفاصلة أخبرت Python أن البنية Tuple، و`len(tuple_one)` أكدت أن بداخلها عنصرًا واحدًا.

> [!WARNING]
> نسيان الفاصلة هو الخطأ الأشهر هنا: `("Python")` ليست one-item Tuple. اكتب `("Python",)`، أو `"Python",` لو السياق واضح.

> [!MENTAL-MODEL]
> في Tuple بعنصر واحد، الأقواس للوضوح؛ **الفاصلة للنوع**.

## Concatenation — دمج Tuples

المعامل `+` يدمج Tuple مع Tuple أخرى وينشئ Tuple جديدة تحتوي العناصر بالترتيب.

```python
a = (1, 2, 3)
b = (4, 5)

c = a + b

print(c)
```

```output
(1, 2, 3, 4, 5)
```

Python أخذت عناصر `a` أولًا ثم عناصر `b`. لم تعدّل أيًا من الأصلين؛ أنشأت Object جديدًا وأسندته إلى `c`، وهذا متوافق مع Immutability الخاصة بالـ Tuple.

> [!IMPORTANT]
> Immutability لا تمنعك من تكوين Tuple جديدة من Tuples قديمة. هي تمنع تعديل الخانات داخل نفس الـ Tuple الموجودة.

## Repeat — تكرار Sequence باستخدام `*`

المعامل `*` مع String أو List أو Tuple يكرر الـ sequence بالعدد المطلوب.

```python
my_string = "Python "
my_list = [1, 2]
my_tuple = ("A", "B")

print(my_string * 3)
print(my_list * 3)
print(my_tuple * 3)
```

```output
Python Python Python
[1, 2, 1, 2, 1, 2]
('A', 'B', 'A', 'B', 'A', 'B')
```

الـ String تكررت ثلاث مرات، والمسافة الموجودة داخل `"Python "` فصلت الكلمات ويوجد بعدها فراغ أخير قبل سطر الطباعة الجديد. عناصر الـ List وعناصر الـ Tuple تكررت بنفس ترتيبها ثلاث دورات.

> [!COMPARISON]
> فكرة `sequence * 3` واحدة في الأنواع الثلاثة: كرر المحتوى. نوع الناتج يظل مطابقًا لنوع الـ sequence: String تنتج String، وList تنتج List، وTuple تنتج Tuple.

## `count()` — عدد مرات ظهور القيمة

الـ `count(value)` في Tuple ترجع عدد القيم المطابقة، بنفس الفكرة التي عرفناها مع List.

```python
numbers = (1, 3, 7, 8, 2, 8, 8)

print(numbers.count(8))
```

```output
3
```

الرقم `8` ظهر ثلاث مرات، لذلك القيمة المرجعة هي `3`. الـ Tuple نفسها لم تتغير.

## `index()` — موقع أول تطابق

الـ `index(value)` ترجع Index أول قيمة مطابقة، والعد يبدأ من الصفر.

```python
numbers = (10, 20, 30, 40)

print(numbers.index(30))
```

```output
2
```

القيمة `30` هي العنصر الثالث في العرض، لكن مواقع Python هي `0`, `1`, `2`, `3`، لذلك Index الخاص بها هو `2`.

> [!IMPORTANT]
> مثل `list.index()`، لو القيمة غير موجودة سترفع `tuple.index()` خطأ `ValueError`.

## Tuple Unpacking — توزيع القيم على متغيرات

الـ **unpacking** أو destructuring تسمح بتوزيع عناصر Tuple على متغيرات منفصلة في سطر واحد.

```python
person = ("Ahmed", 25, "Egypt")

name, age, country = person

print(name)
print(age)
print(country)
```

```output
Ahmed
25
Egypt
```

التوزيع يتم حسب الترتيب:

| المتغير | القيمة المستلمة |
| --- | --- |
| `name` | `"Ahmed"` |
| `age` | `25` |
| `country` | `"Egypt"` |

كل متغير أخذ القيمة الموجودة في الموقع المقابل له. في الـ unpacking العادي يجب أن يطابق عدد المتغيرات عدد القيم.

```python
name, age = person
```

```error
ValueError: too many values to unpack (expected 2)
```

الـ Tuple تحتوي ثلاث قيم، بينما الطرف الأيسر جهّز متغيرين فقط، لذلك لا تعرف Python أين تضع القيمة الثالثة.

## تجاهل قيمة بالاسم `_`

لو استلمنا قيمة ولا نحتاج استخدامها هنا، من المعتاد تسمية المتغير `_`.

```python
person = ("Ahmed", 25, "Egypt")

name, _, country = person

print(name)
print(country)
```

```output
Ahmed
Egypt
```

القيمة `25` وصلت فعلًا إلى `_`، لكن الاسم يخبر القارئ: «استلمت هذه القيمة، ولا أهتم باستخدامها هنا».

> [!IMPORTANT]
> `_` مجرد convention وليس كلمة محجوزة. تقنيًا هو **valid variable name** وتقدر تقرأ قيمته، لكن الأفضل احترام المعنى المتعارف عليه وعدم الاعتماد عليه عندما تقصد تجاهل القيمة.

## الصورة الذهنية النهائية

| الفكرة | معناها |
| --- | --- |
| `("Python",)` | Tuple بعنصر واحد؛ الفاصلة مطلوبة |
| `a + b` | Tuple جديدة مدمجة |
| `data * 3` | تكرار الـ sequence |
| `count(value)` | عدد مرات الظهور |
| `index(value)` | موقع أول ظهور |
| `a, b, c = tuple_data` | Unpacking بالترتيب |
| `_` | متغير صالح يُستخدم اصطلاحيًا لقيمة غير مهمة |

> [!COMPARISON]
> List وTuple تدعمان الترتيب والـ Indexing و`count()` و`index()`. لكن العمليات على Tuple مثل `+` و`*` تنشئ Tuple جديدة؛ لا توجد item assignment لأن Tuple immutable.
