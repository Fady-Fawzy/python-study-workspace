# 068 — Files Handling Part 4 — Important Information

File object تحتفظ بموضع حالي اسمه Cursor. `tell()` تقرأ الموضع، و`seek()` تحركه، بينما `truncate()` تغيّر حجم الملف و`os.remove()` تحذف الملف نفسه.

## `tell()` — أين الـ Cursor؟

```python
file = open("data.txt", "r")

print(file.tell())
```

```output
0
```

عند فتح Text file للقراءة، الموضع الأولي في البداية، لذلك `tell()` ترجع 0.

## `seek()` — حرّك موضع القراءة

بافتراض ملف ASCII يحتوي `Hello Python`:

```python
file = open("data.txt", "r")

file.seek(5)

print(file.read())
```

```example-output
 Python
```

المواضع من 0 إلى 4 هي حروف `Hello`. الموضع 5 عند المسافة، لذلك `read()` بدأت منها حتى النهاية.

> [!IMPORTANT]
> في Text mode ومع Encoding متعدد البايتات، قيم الـ Cursor ليست دائمًا "رقم حرف" بسيط. المثال واضح لأنه ASCII؛ لا تعمم الحساب اليدوي على كل Unicode file.

## `truncate()` — غيّر حجم الملف

لو `data.txt` يحتوي `Hello Python`:

```python
file = open("data.txt", "a")

file.truncate(10)

file.close()
```

```example-output
Contents of data.txt:
Hello Pyth
```

تم تقصير الملف إلى 10 bytes في هذا المثال ASCII، فضاع ما بعد الحد. العملية تغيّر البيانات فعليًا.

## حذف ملف باستخدام `os.remove()`

```python
import os

os.remove("data.txt")
```

```example-output
Filesystem effect:
data.txt no longer exists
```

لا يوجد Console output ناجح تلقائيًا؛ الأثر هو حذف الملف. لو المسار غير موجود، يحدث `FileNotFoundError`.

> [!WARNING]
> `truncate()` و`os.remove()` عمليتان Destructive. تأكد من المسار، وأغلق الملف، ولا تجرب على بيانات مهمة بلا نسخة احتياطية.

## الصورة الذهنية السريعة

- `tell()` = أخبرني بموقعي.
- `seek(position)` = انقلني لموضع.
- `truncate(size)` = غيّر طول الملف.
- `os.remove(path)` = احذف الملف من النظام.
