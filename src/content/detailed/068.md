# 068 — Files Handling Part 4 — Important Information

A file object keeps a current position called the cursor. `tell()` reads the position, `seek()` moves it, `truncate()` changes file size, and `os.remove()` deletes the file itself.

## `tell()` — where is the cursor?

```python
file = open("data.txt", "r")

print(file.tell())
```

```output
0
```

When a text file is opened for reading, the initial position is the beginning, so `tell()` returns 0.

## `seek()` — move the reading position

Assume an ASCII file containing `Hello Python`:

```python
file = open("data.txt", "r")

file.seek(5)

print(file.read())
```

```example-output
 Python
```

Positions 0 through 4 are the letters in `Hello`. Position 5 is the space, so `read()` starts there and continues to the end.

> [!IMPORTANT]
> In text mode with a multibyte encoding, cursor values are not always a simple “character number.” This example is clear because it is ASCII; do not generalize the manual count to every Unicode file.

## `truncate()` — change file size

If `data.txt` contains `Hello Python`:

```python
file = open("data.txt", "a")

file.truncate(10)

file.close()
```

```example-output
Contents of data.txt:
Hello Pyth
```

The file is shortened to 10 bytes in this ASCII example, so everything after the limit is lost. The operation changes data permanently.

## Delete a file with `os.remove()`

```python
import os

os.remove("data.txt")
```

```example-output
Filesystem effect:
data.txt no longer exists
```

There is no successful console output automatically; the effect is that the file is deleted. If the path is missing, `FileNotFoundError` occurs.

> [!WARNING]
> `truncate()` and `os.remove()` are destructive operations. Verify the path, close the file, and do not try them on important data without a backup.

## Quick mental model

- `tell()` = tell me my position.
- `seek(position)` = move me to a position.
- `truncate(size)` = change the file length.
- `os.remove(path)` = delete the file from the system.
