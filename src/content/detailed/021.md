# 021 — Lists

A **List** is an ordered collection of values written inside square brackets `[]`. The core mental model is **List = ordered, mutable sequence**: items have a stable order that we can access by index, and the contents can be changed after creation.

```python
my_list = ["Python", "HTML", "Python", 10, 50.5, True]

print(my_list)
```

```output
['Python', 'HTML', 'Python', 10, 50.5, True]
```

Python preserves the order in which we wrote the items. The value `"Python"` may appear more than once, and one List can contain different types such as `str`, `int`, `float`, and `bool`.

## Core List properties

- **Ordered:** every item has a position, and insertion order is preserved.
- **Mutable:** an item or part of the List can be changed after creation.
- **Duplicates allowed:** the same value can appear more than once.
- **Mixed types:** values of different types can be stored together, although similar types are often clearer in real applications.

> [!MENTAL-MODEL]
> Think of a List as a row of slots. Each slot has an index, and its content can be changed without creating a completely new List.

## Positive and negative indexes

Positive indexes start at `0` for the first item. Negative indexes start at `-1` for the last item and move backward.

| Direction | Python | HTML | Python | 10 | 50.5 | True |
| --- | --- | --- | --- | --- | --- | --- |
| Positive index | `0` | `1` | `2` | `3` | `4` | `5` |
| Negative index | `-6` | `-5` | `-4` | `-3` | `-2` | `-1` |

```python
print(my_list[1])
print(my_list[-1])
print(my_list[-3])
```

```output
HTML
True
10
```

`my_list[1]` returns the second item because counting starts at zero. `my_list[-1]` returns the last item directly, which is `True`. `my_list[-3]` returns the third item from the end, which is `10`.

> [!WARNING]
> If you request an index that does not exist—such as `my_list[20]` in a List of length 6—Python raises `IndexError: list index out of range`.

## Slicing: taking part of a List

A slice uses the form `list[start:stop]`. `start` **is included** in the result, while `stop` **is excluded**.

```python
print(my_list[1:4])
print(my_list[:4])
print(my_list[1:])
```

```output
['HTML', 'Python', 10]
['Python', 'HTML', 'Python', 10]
['HTML', 'Python', 10, 50.5, True]
```

For `my_list[1:4]`, Python starts at index `1`, takes indexes `1`, `2`, and `3`, and stops before `4`. `my_list[:4]` means start at the beginning, while `my_list[1:]` means continue from index `1` to the end.

> [!IMPORTANT]
> Remember the slice rule: the start is included and the stop is not. Therefore, `1:4` does not include the item at index `4`.

## The step in a slice

The full form is `list[start:stop:step]`. The `step` value controls the jump between one selected item and the next.

```python
print(my_list[::1])
print(my_list[::2])
```

```output
['Python', 'HTML', 'Python', 10, 50.5, True]
['Python', 'Python', 50.5]
```

`my_list[::1]` walks from start to finish one item at a time, so it selects every item. `my_list[::2]` takes every other item: index `0`, then `2`, then `4`.

## Updating one item: mutability

Because a List is **mutable**, we can select a slot by index and assign a new value to it.

```python
my_list[1] = "CSS"
my_list[-1] = False

print(my_list)
```

```output
['Python', 'CSS', 'Python', 10, 50.5, False]
```

The first line changes the value at index `1` from `"HTML"` to `"CSS"`. The second uses `-1` to reach the last item and changes `True` to `False`. The other items stay unchanged.

## Replacing a complete slice

We can use a slice on the left side of `=` to replace several items at once.

```python
my_list[0:2] = ["JavaScript", "PHP"]

print(my_list)
```

```output
['JavaScript', 'PHP', 'Python', 10, 50.5, False]
```

The slice `0:2` refers to the items at indexes `0` and `1`. Python removes those two items and puts `"JavaScript"` and `"PHP"` in their place, while the part from index `2` to the end stays the same.

> [!COMPARISON]
> `my_list[1] = "CSS"` replaces **one item** with one value. `my_list[0:2] = ["JavaScript", "PHP"]` replaces **a range of items** with items from a new sequence.

## Common mistakes and review picture

- Counting starts at `0`, not at `1`.
- The last item is `-1`, not negative `0`.
- The `stop` value in a slice is excluded.
- Element assignment handles one slot, while slice assignment handles a range.

> [!MENTAL-MODEL]
> An index selects one slot, a slice selects a range, and a step controls the jump. Because a List is mutable, the same addressing ideas can update one slot or replace a range.
