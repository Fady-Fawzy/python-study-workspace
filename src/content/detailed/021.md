# 021 — Lists

الـ **List** هي مجموعة قيم مرتبة داخل أقواس مربعة `[]`. الصورة الذهنية الأساسية هي: **List = ordered, mutable sequence**؛ يعني العناصر لها ترتيب ثابت نقدر نوصل له بالـ Index، ونقدر نعدّل محتوى الـ List بعد إنشائها.

```python
my_list = ["Python", "HTML", "Python", 10, 50.5, True]

print(my_list)
```

```output
['Python', 'HTML', 'Python', 10, 50.5, True]
```

Python حافظت على ترتيب العناصر كما كتبناه. تكرار القيمة `"Python"` مسموح، وكمان الـ List الواحدة ممكن تحتوي أنواعًا مختلفة مثل `str` و`int` و`float` و`bool`.

## خصائص الـ List الأساسية

- **Ordered:** كل عنصر له مكان محدد، وترتيب الإدخال محفوظ.
- **Mutable:** نقدر نغيّر عنصرًا أو جزءًا من الـ List بعد إنشائها.
- **Duplicates allowed:** نفس القيمة ممكن تتكرر أكثر من مرة.
- **Mixed types:** ممكن تجمع قيمًا من أنواع مختلفة، رغم إن استخدام نوع متقارب يكون أوضح في تطبيقات كثيرة.

> [!MENTAL-MODEL]
> تخيّل الـ List كصف من الخانات. كل خانة لها رقم Index، ومحتوى الخانة قابل للتغيير من غير ما نحتاج ننشئ List جديدة بالكامل.

## الـ Index والـ Negative Index

الـ Index الموجب يبدأ من `0` عند أول عنصر. والـ Negative Index يبدأ من `-1` عند آخر عنصر ويتحرك للخلف.

| الاتجاه | Python | HTML | Python | 10 | 50.5 | True |
| --- | --- | --- | --- | --- | --- | --- |
| Positive Index | `0` | `1` | `2` | `3` | `4` | `5` |
| Negative Index | `-6` | `-5` | `-4` | `-3` | `-2` | `-1` |

```python
print(my_list[1])
print(my_list[-1])
print(my_list[-3])
```

```output
HTML
True
10
```

`my_list[1]` ترجع العنصر الثاني لأن العد بدأ من الصفر. `my_list[-1]` ترجع آخر عنصر مباشرة، وهو `True`. أما `my_list[-3]` فترجع ثالث عنصر من النهاية، وهو `10`.

> [!WARNING]
> لو طلبت Index غير موجود—مثل `my_list[20]` في List طولها 6—Python سترفع `IndexError: list index out of range`.

## الـ Slicing: أخذ جزء من الـ List

الـ Slice تكتب بالصورة `list[start:stop]`. الـ `start` **مشمول** في النتيجة، لكن الـ `stop` **غير مشمول**.

```python
print(my_list[1:4])
print(my_list[:4])
print(my_list[1:])
```

```output
['HTML', 'Python', 10]
['Python', 'HTML', 'Python', 10]
['HTML', 'Python', 10, 50.5, True]
```

في `my_list[1:4]` تبدأ Python من Index `1` وتأخذ العناصر عند `1` و`2` و`3`، ثم تتوقف قبل `4`. كتابة `my_list[:4]` تعني ابدأ من أول الـ List، و`my_list[1:]` تعني استمر من Index `1` حتى النهاية.

> [!IMPORTANT]
> تذكّر قاعدة الـ Slice: البداية تدخل، والنهاية لا تدخل. لذلك `1:4` لا تشمل العنصر الموجود عند Index `4`.

## الـ Step داخل الـ Slice

الصيغة الكاملة هي `list[start:stop:step]`. قيمة الـ `step` تحدد مقدار القفزة بين كل عنصر والعنصر التالي.

```python
print(my_list[::1])
print(my_list[::2])
```

```output
['Python', 'HTML', 'Python', 10, 50.5, True]
['Python', 'Python', 50.5]
```

`my_list[::1]` تبدأ من البداية للنهاية بقفزة واحدة، فتأخذ كل العناصر. أما `my_list[::2]` فتأخذ عنصرًا وتترك الذي بعده: Index `0` ثم `2` ثم `4`.

## تعديل عنصر واحد — Mutability

لأن الـ List **mutable**، نقدر نختار خانة بالـ Index ونضع فيها قيمة جديدة.

```python
my_list[1] = "CSS"
my_list[-1] = False

print(my_list)
```

```output
['Python', 'CSS', 'Python', 10, 50.5, False]
```

السطر الأول استبدل القيمة عند Index `1` من `"HTML"` إلى `"CSS"`. والسطر الثاني استخدم `-1` للوصول إلى آخر عنصر واستبدل `True` بـ`False`. باقي العناصر لم تتغير.

## استبدال Slice كاملة

نقدر نستخدم Slice في الطرف الأيسر من `=` لاستبدال مجموعة عناصر دفعة واحدة.

```python
my_list[0:2] = ["JavaScript", "PHP"]

print(my_list)
```

```output
['JavaScript', 'PHP', 'Python', 10, 50.5, False]
```

الـ Slice `0:2` تشير إلى العنصرين عند Index `0` و`1`. Python أزالت هذين العنصرين ووضعت مكانهما `"JavaScript"` و`"PHP"`، بينما ظل الجزء من Index `2` إلى النهاية كما هو.

> [!COMPARISON]
> `my_list[1] = "CSS"` يستبدل **عنصرًا واحدًا** بقيمة واحدة. أما `my_list[0:2] = ["JavaScript", "PHP"]` فيستبدل **نطاقًا من العناصر** بعناصر مأخوذة من sequence جديدة.

## أخطاء شائعة وصورة المراجعة

- العد يبدأ من `0`، وليس من `1`.
- آخر عنصر هو `-1`، وليس `0` من الناحية السالبة.
- قيمة `stop` في الـ Slice غير مشمولة.
- Element assignment يتعامل مع خانة واحدة، بينما Slice assignment يتعامل مع نطاق.

> [!MENTAL-MODEL]
> Index يجيب خانة واحدة، وSlice يجيب نطاقًا، وStep يحدد القفزة. ولأن الـ List mutable، تقدر تستخدم نفس العناوين لتعديل خانة أو استبدال نطاق.
