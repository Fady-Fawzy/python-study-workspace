# 052 — For Loop Trainings

These exercises combine `for` with conditions and modulus to classify items and perform an action for each value.

## Even or odd

```python
numbers = [1, 2, 3, 4, 5, 6]

for number in numbers:
    if number % 2 == 0:
        print(f"{number} Is Even")
    else:
        print(f"{number} Is Odd")
```

```output
1 Is Odd
2 Is Even
3 Is Odd
4 Is Even
5 Is Odd
6 Is Even
```

The remainder when an even number is divided by 2 is zero. If `number % 2 == 0`, it is even; otherwise it is odd.

## A message for each friend

```python
friends = ["Ahmed", "Mohamed", "Ali", "Omar"]

for friend in friends:
    print(f"Hello {friend}")
```

```output
Hello Ahmed
Hello Mohamed
Hello Ali
Hello Omar
```

The same message template is applied to every item, and `friend` changes automatically on each cycle.

## Numbers divisible by 5

```python
numbers = [10, 15, 20, 25, 30]

for number in numbers:
    if number % 5 == 0:
        print(number)

else:
    print("Loop Finished Successfully")
```

```output
10
15
20
25
30
Loop Finished Successfully
```

Every number has a remainder of zero when divided by 5, so all are printed. `else` is aligned with `for`, not `if`, so it runs once after the loop completes, not after each number.

> [!WARNING]
> Indentation determines which statement owns `else`. If it were aligned with `if`, it would mean something different.

## Quick mental model

`for` brings the value, and `if` decides what to do with it. Modulus is a powerful classification tool for divisibility.
