# 024 — Tuples And Methods Part 1

الـ **Tuple** تشبه الـ List في الترتيب والـ Indexing، لكن الفرق المحوري أنها غير قابلة للتعديل بعد إنشائها. الصورة الذهنية الأساسية هي: **Tuple = ordered, immutable sequence**.

## إنشاء Tuple ودور الفاصلة

يمكن كتابة Tuple بأقواس دائرية، أو من غير أقواس في سياقات واضحة. الفاصلة هي التي تجمع القيم في Tuple، بينما الأقواس غالبًا تجعل القراءة أوضح.

```python
tuple_one = ("Ahmed", "Mohamed")
tuple_two = "Ahmed", "Mohamed"

print(tuple_one)
print(tuple_two)

print(type(tuple_one))
print(type(tuple_two))
```

```output
('Ahmed', 'Mohamed')
('Ahmed', 'Mohamed')
<class 'tuple'>
<class 'tuple'>
```

رغم اختلاف طريقة الكتابة، المتغيران يحملان نفس النوع. ظهور الأقواس في الـ Output هو تمثيل Python للـ Tuple.

> [!IMPORTANT]
> في `tuple_two = "Ahmed", "Mohamed"` الفاصلة هي العنصر الأساسي الذي كوّن الـ Tuple. الأقواس مستحسنة للوضوح، لكنها ليست المطلوبة في كل حالة.

## خصائص الـ Tuple الأساسية

- **Ordered:** ترتيب القيم محفوظ.
- **Indexed:** نقدر نصل إلى عنصر باستخدام Index موجب أو سالب.
- **Duplicates allowed:** القيم المكررة مسموحة.
- **Mixed values:** ممكن تحتوي أنواعًا مختلفة.
- **Immutable:** لا يمكن استبدال عنصر أو تعديله داخل نفس الـ Tuple.

> [!MENTAL-MODEL]
> تخيّل Tuple كسجل ثابت: تقدر تقرأ خاناته بالترتيب، لكن لا تقدر تمسح خانة وتكتب مكانها قيمة جديدة.

## الـ Index والـ Negative Index

الـ Index الموجب يبدأ من `0`، والـ Negative Index يبدأ من `-1` عند النهاية، بنفس الفكرة التي استخدمناها مع List.

```python
numbers = (1, 2, 3, 4, 5)

print(numbers[0])
print(numbers[-1])
print(numbers[-3])
```

```output
1
5
3
```

`numbers[0]` ترجع أول عنصر. `numbers[-1]` ترجع آخر عنصر، و`numbers[-3]` تعد ثلاث خانات من النهاية فتصل إلى الرقم `3`.

## القيم المختلطة والتكرار

Tuple يمكن أن تحتوي Strings وأرقامًا وBoolean، ويمكن أن تتكرر نفس القيمة.

```python
mixed = ("Python", "Python", 1, 20.5, True)

print(mixed[1])
print(mixed[-1])
```

```output
Python
True
```

القيمة `"Python"` تكررت مرتين بلا مشكلة. الـ Index `1` وصل إلى النسخة الثانية، والـ Index `-1` وصل إلى `True` في النهاية.

## Immutability — لماذا التعديل يفشل؟

لو حاولنا إسناد قيمة جديدة إلى عنصر داخل Tuple، العملية غير مسموحة:

```python
numbers = (1, 2, 3)

numbers[1] = 100
```

```error
TypeError: 'tuple' object does not support item assignment
```

الرسالة توضح أن Tuple لا تدعم **item assignment**. Python تعرف مكان العنصر عند Index `1`، لكنها ترفض تغيير محتواه لأن بنية Tuple immutable.

> [!WARNING]
> نجاح `numbers[1]` في قراءة العنصر لا يعني أن `numbers[1] = 100` مسموحة. الـ Indexing متاح للقراءة، لكن الإسناد لعنصر غير متاح.

## متى تكون Immutability مفيدة؟

- لما تمثل مجموعة ثابتة لا يُفترض تغييرها بالخطأ.
- لما تريد توصيل معنى أن هذه القيم تنتمي معًا وتبقى كما هي.
- لما تمرر بيانات وتريد تقليل احتمالات تعديل ترتيبها أو عناصرها دون قصد.

المقصود ليس أن Tuple «أفضل» دائمًا؛ هي تعبّر عن نية مختلفة: بيانات مرتبة لكن ثابتة.

> [!COMPARISON]
> كل من List وTuple ordered، يدعمان Indexing، يسمحان بالتكرار وبأنواع مختلطة. الـ List تكتب غالبًا بـ`[]` وهي mutable، بينما Tuple تكتب غالبًا بـ`()` وهي immutable.

## List أم Tuple؟

| لو البيانات... | الاختيار الأقرب |
| --- | --- |
| ستُضاف أو تُحذف أو تُعدّل | `List` |
| تمثل مجموعة ثابتة مترابطة | `Tuple` |

> [!MENTAL-MODEL]
> List مثل ورقة عمل قابلة للتعديل. Tuple مثل سجل ثابت للقراءة: الترتيب موجود والـ Index موجود، لكن الخانات لا تقبل item assignment.
