# 024 — Tuples And Methods Part 1

A **Tuple** is like a List in that it is ordered and indexed, but its defining difference is that it cannot be changed after creation. The core mental model is **Tuple = ordered, immutable sequence**.

## Creating a Tuple and the role of the comma

A Tuple can be written with parentheses, or without them when the context is clear. The comma creates the Tuple structure; parentheses mainly make the grouping easier to read.

```python
tuple_one = ("Ahmed", "Mohamed")
tuple_two = "Ahmed", "Mohamed"

print(tuple_one)
print(tuple_two)

print(type(tuple_one))
print(type(tuple_two))
```

```output
('Ahmed', 'Mohamed')
('Ahmed', 'Mohamed')
<class 'tuple'>
<class 'tuple'>
```

Although the syntax looks different, both variables hold the same type. The parentheses in the output are Python's representation of a Tuple.

> [!IMPORTANT]
> In `tuple_two = "Ahmed", "Mohamed"`, the comma is what creates the Tuple. Parentheses are recommended for clarity, but they are not required in every context.

## Core Tuple properties

- **Ordered:** value order is preserved.
- **Indexed:** items can be reached with positive or negative indexes.
- **Duplicates allowed:** repeated values are allowed.
- **Mixed values:** different types can be stored together.
- **Immutable:** an item cannot be replaced or changed inside the same Tuple.

> [!MENTAL-MODEL]
> Think of a Tuple as a fixed record: you can read its slots in order, but you cannot erase a slot and write a new value into it.

## Positive and negative indexes

Positive indexes start at `0`, while negative indexes start at `-1` at the end, just as they do with Lists.

```python
numbers = (1, 2, 3, 4, 5)

print(numbers[0])
print(numbers[-1])
print(numbers[-3])
```

```output
1
5
3
```

`numbers[0]` returns the first item. `numbers[-1]` returns the last item, and `numbers[-3]` counts three slots from the end to reach `3`.

## Mixed values and duplicates

A Tuple can contain Strings, numbers, and Booleans, and the same value may be repeated.

```python
mixed = ("Python", "Python", 1, 20.5, True)

print(mixed[1])
print(mixed[-1])
```

```output
Python
True
```

The value `"Python"` appears twice without a problem. Index `1` reaches the second copy, and index `-1` reaches the final `True`.

## Immutability: why assignment fails

If we try to assign a new value to an item inside a Tuple, the operation is not allowed:

```python
numbers = (1, 2, 3)

numbers[1] = 100
```

```error
TypeError: 'tuple' object does not support item assignment
```

The message explains that a Tuple does not support **item assignment**. Python knows the item's position at index `1`, but refuses to change its content because the Tuple structure is immutable.

> [!WARNING]
> Being able to read `numbers[1]` does not mean that `numbers[1] = 100` is allowed. Indexing is available for reading, but item assignment is not.

## When is immutability useful?

- When you represent a fixed group that should not be changed accidentally.
- When you want to communicate that these values belong together and should stay fixed.
- When passing data and you want to reduce accidental changes to its order or items.

This does not mean a Tuple is always “better”; it expresses a different intention: ordered but fixed data.

> [!COMPARISON]
> Both Lists and Tuples are ordered, support indexing, and allow duplicates and mixed types. Lists are usually written with `[]` and are mutable; Tuples are usually written with `()` and are immutable.

## List or Tuple?

| If the data... | The closer choice |
| --- | --- |
| will be added, removed, or edited | `List` |
| represents a fixed related group | `Tuple` |

> [!MENTAL-MODEL]
> A List is like an editable worksheet. A Tuple is like a fixed read-only record: it has order and indexes, but its slots do not accept item assignment.
