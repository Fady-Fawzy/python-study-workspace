# 040 — Practical Your Age In Full Details

This example converts age in years into estimates in smaller time units. The goal is practical practice with `input()`, type conversion, arithmetic, and variables.

## Read the age as a number

```python
age = int(input("Enter Your Age: "))
```

`input()` returns a String, and `int()` converts it to an Integer so we can multiply it by numbers.

## Calculate months, weeks, and days

```python
months = age * 12
weeks = months * 4
days = age * 365
```

- Each year is counted as 12 months.
- Each month is estimated here as four weeks.
- Each year is estimated as 365 days.

These are educational estimates; month lengths and leap years make a real calendar age more precise than these simple formulas.

## Convert to hours, minutes, and seconds

```python
hours = days * 24
minutes = hours * 60
seconds = minutes * 60
```

Each value depends on the previous one: a day has 24 hours, an hour has 60 minutes, and a minute has 60 seconds.

## Run the example for age 25

```python
age = int(input("Enter Your Age: "))

months = age * 12
weeks = months * 4
days = age * 365
hours = days * 24
minutes = hours * 60
seconds = minutes * 60

print(f"You Lived For {months} Months")
print(f"You Lived For {weeks} Weeks")
print(f"You Lived For {days} Days")
print(f"You Lived For {hours} Hours")
print(f"You Lived For {minutes} Minutes")
print(f"You Lived For {seconds} Seconds")
```

```example-run
Enter Your Age: 25
You Lived For 300 Months
You Lived For 1200 Weeks
You Lived For 9125 Days
You Lived For 219000 Hours
You Lived For 13140000 Minutes
You Lived For 788400000 Seconds
```

For example, `months = 25 * 12 = 300`. Then `days = 25 * 365 = 9125`, and the remaining units are based on the previous result.

> [!IMPORTANT]
> Weeks are calculated here as `months * 4`, so this educational estimate equals 48 weeks per year rather than a precise calendar conversion. The important point is understanding the calculation chain.

> [!WARNING]
> If the user types a value that `int()` cannot parse, `ValueError` occurs. A negative age also produces negative numbers because this version has no validation yet.
