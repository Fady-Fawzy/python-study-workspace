# 051 — For Loop And Else

`for` تمر على عناصر Iterable واحدًا واحدًا من غير ما تدير Index أو Counter يدويًا. مناسبة عندما تريد معالجة كل عنصر في sequence أو collection.

## المرور على List

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    print(number)
```

```output
1
2
3
4
5
```

في كل دورة، المتغير `number` يأخذ العنصر التالي. بعد آخر عنصر تنتهي Loop تلقائيًا.

## المرور على String

```python
name = "Python"

for letter in name:
    print(letter)
```

```output
P
y
t
h
o
n
```

الـ String iterable من Characters، لذلك `letter` أخذ حرفًا واحدًا في كل دورة.

## `for` مع `else`

```python
numbers = [1, 2, 3, 4]

for number in numbers:
    print(number)

else:
    print("Loop Finished")
```

```output
1
2
3
4
Loop Finished
```

`else` تنفذ عند اكتمال المرور طبيعيًا. لو خرجت بـ `break`، لا تنفذ.

> [!COMPARISON]
> `while` تعتمد على Condition وتحتاج تحديث الحالة يدويًا.
> `for` تأخذ العناصر مباشرة من Iterable وتنتقل تلقائيًا للعنصر التالي.

## الصورة الذهنية السريعة

`for item in items` = لكل عنصر داخل المجموعة، ضعه مؤقتًا في `item` ونفذ الـ Block.
