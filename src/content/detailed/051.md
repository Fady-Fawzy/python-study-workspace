# 051 — For Loop And Else

`for` visits iterable items one by one without manually managing an index or counter. It is useful when you want to process every item in a sequence or collection.

## Walk through a List

```python
numbers = [1, 2, 3, 4, 5]

for number in numbers:
    print(number)
```

```output
1
2
3
4
5
```

On each cycle, `number` receives the next item. After the last item, the loop ends automatically.

## Walk through a String

```python
name = "Python"

for letter in name:
    print(letter)
```

```output
P
y
t
h
o
n
```

The String is iterable by Character, so `letter` receives one character per cycle.

## `for` with `else`

```python
numbers = [1, 2, 3, 4]

for number in numbers:
    print(number)

else:
    print("Loop Finished")
```

```output
1
2
3
4
Loop Finished
```

`else` runs when the traversal completes normally. If the loop exits with `break`, it does not run.

> [!COMPARISON]
> `while` depends on a condition and needs manual state updates.
> `for` takes items directly from an iterable and moves automatically to the next one.

## Quick mental model

`for item in items` = for each item in the collection, temporarily place it in `item` and run the block.
