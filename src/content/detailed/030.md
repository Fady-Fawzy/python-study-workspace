# 030 — Dictionary

الـ **Dictionary** بتخزّن البيانات كأزواج `key: value`. بدل ما توصل للقيمة برقم Index، توصل لها باسم الـ Key الذي يصفها.

> [!MENTAL-MODEL]
> Dictionary = جدول ربط. كل Key فريد يشاور على Value. مثال: المفتاح `"name"` يشاور على القيمة `"Ahmed"`.

## إنشاء Dictionary وقراءة شكلها

```python
user = {
    "name": "Ahmed",
    "age": 25,
    "country": "Egypt",
    "skills": ["Python", "HTML", "CSS"],
    "rating": 9.5
}

print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt', 'skills': ['Python', 'HTML', 'CSS'], 'rating': 9.5}
```

كل زوج فيه Key قبل `:` وValue بعدها. القيم ممكن تكون أنواعًا مختلفة، ومنها List كاملة في `skills`. ترتيب الإدخال محفوظ في Python الحديثة، لكن الوصول المنطقي يظل بالمفتاح وليس بالموقع.

## الوصول باستخدام `[]`

```python
print(user["name"])
print(user["country"])
```

```output
Ahmed
Egypt
```

`user["name"]` طلبت القيمة المرتبطة بالمفتاح `"name"`، فكانت `"Ahmed"`. الاقتباسات لا تظهر لأن `print()` تطبع محتوى الـ String.

لو استخدمت Key غير موجود مع `[]` ستحصل على `KeyError`، لأنك طلبت مدخلًا لا تعرفه الـ Dictionary.

## الوصول باستخدام `get()`

```python
print(user.get("name"))
print(user.get("country"))
```

```output
Ahmed
Egypt
```

`get(key)` تُرجع نفس القيم عند وجود المفتاح. الفرق المهم يظهر عند الغياب: `user.get("job")` تُرجع `None` افتراضيًا بدل `KeyError`، ويمكن إعطاؤها قيمة بديلة مثل `user.get("job", "Unknown")`.

> [!COMPARISON]
> `user[key]` مناسب لما المفتاح لازم يكون موجودًا وغيابه خطأ.
> `user.get(key)` مناسب لما غياب المفتاح حالة متوقعة وتريد Default بدل Error.

## `keys()` و`values()`

```python
print(user.keys())
print(user.values())
```

```output
dict_keys(['name', 'age', 'country', 'skills', 'rating'])
dict_values(['Ahmed', 25, 'Egypt', ['Python', 'HTML', 'CSS'], 9.5])
```

`keys()` تعرض View للمفاتيح، و`values()` تعرض القيم المقابلة بنفس ترتيب الإدخال. الناتج ليس List عادية؛ لذلك يظهر النوع `dict_keys` أو `dict_values`.

## Dictionary داخل Dictionary

لما كل عنصر له أكثر من معلومة، ممكن تكون الـ Value نفسها Dictionary:

```python
languages = {
    "one": {
        "name": "Python",
        "progress": "80%"
    },

    "two": {
        "name": "HTML",
        "progress": "90%"
    },

    "three": {
        "name": "CSS",
        "progress": "70%"
    }
}

print(languages)
```

```output
{'one': {'name': 'Python', 'progress': '80%'}, 'two': {'name': 'HTML', 'progress': '90%'}, 'three': {'name': 'CSS', 'progress': '70%'}}
```

المفاتيح الخارجية `one`, `two`, `three`، وكل واحد يرتبط بـ Dictionary داخلية فيها `name` و`progress`.

## الوصول المتدرج للبيانات المتداخلة

```python
print(languages["one"])

print(languages["one"]["name"])

print(languages["two"]["progress"])
```

```output
{'name': 'Python', 'progress': '80%'}
Python
90%
```

في `languages["one"]["name"]`، الجزء الأول رجّع الـ Dictionary الداخلية الخاصة بـ `one`، ثم `['name']` قرأت منها قيمة الاسم.

> [!IMPORTANT]
> اقرأ الوصول المتداخل خطوة خطوة من الشمال: اختر المستوى الخارجي، ثم المفتاح الداخلي. ده يقلل أخطاء الأقواس والمفاتيح.

## `len()` وعدد الأزواج

```python
print(len(user))
print(len(languages))

print(len(languages["one"]))
```

```output
5
3
2
```

- `user` فيها خمسة مفاتيح.
- `languages` فيها ثلاثة مفاتيح خارجية.
- `languages["one"]` Dictionary داخلية فيها مفتاحان: `name` و`progress`.

`len()` تحسب عدد أزواج `key: value` في المستوى الذي أعطيته لها فقط، ولا تجمع كل المستويات المتداخلة.

## قواعد المفاتيح المهمة

- الـ Key لازم يكون فريدًا؛ تكراره يستبدل القيمة القديمة بدل إنشاء مدخل ثانٍ.
- المفاتيح لازم تكون من نوع ثابت قابل للاستخدام كمفتاح، مثل String أو Number أو Tuple مناسبة.
- القيم مرنة وقد تكون List أو Dictionary أخرى.

## الصورة الذهنية السريعة

- `dictionary[key]` = هات القيمة باسم المفتاح.
- `get(key)` = هات القيمة بأمان عند احتمال الغياب.
- `keys()` = أسماء الحقول.
- `values()` = محتوى الحقول.
- الوصول المتداخل = مفتاح خارجي ثم مفتاح داخلي.
