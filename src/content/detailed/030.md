# 030 — Dictionary

A **Dictionary** stores data as `key: value` pairs. Instead of reaching a value by a numeric index, you reach it by the descriptive key name.

> [!MENTAL-MODEL]
> Dictionary = a lookup table. Each key points to a value. For example, the key `"name"` points to the value `"Ahmed"`.

## Creating a Dictionary and reading its shape

```python
user = {
    "name": "Ahmed",
    "age": 25,
    "country": "Egypt",
    "skills": ["Python", "HTML", "CSS"],
    "rating": 9.5
}

print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt', 'skills': ['Python', 'HTML', 'CSS'], 'rating': 9.5}
```

Each pair has a key before `:` and a value after it. Values can have different types, including a complete List in `skills`. Modern Python preserves insertion order, but the meaningful access method is still the key, not the position.

## Access with `[]`

```python
print(user["name"])
print(user["country"])
```

```output
Ahmed
Egypt
```

`user["name"]` requests the value linked to the key `"name"`, so it returns `"Ahmed"`. The quotes do not appear because `print()` displays the String content.

If you use a missing key with `[]`, you get `KeyError` because you requested an entry the Dictionary does not know.

## Access with `get()`

```python
print(user.get("name"))
print(user.get("country"))
```

```output
Ahmed
Egypt
```

`get(key)` returns the same values when the key exists. The important difference appears when it is missing: `user.get("job")` returns `None` by default instead of raising `KeyError`, and you can provide a fallback such as `user.get("job", "Unknown")`.

> [!COMPARISON]
> `user[key]` is appropriate when the key must exist and its absence is an error.
> `user.get(key)` is appropriate when a missing key is expected and you want a default instead of an error.

## `keys()` and `values()`

```python
print(user.keys())
print(user.values())
```

```output
dict_keys(['name', 'age', 'country', 'skills', 'rating'])
dict_values(['Ahmed', 25, 'Egypt', ['Python', 'HTML', 'CSS'], 9.5])
```

`keys()` exposes a view of the keys, and `values()` exposes the corresponding values in insertion order. The result is not an ordinary List, so its type appears as `dict_keys` or `dict_values`.

## Dictionary inside a Dictionary

When each item has more than one piece of information, the value itself can be another Dictionary:

```python
languages = {
    "one": {
        "name": "Python",
        "progress": "80%"
    },

    "two": {
        "name": "HTML",
        "progress": "90%"
    },

    "three": {
        "name": "CSS",
        "progress": "70%"
    }
}

print(languages)
```

```output
{'one': {'name': 'Python', 'progress': '80%'}, 'two': {'name': 'HTML', 'progress': '90%'}, 'three': {'name': 'CSS', 'progress': '70%'}}
```

The outer keys are `one`, `two`, and `three`; each points to an inner Dictionary containing `name` and `progress`.

## Step-by-step access to nested data

```python
print(languages["one"])

print(languages["one"]["name"])

print(languages["two"]["progress"])
```

```output
{'name': 'Python', 'progress': '80%'}
Python
90%
```

In `languages["one"]["name"]`, the first part returns the inner Dictionary for `one`, then `['name']` reads the name value from it.

> [!IMPORTANT]
> Read nested access from left to right: choose the outer level, then the inner key. This reduces bracket and key mistakes.

## `len()` and the number of pairs

```python
print(len(user))
print(len(languages))

print(len(languages["one"]))
```

```output
5
3
2
```

- `user` has five keys.
- `languages` has three outer keys.
- `languages["one"]` is an inner Dictionary with two keys: `name` and `progress`.

`len()` counts `key: value` pairs only at the level you pass to it; it does not total every nested level.

## Important key rules

- A key must be unique; repeating it replaces the old value instead of creating a second entry.
- Keys must be immutable/hashable types suitable for keys, such as a String, Number, or suitable Tuple.
- Values are flexible and may be a List or another Dictionary.

## Quick mental model

- `dictionary[key]` = get the value by key name.
- `get(key)` = get a value safely when it may be missing.
- `keys()` = field names.
- `values()` = field contents.
- Nested access = outer key, then inner key.
