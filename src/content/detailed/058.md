# 058 — Packing & Unpacking Arguments

النجمة الواحدة `*` تساعد Function تستقبل عددًا متغيرًا من Positional Arguments، أو تفك sequence جاهزة إلى Arguments منفصلة.

## Packing باستخدام `*names`

```python
def say_hello(*names):
    print(names)


say_hello("Ahmed", "Ali", "Omar")
```

```output
('Ahmed', 'Ali', 'Omar')
```

`*names` جمعت الـ Arguments الثلاث في Tuple اسمها `names`. النجمة تعني إن العدد مش لازم يكون ثابتًا.

## Loop على الـ Packed Arguments

```python
def say_hello(*names):
    for name in names:
        print(f"Hello {name}")


say_hello("Ahmed", "Ali", "Omar")
```

```output
Hello Ahmed
Hello Ali
Hello Omar
```

بعد Packing نتعامل مع `names` كأي Tuple ونمر على عناصرها.

## Unpacking باستخدام `*skills`

```python
skills = ["Python", "HTML", "CSS"]


def show_skills(skill1, skill2, skill3):
    print(skill1)
    print(skill2)
    print(skill3)


show_skills(*skills)
```

```output
Python
HTML
CSS
```

`*skills` في الاستدعاء فكّت الـ List إلى ثلاث Arguments منفصلة، فكأننا كتبنا `show_skills("Python", "HTML", "CSS")`.

> [!COMPARISON]
> نجمة في التعريف `def f(*args)` = Packing إلى Tuple.
> نجمة في الاستدعاء `f(*items)` = Unpacking لعناصر iterable كـ Positional Arguments.

> [!WARNING]
> عند Unpacking لدالة ذات Parameters ثابتة، عدد العناصر لازم يطابق العدد المتوقع، وإلا يحدث `TypeError`.

## الصورة الذهنية السريعة

`*` عند الباب تجمع الداخل، و`*` عند الاستدعاء تفك المجموعة قبل إدخالها.
