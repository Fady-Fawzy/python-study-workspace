# 058 — Packing & Unpacking Arguments

One star, `*`, lets a function receive a variable number of positional arguments, or expands a ready sequence into separate arguments.

## Packing with `*names`

```python
def say_hello(*names):
    print(names)


say_hello("Ahmed", "Ali", "Omar")
```

```output
('Ahmed', 'Ali', 'Omar')
```

`*names` packs the three arguments into a Tuple named `names`. The star means the count does not have to be fixed.

## Loop over packed arguments

```python
def say_hello(*names):
    for name in names:
        print(f"Hello {name}")


say_hello("Ahmed", "Ali", "Omar")
```

```output
Hello Ahmed
Hello Ali
Hello Omar
```

After packing, we treat `names` like any Tuple and iterate over its items.

## Unpacking with `*skills`

```python
skills = ["Python", "HTML", "CSS"]


def show_skills(skill1, skill2, skill3):
    print(skill1)
    print(skill2)
    print(skill3)


show_skills(*skills)
```

```output
Python
HTML
CSS
```

`*skills` in the call expands the List into three separate arguments, as if we had written `show_skills("Python", "HTML", "CSS")`.

> [!COMPARISON]
> A star in the definition, `def f(*args)`, means packing into a Tuple.
> A star in the call, `f(*items)`, means unpacking iterable items as positional arguments.

> [!WARNING]
> When unpacking into a function with fixed parameters, the item count must match the expected count or `TypeError` occurs.

## Quick mental model

`*` at the function boundary gathers incoming values, while `*` at the call expands a group before passing it in.
