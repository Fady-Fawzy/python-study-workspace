# 074 — Built In Functions Part 6 — Reduce

`reduce()` combines an iterable step by step into **one value**. It lives in the `functools` module, so it must be imported.

## Import `reduce`

```python
from functools import reduce
```

Unlike `map()` and `filter()`, `reduce` is not a directly available built-in name in Python 3.

## A function that combines two values

```python
numbers = [1, 2, 3, 4]


def add_numbers(num1, num2):
    return num1 + num2


result = reduce(add_numbers, numbers)

print(result)
```

```output
10
```

`reduce()` carries an accumulator from one step to the next:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
```

The result of each step becomes `num1` in the next step until one result remains.

## Reduce with a Lambda

```python
from functools import reduce

numbers = [10, 20, 30, 40]

result = reduce(
    lambda num1, num2: num1 + num2,
    numbers
)

print(result)
```

```output
100
```

The steps are 10+20=30, then 30+30=60, then 60+40=100.

## Map / Filter / Reduce

Using:

```python
numbers = [1, 2, 3, 4, 5]
```

```python
print(list(map(lambda x: x * 2, numbers)))
print(list(filter(lambda x: x > 2, numbers)))

from functools import reduce
print(reduce(lambda x, y: x + y, numbers))
```

```output
[2, 4, 6, 8, 10]
[3, 4, 5]
15
```

| Function | Data movement | Result |
|---|---|---|
| `map()` | Transform every item | Iterable of transformed items |
| `filter()` | Select accepted items | An iterable that may contain fewer items |
| `reduce()` | Combine one item after another | One value |

> [!WARNING]
> `reduce()` on an empty iterable without an initial value raises `TypeError`. For long operations, a regular loop may be clearer; choose the tool that makes the intent understandable.

## Quick mental model

- Map = one transformed output for each input.
- Filter = some items pass.
- Reduce = everything combines into one result.
