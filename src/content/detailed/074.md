# 074 — Built In Functions Part 6 — Reduce

`reduce()` تجمع Iterable تدريجيًا في **قيمة واحدة**. هي موجودة في module `functools`، لذلك تحتاج Import.

## استيراد `reduce`

```python
from functools import reduce
```

بعكس `map()` و`filter()`، `reduce` ليست اسمًا Built-in مباشرًا في Python 3.

## Function تجمع قيمتين

```python
numbers = [1, 2, 3, 4]


def add_numbers(num1, num2):
    return num1 + num2


result = reduce(add_numbers, numbers)

print(result)
```

```output
10
```

`reduce()` تحمل Accumulator بين الخطوات:

```text
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
```

ناتج كل خطوة يصبح `num1` في الخطوة التالية، حتى يتبقى ناتج واحد.

## Reduce مع Lambda

```python
from functools import reduce

numbers = [10, 20, 30, 40]

result = reduce(
    lambda num1, num2: num1 + num2,
    numbers
)

print(result)
```

```output
100
```

الخطوات هي 10+20=30، ثم 30+30=60، ثم 60+40=100.

## Map / Filter / Reduce

باستخدام:

```python
numbers = [1, 2, 3, 4, 5]
```

```python
print(list(map(lambda x: x * 2, numbers)))
print(list(filter(lambda x: x > 2, numbers)))

from functools import reduce
print(reduce(lambda x, y: x + y, numbers))
```

```output
[2, 4, 6, 8, 10]
[3, 4, 5]
15
```

| Function | حركة البيانات | الناتج |
|---|---|---|
| `map()` | تحوّل كل عنصر | Iterable من عناصر محوّلة |
| `filter()` | تختار العناصر المقبولة | Iterable بعدد قد يقل |
| `reduce()` | تدمج عنصرًا بعد عنصر | قيمة واحدة |

> [!WARNING]
> `reduce()` على Iterable فاضية من غير Initial value يرفع `TypeError`. ومع العمليات الطويلة، Loop عادية قد تكون أوضح؛ اختار الأداة التي تجعل النية مفهومة.

## الصورة الذهنية السريعة

- Map = واحد يدخل، واحد يخرج لكل عنصر.
- Filter = بعض العناصر تمر.
- Reduce = الكل يندمج في نتيجة واحدة.
