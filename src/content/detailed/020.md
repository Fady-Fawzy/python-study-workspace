# 020 — Arithmetic Operators

الـ **Arithmetic Operators** هي الرموز اللي Python بتستخدمها لتنفيذ العمليات الحسابية. في الأمثلة دي `print()` بتعرض نتيجة التعبير، لكن تركيزنا الحقيقي هو: Python حسبت النتيجة إزاي وليه النتيجة ظهرت بالشكل ده؟

## الجمع `+` — Addition

المعامل `+` بيجمع الرقم الموجود على الشمال مع الرقم الموجود على اليمين. ينفع مع الأعداد الموجبة والسالبة، ولو أحد الأرقام `float` فغالبًا النتيجة هتكون `float` برضه.

```python
print(10 + 20)
print(-10 + 30)
print(2.5 + 1.5)
```

```output
30
20
4.0
```

في السطر الأول جمعنا `10` و`20` فكانت النتيجة `30`. في السطر الثاني بدأنا من `-10` وتحركنا 30 خطوة ناحية الموجب، فوصلنا إلى `20`. وفي السطر الثالث دخلت أعداد عشرية في العملية، لذلك Python حافظت على نوع النتيجة كـ `float` وظهرت `4.0`.

## الطرح `-` — Subtraction

المعامل `-` بيطرح القيمة اللي على اليمين من القيمة اللي على الشمال. وجود رقم سالب بعد علامة الطرح محتاج انتباه؛ لأن طرح السالب يعادل إضافة قيمته الموجبة.

```python
print(50 - 20)
print(-20 - 10)
print(-20 - -10)
```

```output
30
-30
-10
```

`50 - 20` نتيجتها `30`. أما `-20 - 10` فبننزل عشر درجات إضافية من `-20` إلى `-30`. وفي `-20 - -10` إحنا بنطرح عددًا سالبًا، يعني العملية تكافئ `-20 + 10`، ولذلك النتيجة `-10`.

> [!IMPORTANT]
> في التعبير `-20 - -10` العلامة الأولى هي معامل الطرح، والعلامة الثانية جزء من العدد السالب `-10`.

## الضرب `*` وأولوية العمليات — Multiplication

المعامل `*` بيكرر قيمة الرقم الأول بعدد مرات الرقم الثاني. ولما يوجد أكثر من Operator في نفس التعبير، Python تتبع **operator precedence**: الضرب والقسمة يتم تنفيذهما قبل الجمع والطرح، إلا لو استخدمنا الأقواس.

```python
print(10 * 5)
print(5 + 10 * 20)
print((5 + 10) * 20)
```

```output
50
205
300
```

`10 * 5` تساوي `50`. في `5 + 10 * 20` تنفذ Python الضرب أولًا: `10 * 20 = 200`، ثم تضيف `5` فتكون النتيجة `205`.

في المثال الأخير الأقواس غيّرت ترتيب التقييم: Python تحسب `5 + 10 = 15` أولًا، ثم `15 * 20 = 300`.

> [!WARNING]
> قراءة التعبير من الشمال لليمين فقط ممكن تطلع نتيجة غلط. راجع أولوية العمليات، واستخدم الأقواس لما تكون عايز توضح الترتيب أو تغيّره.

## القسمة الحقيقية `/` — True Division

المعامل `/` ينفذ **True Division**، ونتيجته في Python تكون `float` حتى لو القسمة من غير كسر.

```python
print(100 / 20)
print(int(100 / 20))
```

```output
5.0
5
```

القيمة الرياضية لـ`100 / 20` هي خمسة، لكن `/` يرجعها كـ `5.0` لأن نوع النتيجة `float`. في السطر الثاني `int(...)` حوّل `5.0` إلى العدد الصحيح `5`، لذلك اختفى الجزء العشري.

> [!IMPORTANT]
> التحويل باستخدام `int()` لا يغيّر سلوك `/` نفسه؛ هو يستقبل نتيجة القسمة بعد حسابها ثم يحولها إلى `int`.

## باقي القسمة `%` — Modulus

المعامل `%` لا يرجع ناتج القسمة، بل يرجع **الباقي** بعد توزيع العدد إلى مجموعات كاملة.

```python
print(8 % 2)
print(9 % 2)
print(22 % 5)
```

```output
0
1
2
```

العدد `8` ينقسم على `2` بلا باقي، لذلك `8 % 2` تساوي `0`. عند قسمة `9` على `2` نقدر نكوّن أربع مجموعات كاملة قيمتها `8` ويتبقى `1`. وعند قسمة `22` على `5` نكوّن أربع مجموعات قيمتها `20` ويتبقى `2`.

من أشهر الاستخدامات العملية للـ Modulus فحص الزوجي والفردي: لو `number % 2` تساوي `0` فالعدد زوجي، ولو تساوي `1` لعدد موجب فالعدد فردي.

## الأس `**` — Exponentiation

المعامل `**` يرفع العدد الموجود على الشمال للقوة الموجودة على اليمين.

```python
print(2 ** 5)
print(5 ** 3)
```

```output
32
125
```

`2 ** 5` معناها:

```text
2 × 2 × 2 × 2 × 2 = 32
```

وبنفس الفكرة، `5 ** 3` معناها `5 × 5 × 5`، والنتيجة `125`. الرقم بعد `**` يحدد عدد مرات ضرب الأساس في نفسه.

## القسمة الأرضية `//` — Floor Division

المعامل `//` ينفذ القسمة ثم يرجع **أرضية الناتج**؛ أي أكبر عدد صحيح لا يتجاوز النتيجة.

```python
print(100 // 20)
print(119 // 20)
print(142 // 20)
```

```output
5
5
7
```

`100 / 20` تساوي `5` بالضبط. أما `119 / 20` فتساوي `5.95`، وأرضيتها `5`. و`142 / 20` تساوي `7.1`، وأرضيتها `7`.

> [!COMPARISON]
> `/` ترجع نتيجة القسمة الحقيقية كـ `float`، لذلك `119 / 20` تساوي `5.95`. أما `//` فترجع أرضية النتيجة، لذلك `119 // 20` تساوي `5`.

> [!IMPORTANT]
> مع الأعداد السالبة، `//` لا تكتفي بحذف الجزء العشري ناحية الصفر؛ هي تتحرك إلى الأسفل. مثلًا `-5 // 2` نتيجتها `-3` لأن `-3` هي أرضية `-2.5`.

## الصورة الذهنية النهائية

| Operator | المعنى السريع |
| --- | --- |
| `+` | Add — اجمع |
| `-` | Subtract — اطرح |
| `*` | Multiply — اضرب |
| `/` | Divide → `float` — قسمة حقيقية |
| `%` | Remainder — باقي القسمة |
| `**` | Power — الأس |
| `//` | Floor division — أرضية القسمة |

> [!MENTAL-MODEL]
> اسأل نفسك أولًا: هل أريد الناتج الكامل؟ استخدم `/`. هل أريد عدد المجموعات الصحيحة بعد النزول لأرضية الناتج؟ استخدم `//`. هل أريد فقط ما تبقى بعد تكوين المجموعات؟ استخدم `%`.
