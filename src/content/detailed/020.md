# 020 — Arithmetic Operators

**Arithmetic operators** are the symbols Python uses to perform calculations. In these examples, `print()` displays the expression result, but the real goal is to understand how Python calculated it and why the result has that form.

## Addition `+`

The `+` operator adds the value on the left to the value on the right. It works with positive and negative numbers, and when either operand is a `float`, the result is usually a `float` as well.

```python
print(10 + 20)
print(-10 + 30)
print(2.5 + 1.5)
```

```output
30
20
4.0
```

In the first line, adding `10` and `20` gives `30`. In the second, starting at `-10` and adding `30` moves to `20`. The third expression contains decimal values, so Python keeps the result as a `float` and displays `4.0`.

## Subtraction `-`

The `-` operator subtracts the right-hand value from the left-hand value. A negative number after the subtraction sign needs attention: subtracting a negative is the same as adding its positive value.

```python
print(50 - 20)
print(-20 - 10)
print(-20 - -10)
```

```output
30
-30
-10
```

`50 - 20` produces `30`. With `-20 - 10`, we move ten more units down from `-20` to `-30`. In `-20 - -10`, we subtract a negative number, which is equivalent to `-20 + 10`, so the result is `-10`.

> [!IMPORTANT]
> In `-20 - -10`, the first sign is the subtraction operator and the second sign belongs to the negative number `-10`.

## Multiplication `*` and operator precedence

The `*` operator multiplies the two values. When an expression contains more than one operator, Python follows **operator precedence**: multiplication and division are evaluated before addition and subtraction unless parentheses change the order.

```python
print(10 * 5)
print(5 + 10 * 20)
print((5 + 10) * 20)
```

```output
50
205
300
```

`10 * 5` equals `50`. In `5 + 10 * 20`, Python evaluates the multiplication first: `10 * 20 = 200`, then adds `5`, producing `205`.

In the last example, parentheses change the evaluation order: Python calculates `5 + 10 = 15` first, then `15 * 20 = 300`.

> [!WARNING]
> Reading an expression strictly from left to right can produce the wrong expectation. Check operator precedence and use parentheses when you want to make the order explicit or change it.

## True division `/`

The `/` operator performs **true division**. In Python, its result is a `float` even when the division is mathematically exact.

```python
print(100 / 20)
print(int(100 / 20))
```

```output
5.0
5
```

The mathematical value of `100 / 20` is five, but `/` returns it as `5.0` because the result type is `float`. In the second line, `int(...)` converts `5.0` to the integer `5`, so the decimal part is gone.

> [!IMPORTANT]
> Calling `int()` does not change how `/` works. It receives the already-calculated division result and converts that value to `int`.

## Modulus `%` (remainder)

The `%` operator does not return the quotient. It returns the **remainder** left after forming complete groups.

```python
print(8 % 2)
print(9 % 2)
print(22 % 5)
```

```output
0
1
2
```

`8` divides by `2` with no remainder, so `8 % 2` is `0`. When dividing `9` by `2`, we can form four complete groups totaling `8`, leaving `1`. With `22 % 5`, four groups total `20`, leaving `2`.

One common practical use of modulus is checking even and odd values: if `number % 2` is `0`, the number is even; for a positive number, a remainder of `1` means it is odd.

## Exponentiation `**`

The `**` operator raises the left-hand number to the power given on the right.

```python
print(2 ** 5)
print(5 ** 3)
```

```output
32
125
```

`2 ** 5` means:

```text
2 × 2 × 2 × 2 × 2 = 32
```

Likewise, `5 ** 3` means `5 × 5 × 5`, giving `125`. The number after `**` tells Python how many times to multiply the base by itself.

## Floor division `//`

The `//` operator divides and returns the **floor** of the result: the greatest integer that is not greater than the exact value.

```python
print(100 // 20)
print(119 // 20)
print(142 // 20)
```

```output
5
5
7
```

`100 / 20` is exactly `5`. `119 / 20` is `5.95`, whose floor is `5`. `142 / 20` is `7.1`, whose floor is `7`.

> [!COMPARISON]
> `/` returns the true division result as a `float`, so `119 / 20` is `5.95`. `//` returns the floor, so `119 // 20` is `5`.

> [!IMPORTANT]
> For negative numbers, `//` does not simply remove decimal digits toward zero; it moves downward. For example, `-5 // 2` is `-3` because `-3` is the floor of `-2.5`.

## Final mental model

| Operator | Quick meaning |
| --- | --- |
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide → `float` |
| `%` | Remainder |
| `**` | Power |
| `//` | Floor division |

> [!MENTAL-MODEL]
> Ask what you need first: use `/` for the full division result, `//` for the number of complete groups after flooring, and `%` for what remains after those groups are formed.
