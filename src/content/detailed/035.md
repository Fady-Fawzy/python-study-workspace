# 035 — Assignment Operators

Assignment Operators المختصرة تنفذ عملية باستخدام القيمة الحالية ثم تحفظ النتيجة في نفس المتغير.

## `+=` — اجمع ثم خزّن

```python
x = 10

x += 5
print(x)
```

```output
15
```

`x += 5` معناها `x = x + 5`: أخذت 10، أضافت 5، ثم حفظت 15 في `x`.

## `-=` — اطرح ثم خزّن

```python
x -= 3
print(x)
```

```output
12
```

المثال متسلسل؛ `x` كانت 15 من الخطوة السابقة، فبعد طرح 3 أصبحت 12.

## `*=` — اضرب ثم خزّن

```python
x *= 2
print(x)
```

```output
24
```

القيمة الحالية 12 ضُربت في 2.

## `/=` — اقسم ثم خزّن

```python
x /= 4
print(x)
```

```output
6.0
```

`24 / 4` تساوي 6، لكن `/` في Python ترجع Float، لذلك القيمة المحفوظة هي `6.0`.

## `%=` — احفظ باقي القسمة

```python
x %= 4
print(x)
```

```output
2.0
```

القيمة قبل العملية `6.0`، وباقي قسمة 6 على 4 هو 2. لأن `x` أصبحت Float في خطوة `/=`، يظهر الناتج `2.0`.

## الصيغة المختصرة والكاملة

```python
x += 5
```

تعبر عن نفس فكرة:

```python
x = x + 5
```

> [!WARNING]
> تتبع القيمة الحالية للمتغير. الأمثلة هنا متسلسلة، لذلك كل سطر يبدأ من نتيجة السطر السابق، وليس من `x = 10` من جديد.

## الصورة الذهنية السريعة

- `x += n` → `x = x + n`
- `x -= n` → `x = x - n`
- `x *= n` → `x = x * n`
- `x /= n` → `x = x / n`
- `x %= n` → `x = x % n`
