# 035 — Assignment Operators

Compound assignment operators perform an operation with the current value and store the result back in the same variable.

## `+=` — add, then store

```python
x = 10

x += 5
print(x)
```

```output
15
```

`x += 5` means `x = x + 5`: it takes 10, adds 5, and stores 15 in `x`.

## `-=` — subtract, then store

```python
x -= 3
print(x)
```

```output
12
```

The example is sequential: `x` was 15 from the previous step, so subtracting 3 changes it to 12.

## `*=` — multiply, then store

```python
x *= 2
print(x)
```

```output
24
```

The current value, 12, is multiplied by 2.

## `/=` — divide, then store

```python
x /= 4
print(x)
```

```output
6.0
```

`24 / 4` equals 6, but `/` returns a Float in Python, so the stored value is `6.0`.

## `%=` — store the remainder

```python
x %= 4
print(x)
```

```output
2.0
```

The value before the operation is `6.0`, and the remainder of 6 divided by 4 is 2. Because `x` became a Float in the `/=` step, the result appears as `2.0`.

## Short and full forms

```python
x += 5
```

expresses the same idea as:

```python
x = x + 5
```

> [!WARNING]
> Track the variable's current value. These examples are sequential, so each line starts from the previous line's result, not from `x = 10` again.

## Quick mental model

- `x += n` → `x = x + n`
- `x -= n` → `x = x - n`
- `x *= n` → `x = x * n`
- `x /= n` → `x = x / n`
- `x %= n` → `x = x % n`
