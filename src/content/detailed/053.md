# 053 — Nested For Loop

Nested For تعني Loop داخل Loop. لكل دورة خارجية، تكتمل كل الدورات الداخلية.

## كل شخص مع كل Skill

```python
people = ["Ahmed", "Mohamed", "Ali"]
skills = ["HTML", "CSS", "Python"]

for person in people:
    print(f"{person} Skills:")

    for skill in skills:
        print(f"- {skill}")
```

```output
Ahmed Skills:
- HTML
- CSS
- Python
Mohamed Skills:
- HTML
- CSS
- Python
Ali Skills:
- HTML
- CSS
- Python
```

عندما `person = "Ahmed"`، الـ Loop الداخلية تمر على Skills الثلاثة. بعدها فقط تنتقل الخارجية إلى `Mohamed` وتعيد الداخلية من البداية.

عدد مرات طباعة الـ Skills هنا `3 people × 3 skills = 9`.

## المرور على List متداخلة

```python
students = [
    ["Ahmed", 90],
    ["Ali", 80],
    ["Omar", 70]
]

for student in students:
    for data in student:
        print(data)
```

```output
Ahmed
90
Ali
80
Omar
70
```

`student` تأخذ List داخلية كاملة، مثل `["Ahmed", 90]`. ثم `data` تمر على الاسم وبعده الدرجة.

> [!IMPORTANT]
> أسماء المتغيرات تساعدك تفهم المستوى: الخارجية تتعامل مع `student` كامل، والداخلية مع `data` واحدة داخله.

> [!WARNING]
> عدد العمليات يتضاعف مع الـ Nesting. في المثال الصغير واضح، لكن Collections كبيرة قد تجعل العمل كثيرًا.

## الصورة الذهنية السريعة

الخارجية تختار مجموعة، والداخلية تمر على محتوى تلك المجموعة بالكامل قبل الانتقال للمجموعة التالية.
