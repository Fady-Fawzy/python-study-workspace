# 053 — Nested For Loop

Nested `for` means a loop inside another loop. For every outer cycle, all inner cycles complete.

## Every person with every skill

```python
people = ["Ahmed", "Mohamed", "Ali"]
skills = ["HTML", "CSS", "Python"]

for person in people:
    print(f"{person} Skills:")

    for skill in skills:
        print(f"- {skill}")
```

```output
Ahmed Skills:
- HTML
- CSS
- Python
Mohamed Skills:
- HTML
- CSS
- Python
Ali Skills:
- HTML
- CSS
- Python
```

When `person = "Ahmed"`, the inner loop visits all three skills. Only then does the outer loop move to `Mohamed` and restart the inner loop.

The number of skill prints is `3 people × 3 skills = 9`.

## Walk through a nested List

```python
students = [
    ["Ahmed", 90],
    ["Ali", 80],
    ["Omar", 70]
]

for student in students:
    for data in student:
        print(data)
```

```output
Ahmed
90
Ali
80
Omar
70
```

`student` receives a complete inner List, such as `["Ahmed", 90]`. Then `data` visits the name followed by the score.

> [!IMPORTANT]
> Variable names help reveal the level: the outer loop handles the full `student`, while the inner loop handles one `data` item inside it.

> [!WARNING]
> The number of operations multiplies with nesting. It is easy to see in this small example, but large collections can make the work substantial.

## Quick mental model

The outer loop chooses a group, and the inner loop traverses that group's full content before moving to the next group.
