# 042 — Nested If + Trainings

Nested `if` means a condition inside another condition's branch. The inner condition is checked only after the program enters the outer branch.

## Discount by country, then student status

```python
name = "Ahmed"
country = "Egypt"
student = True
price = 100

if country == "Egypt":

    if student:
        print(f"Hello {name}")
        print(f"Your Price Is {price - 30}")

    else:
        print(f"Hello {name}")
        print(f"Your Price Is {price - 20}")

else:
    print(f"Hello {name}")
    print(f"Your Price Is {price}")
```

```output
Hello Ahmed
Your Price Is 70
```

The program enters the Egypt branch first. Inside it, `student` is True, so it applies a 30-unit discount: `100 - 30 = 70`. The inner `else` belongs to `if student`, while the outer `else` belongs to `if country`.

## Age and license training

```python
age = 25
has_license = True

if age >= 18:

    if has_license:
        print("You Can Drive")

    else:
        print("You Need A License")

else:
    print("You Are Too Young")
```

```output
You Can Drive
```

The age condition is True, so the license is checked. Because it is True, `You Can Drive` appears. If the age is below 18, `has_license` is not checked at all because the outer branch prevents reaching it.

## Reading the nesting

Read it as staged decisions:

1. Does the outer condition allow entry?
2. If yes, which inner branch applies?
3. If no, run the outer `else`.

> [!IMPORTANT]
> Indentation level determines which `if` each `else` belongs to. Aligning `else` with the correct `if` creates the relationship.

> [!COMPARISON]
> Simple conditions can sometimes be combined with `and`. Nested `if` is useful when the inner condition has its own result or should not be checked until an outer condition passes.

## Quick mental model

Nested `if` = an outer gate followed by an inner gate. Follow indentation to know which level you are inside.
