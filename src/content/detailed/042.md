# 042 — Nested If + Trainings

Nested If معناها شرط داخل فرع شرط آخر. الشرط الداخلي لا يُفحص إلا إذا دخل البرنامج إلى الفرع الخارجي.

## خصم حسب البلد ثم حالة الطالب

```python
name = "Ahmed"
country = "Egypt"
student = True
price = 100

if country == "Egypt":

    if student:
        print(f"Hello {name}")
        print(f"Your Price Is {price - 30}")

    else:
        print(f"Hello {name}")
        print(f"Your Price Is {price - 20}")

else:
    print(f"Hello {name}")
    print(f"Your Price Is {price}")
```

```output
Hello Ahmed
Your Price Is 70
```

البرنامج دخل فرع Egypt أولًا. داخله وجد `student` تساوي True، فطبّق خصم 30: `100 - 30 = 70`. الـ `else` الداخلية مرتبطة بـ `if student`، والخارجية مرتبطة بـ `if country`.

## تدريب السن والرخصة

```python
age = 25
has_license = True

if age >= 18:

    if has_license:
        print("You Can Drive")

    else:
        print("You Need A License")

else:
    print("You Are Too Young")
```

```output
You Can Drive
```

شرط العمر True، فتم فحص الرخصة. لأنها True، ظهر `You Can Drive`. لو العمر أقل من 18، فلن يُفحص `has_license` أصلًا لأن الفرع الخارجي يمنع الوصول له.

## قراءة الـ Nesting

اقرأه كقرارات على مراحل:

1. هل الشرط الخارجي يسمح بالدخول؟
2. لو نعم، أي فرع داخلي ينطبق؟
3. لو لا، نفّذ `else` الخارجية.

> [!IMPORTANT]
> مستوى الـ Indentation يحدد لأي `if` تنتمي كل `else`. محاذاة `else` مع `if` المناسبة هي اللي تربطهما.

> [!COMPARISON]
> ممكن أحيانًا دمج شروط بسيطة باستخدام `and`. لكن Nested If مفيدة عندما تريد نتيجة مختلفة للشرط الداخلي أو لا تريد فحصه إلا بعد تحقق شرط خارجي.

## الصورة الذهنية السريعة

Nested If = بوابة خارجية، وبعد دخولها توجد بوابة داخلية. تتبع الـ Indentation لتعرف أنت داخل أي مستوى.
