# 059 — Function Default Parameters

A default parameter has a value used automatically when the caller does not send a matching argument.

## A simple default

```python
def say_hello(name="Unknown"):
    print(f"Hello {name}")


say_hello("Ahmed")
say_hello()
```

```output
Hello Ahmed
Hello Unknown
```

In the first call, `Ahmed` replaces the default. In the second there is no argument, so the function uses `Unknown`.

## Required and optional parameters

```python
def user_info(name, age="Unknown", country="Egypt"):
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"Country: {country}")
```

`name` is required because it has no default. `age` and `country` are optional because each has a default.

```python
user_info("Ahmed")
```

```output
Name: Ahmed
Age: Unknown
Country: Egypt
```

## Replace part of the defaults

```python
user_info("Ahmed", 25)
```

```output
Name: Ahmed
Age: 25
Country: Egypt
```

The second argument binds to `age`, while `country` keeps its default value.

> [!WARNING]
> Parameters without defaults must come before parameters with defaults. Otherwise Python cannot determine which values are required and which are optional, resulting in `SyntaxError`.

## Quick mental model

Default = a fallback inside a function signature. An explicit argument has priority; when it is absent, the default is used.
