# 059 — Function Default Parameters

Default Parameter لها قيمة تُستخدم تلقائيًا لو المستدعي لم يرسل Argument مقابلة.

## Default بسيط

```python
def say_hello(name="Unknown"):
    print(f"Hello {name}")


say_hello("Ahmed")
say_hello()
```

```output
Hello Ahmed
Hello Unknown
```

في الاستدعاء الأول، `Ahmed` استبدلت الـ Default. في الثاني لا توجد Argument، فاستخدمت الدالة `Unknown`.

## Required مع Optional Parameters

```python
def user_info(name, age="Unknown", country="Egypt"):
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"Country: {country}")
```

`name` Required لأنه بلا Default. `age` و`country` Optional لأن لكل واحدة Default.

```python
user_info("Ahmed")
```

```output
Name: Ahmed
Age: Unknown
Country: Egypt
```

## استبدال جزء من الـ Defaults

```python
user_info("Ahmed", 25)
```

```output
Name: Ahmed
Age: 25
Country: Egypt
```

الـ Argument الثانية ارتبطت بـ `age`، بينما `country` احتفظت بالقيمة الافتراضية.

> [!WARNING]
> Parameters بلا Default لازم تأتي قبل Parameters التي لها Default. غير ذلك يجعل Python غير قادرة على تحديد أي القيم Required وأيها Optional ويؤدي إلى `SyntaxError`.

## الصورة الذهنية السريعة

Default = خطة بديلة داخل توقيع Function. الـ Argument الصريحة لها الأولوية، ولو غابت نستخدم الافتراضي.
