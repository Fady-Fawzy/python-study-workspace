# 044 — Calculate Age Advanced Version

This advanced version adds simple validation before calculating: conversions run only when the age is inside a defined range.

## Read and clean the age

```python
age = int(input("Enter Your Age: ").strip())
```

`strip()` removes spaces from the text, then `int()` converts it to an integer.

## Check the range with `and`

```python
if age > 10 and age < 100:
```

`and` requires both conditions: the age is greater than 10 **and less than 100**. The boundaries themselves are excluded, so 10 and 100 go to `else`.

Python can also write this comparison as `10 < age < 100`, but the example keeps the lesson's form.

## Calculate inside the valid branch

```python
months = age * 12
weeks = age * 52
days = age * 365
hours = days * 24
minutes = hours * 60
seconds = minutes * 60
```

Using 52 weeks per year is more precise than the previous four-weeks-per-month approximation. Days are still an estimate and do not account for leap years.

## Run with an age inside the range

```python
age = int(input("Enter Your Age: ").strip())

if age > 10 and age < 100:
    months = age * 12
    weeks = age * 52
    days = age * 365
    hours = days * 24
    minutes = hours * 60
    seconds = minutes * 60

    print(f"You Lived {months} Months")
    print(f"You Lived {weeks} Weeks")
    print(f"You Lived {days} Days")
    print(f"You Lived {hours} Hours")
    print(f"You Lived {minutes} Minutes")
    print(f"You Lived {seconds} Seconds")

else:
    print("Age Is Out Of Range")
```

```example-run
Enter Your Age: 25
You Lived 300 Months
You Lived 1300 Weeks
You Lived 9125 Days
You Lived 219000 Hours
You Lived 13140000 Minutes
You Lived 788400000 Seconds
```

Age 25 satisfies both conditions, so the calculations run. `weeks = 25 * 52 = 1300`.

## Run with an age outside the range

```example-run
Enter Your Age: 8
Age Is Out Of Range
```

The first condition, `8 > 10`, is False, so Python skips all calculations and runs `else`.

> [!WARNING]
> The range check happens after `int()`. Typing letters still causes `ValueError` before the range is reached; this lesson validates the range only.

## Quick mental model

Validate first, calculate second: after converting the type, confirm that the value is acceptable, then do the work inside the correct branch.
