# 031 — Dictionary Methods Part 1

الـ Dictionary Mutable، يعني نقدر نفرغها، نضيف أو نحدّث أزواجًا، وننسخها. الدرس ده يوضح الفرق بين العمليات التي تغيّر نفس Dictionary والعمليات التي تصنع نسخة.

## `clear()` — تفريغ Dictionary

```python
user = {
    "name": "Ahmed",
    "age": 25
}

test = user.copy()
test.clear()
print(test)
```

```output
{}
```

`test.clear()` حذفت كل أزواج `key: value` من `test` نفسها. استخدمنا نسخة، لذلك `user` الأصلية ما زالت تحتوي `name` و`age`.

> [!IMPORTANT]
> `clear()` تعدّل نفس object وترجع `None`. لا تكتب `empty = test.clear()` متوقعًا Dictionary فاضية؛ المتغير `empty` سيأخذ `None`.

## `update()` — إضافة أو تحديث أزواج

```python
user.update({"country": "Egypt"})
print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt'}
```

المفتاح `country` لم يكن موجودًا، لذلك `update()` أضافه. لو أرسلت Key موجودًا، يتم تحديث قيمته بدل إنشاء Key مكرر.

لو استخدمت `update()` مع `age` الموجودة، ستستبدل قيمتها بدل إنشاء Key ثانية؛ لأن كل Key لازم يظل فريدًا.

## الإضافة المباشرة باستخدام المفتاح

```python
user["skill"] = "Python"
print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt', 'skill': 'Python'}
```

التعيين `user["skill"] = "Python"` يضيف الزوج لو المفتاح جديد، ويستبدل القيمة لو المفتاح موجود.

> [!COMPARISON]
> `user[key] = value` واضح لإضافة أو تحديث زوج واحد.
> `user.update({...})` مناسب لإضافة أو تحديث عدة أزواج معًا.

## `copy()` — نسخ المستوى الخارجي

```python
copied_user = user.copy()
print(copied_user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt', 'skill': 'Python'}
```

وقت النسخ، `copied_user` لها نفس الأزواج، لكنها Dictionary object مختلفة. إضافة مفتاح جديد في واحدة لا تضيفه تلقائيًا للأخرى.

النسخة **shallow copy**: الفصل يكون في الـ Dictionary الخارجية. لو القيم نفسها objects متداخلة Mutable، فالتفاصيل الداخلية لها سلوك يحتاج دراسة أعمق لاحقًا.

## `keys()` — View للمفاتيح

```python
print(user.keys())
```

```output
dict_keys(['name', 'age', 'country', 'skill'])
```

`keys()` لا تعيد القيم؛ تعيد المفاتيح التي نستخدمها للوصول للبيانات. الناتج View مرتبط بالـ Dictionary، وليس List مستقلة.

## `values()` — View للقيم

```python
print(user.values())
```

```output
dict_values(['Ahmed', 25, 'Egypt', 'Python'])
```

كل قيمة تقابل المفتاح في نفس موضع ترتيب الإدخال: `name → Ahmed`، ثم `age → 25`، وهكذا.

## تنفيذ المثال كاملًا

لو شغّلت مثال المصدر بالترتيب، `test.clear()` لا تغيّر `user`، ثم يضاف `country` وبعده `skill`، ثم تُصنع النسخة. ده يوضح ليه تتبع اسم المتغير مهم: كل Method تُستدعى على object محددة قبل النقطة.

> [!WARNING]
> لا تخلط بين `test.clear()` و`user.clear()`. الميثود تعدّل الـ Dictionary المكتوبة قبل النقطة فقط.

## الصورة الذهنية السريعة

- `clear()` = امسح كل الأزواج من نفس Dictionary.
- `update()` = أضف أو حدّث أزواجًا.
- `dictionary[key] = value` = تعامل مباشر مع زوج واحد.
- `copy()` = نسخة خارجية منفصلة.
- `keys()` و`values()` = Views لجانبي كل زوج.
