# 033 — Boolean

الـ **Boolean** نوع منطقي له قيمتان فقط: `True` و`False`. بنستخدمه لتمثيل إجابة سؤال نعم/لا مثل: هل الرقم أكبر؟ هل النص غير فارغ؟

## المقارنات تُنتج Boolean

```python
print(10 > 5)
print(10 < 5)
```

```output
True
False
```

`10 > 5` حقيقة، لذلك نتيجتها `True`. أما `10 < 5` فليست صحيحة، فنتيجتها `False`.

## قيم Truthy

```python
print(bool("Python"))
print(bool(100))
print(bool(15.5))
print(bool([1, 2, 3]))
print(bool(True))
```

```output
True
True
True
True
True
```

`bool(value)` تسأل: "هل هذه القيمة تعتبر موجودة/حقيقية في سياق منطقي؟" النص غير الفارغ، الأرقام غير الصفرية، والـ collection غير الفارغة تعتبر Truthy.

## قيم Falsy

```python
print(bool(0))
print(bool(""))
print(bool([]))
print(bool(()))
print(bool({}))
print(bool(False))
print(bool(None))
```

```output
False
False
False
False
False
False
False
```

الصفر، النص الفارغ، الـ collections الفارغة، `False` نفسها، و`None` كلها Falsy.

## الفاصل المطبوع في المثال

```python
print("=" * 30)
```

```output
==============================
```

ده مجرد فاصل بصري: String فيها `=` تكررت 30 مرة. لا يغيّر معنى الـ Boolean.

## المسافة ليست نصًا فارغًا

```python
print(bool(" "))
print(bool(""))
```

```output
True
False
```

النص الأول يحتوي حرف Space، فطوله `1` ويعتبر Truthy. النص الثاني لا يحتوي أي حرف، فطوله `0` ويعتبر Falsy.

> [!WARNING]
> لا تحكم على الـ String من شكلها بين الاقتباسات فقط؛ المسافات حروف. استخدم `strip()` قبل الاختبار لو عايز تعتبر النص المكوّن من مسافات فارغًا.

## الصورة الذهنية السريعة

- `True` و`False` هما ناتج الأسئلة المنطقية.
- "فارغ أو صفر" غالبًا Falsy.
- "فيه محتوى أو رقم غير صفر" غالبًا Truthy.
- `bool(value)` تكشف التقييم المنطقي للقيمة.
