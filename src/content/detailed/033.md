# 033 — Boolean

A **Boolean** is a logical type with only two values: `True` and `False`. It represents a yes/no answer, such as whether a number is larger or a String is non-empty.

## Comparisons produce Booleans

```python
print(10 > 5)
print(10 < 5)
```

```output
True
False
```

`10 > 5` is true, so its result is `True`. `10 < 5` is not true, so its result is `False`.

## Truthy values

```python
print(bool("Python"))
print(bool(100))
print(bool(15.5))
print(bool([1, 2, 3]))
print(bool(True))
```

```output
True
True
True
True
True
```

`bool(value)` asks: “Does this value count as present/true in a logical context?” Non-empty Strings, non-zero numbers, and non-empty collections are Truthy.

## Falsy values

```python
print(bool(0))
print(bool(""))
print(bool([]))
print(bool(()))
print(bool({}))
print(bool(False))
print(bool(None))
```

```output
False
False
False
False
False
False
False
```

Zero, an empty String, empty collections, `False` itself, and `None` are all Falsy.

## The printed separator in the example

```python
print("=" * 30)
```

```output
==============================
```

This is only a visual separator: a String containing `=` repeated 30 times. It does not change the meaning of Boolean values.

## A space is not an empty String

```python
print(bool(" "))
print(bool(""))
```

```output
True
False
```

The first String contains a space character, so its length is `1` and it is Truthy. The second contains no characters, so its length is `0` and it is Falsy.

> [!WARNING]
> Do not judge a String only by how it looks between quotes; spaces are characters. Use `strip()` before testing if a whitespace-only String should count as empty.

## Quick mental model

- `True` and `False` are the results of logical questions.
- “Empty or zero” is usually Falsy.
- “Contains content or a non-zero number” is usually Truthy.
- `bool(value)` reveals a value's logical evaluation.
