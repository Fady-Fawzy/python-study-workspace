# 048 — While Trainings

التدريبات تطبق `while` مع Index لزيارة عناصر List. لازم نحافظ على شرط يمنع تجاوز آخر Index.

## المرور على قائمة Websites

```python
websites = [
    "Google",
    "Facebook",
    "YouTube",
    "Instagram"
]

a = 0

while a < len(websites):
    print(websites[a])
    a += 1
```

```output
Google
Facebook
YouTube
Instagram
```

`len(websites)` تساوي 4، والـ Indexes الصحيحة من 0 إلى 3. الشرط `a < 4` يسمح بهذه المواقع فقط، وبعد زيادة `a` إلى 4 تتوقف Loop قبل `websites[4]`.

> [!IMPORTANT]
> استخدام `< len(list)` هو الحارس الذي يمنع `IndexError`. آخر Index دائمًا `len(list) - 1`.

## ترقيم الأصدقاء للمستخدم

```python
friends = ["Ahmed", "Ali", "Omar", "Hassan"]

index = 0

while index < len(friends):
    print(f"#{index + 1} {friends[index]}")
    index += 1
```

```output
#1 Ahmed
#2 Ali
#3 Omar
#4 Hassan
```

البرنامج يحتاج الـ Index للوصول للعنصر، لكنه يعرض `index + 1` لأن المستخدمين عادة يعدّون من 1 بينما Python تبدأ Index من 0.

## تتبع دورة واحدة

عندما `index = 2`:

- الشرط `2 < 4` True.
- `friends[2]` هي `"Omar"`.
- المعروض `#3` لأن `2 + 1 = 3`.
- بعدها تصبح `index = 3`.

> [!WARNING]
> لا تزود `index` قبل استخدامه إلا لو قصدك تخطي أول عنصر. مكان سطر التحديث يغير العناصر التي ستُقرأ.

## الصورة الذهنية السريعة

في Loop مبنية على Index عندك ثلاثة أجزاء: Index تبدأ من صفر، شرط ضد `len()`, وتحديث بعد معالجة العنصر.
