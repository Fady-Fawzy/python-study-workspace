# 048 — While Trainings

These exercises use `while` with an index to visit List items. The condition must prevent going beyond the last index.

## Walk through a List of websites

```python
websites = [
    "Google",
    "Facebook",
    "YouTube",
    "Instagram"
]

a = 0

while a < len(websites):
    print(websites[a])
    a += 1
```

```output
Google
Facebook
YouTube
Instagram
```

`len(websites)` is 4, and valid indexes run from 0 to 3. The condition `a < 4` allows only those positions; after `a` becomes 4, the loop stops before `websites[4]`.

> [!IMPORTANT]
> Using `< len(list)` is the guard that prevents `IndexError`. The last index is always `len(list) - 1`.

## Number friends for the user

```python
friends = ["Ahmed", "Ali", "Omar", "Hassan"]

index = 0

while index < len(friends):
    print(f"#{index + 1} {friends[index]}")
    index += 1
```

```output
#1 Ahmed
#2 Ali
#3 Omar
#4 Hassan
```

The program needs the index to reach the item, but displays `index + 1` because people usually count from 1 while Python starts indexes at 0.

## Trace one cycle

When `index = 2`:

- The condition `2 < 4` is True.
- `friends[2]` is `"Omar"`.
- The displayed number is `#3` because `2 + 1 = 3`.
- Then `index` becomes `3`.

> [!WARNING]
> Do not increment `index` before using it unless you intend to skip the first item. The location of the update line changes which items are read.

## Quick mental model

An index-based loop has three parts: an index that starts at zero, a condition against `len()`, and an update after processing the item.
