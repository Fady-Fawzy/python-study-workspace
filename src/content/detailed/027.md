# 027 — Set Methods Part 1

This lesson covers the basic ways to clear, combine, add, remove, and copy Sets. Always remember that item order is not guaranteed.

## `clear()` — empty the same Set

```python
a = {1, 2, 3}

a.clear()

print(a)
```

```output
set()
```

`clear()` removes every item from the same object. The representation of an empty Set is `set()`, because `{}` means an empty Dictionary.

## `union()` — combine Sets

Union collects items found in any of the Sets, removes duplicates, and returns a new Set without changing the sources.

```python
a = {1, 2, 3}
b = {4, 5, 6}
c = {"A", "B"}

print(a | b)

print(a.union(b, c))
```

```example-output
{1, 2, 3, 4, 5, 6}
{1, 2, 3, 4, 5, 6, 'A', 'B'}
```

`a | b` and `a.union(b)` express the same union operation. The second line combines three Sets. Display order may vary, but every value appears once.

> [!IMPORTANT]
> `union()` does not change `a`. If you need to change the current Set, use `update()`.

## `add()` — add one item

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

```example-output
{1, 2, 3, 4}
```

`add(value)` adds **one item**. If the value already exists, no duplicate appears and no error is raised.

```python
numbers.add(4)
```

After this line, the Set still contains only one `4`.

## `copy()` — an independent outer copy

```python
a = {1, 2, 3}

b = a.copy()

print(b)
```

```example-output
{1, 2, 3}
```

`b` has the same items as `a` at copy time, but it is a separate Set object. Like `list.copy()`, this is a **shallow** copy; deeper nested-object behavior is an advanced topic.

## `remove()` — remove and raise an error when missing

```python
numbers = {1, 2, 3, 4}

numbers.remove(2)

print(numbers)
```

```example-output
{1, 3, 4}
```

The value `2` was present, so it was removed. If you request a value that is missing:

```python
numbers.remove(100)
```

```error
KeyError: 100
```

The error is intentional: `remove()` assumes the value exists.

## `discard()` — safe removal when missing

```python
numbers = {1, 2, 3, 4}

numbers.discard(2)
numbers.discard(100)

print(numbers)
```

```example-output
{1, 3, 4}
```

`2` is removed, while trying to remove `100` does nothing and raises no error.

> [!COMPARISON]
> `remove(value)` raises `KeyError` when the value is missing.
> `discard(value)` ignores a missing value.
> Choose based on whether a missing item is an error or a normal case in your program.

## `pop()` — remove an unspecified item

```python
numbers = {1, 2, 3, 4}

print(numbers.pop())
```

```example-output
1
```

`pop()` **removes and returns** an item from the Set, but because a Set is unordered you cannot rely on which item it will be. The `1` here is only an example run and may differ.

If the Set is empty, `pop()` raises `KeyError`.

## `update()` — add iterable items to the same Set

```python
a = {1, 2, 3}

a.update([4, 5])
a.update({"A", "B"})

print(a)
```

```example-output
{1, 2, 3, 4, 5, 'A', 'B'}
```

`update()` walks through items from a List, Set, or another suitable iterable and adds each item to `a`. The Set's nature removes duplicates.

> [!COMPARISON]
> `add(value)` adds one object.
> `update(iterable)` adds iterable items one by one.
> This resembles the `append()` versus `extend()` comparison for Lists, except Sets do not allow duplicates.

## Quick mental model

- Empty: `clear()`
- Combine into a new Set: `union()` or `|`
- Add one item: `add()`
- Add multiple items: `update()`
- Remove strictly: `remove()`
- Remove safely: `discard()`
- Remove and receive an unspecified item: `pop()`
