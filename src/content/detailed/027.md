# 027 — Set Methods Part 1

الدرس ده بيغطي الطرق الأساسية لتفريغ الـ Set، دمجها، إضافة أو حذف عناصر، ونسخها. افتكر دائمًا إن ترتيب العناصر غير مضمون.

## `clear()` — تفريغ نفس الـ Set

```python
a = {1, 2, 3}

a.clear()

print(a)
```

```output
set()
```

`clear()` حذفت كل العناصر من نفس object. شكل الـ Set الفاضية هو `set()`؛ لأن `{}` معناها Dictionary فاضية.

## `union()` — اتحاد المجموعات

الاتحاد يجمع العناصر الموجودة في أي Set مع إزالة التكرار، ويُرجع Set جديدة من غير تعديل المصادر.

```python
a = {1, 2, 3}
b = {4, 5, 6}
c = {"A", "B"}

print(a | b)

print(a.union(b, c))
```

```example-output
{1, 2, 3, 4, 5, 6}
{1, 2, 3, 4, 5, 6, 'A', 'B'}
```

`a | b` و`a.union(b)` يعبران عن نفس فكرة الاتحاد. السطر الثاني ضم ثلاث مجموعات. ترتيب العرض قد يختلف، لكن كل قيمة تظهر مرة واحدة.

> [!IMPORTANT]
> `union()` لا تعدّل `a`. لو محتاج تعدّل الـ Set الحالية استخدم `update()`.

## `add()` — إضافة عنصر واحد

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

```example-output
{1, 2, 3, 4}
```

`add(value)` تضيف **عنصرًا واحدًا**. لو أضفت قيمة موجودة أصلًا، لا يظهر تكرار ولا يحدث Error.

```python
numbers.add(4)
```

بعد السطر ده تفضل المجموعة محتوية على `4` مرة واحدة فقط.

## `copy()` — نسخة مستقلة من المستوى الخارجي

```python
a = {1, 2, 3}

b = a.copy()

print(b)
```

```example-output
{1, 2, 3}
```

`b` لها نفس العناصر وقت النسخ، لكنها Set object منفصلة عن `a`. زي `list.copy()`، النسخة **shallow**؛ والتفصيل الأعمق للأجسام المتداخلة موضوع متقدم.

## `remove()` — حذف مع Error عند الغياب

```python
numbers = {1, 2, 3, 4}

numbers.remove(2)

print(numbers)
```

```example-output
{1, 3, 4}
```

القيمة `2` كانت موجودة فاتحذفت. لكن لو طلبت حذف قيمة غير موجودة:

```python
numbers.remove(100)
```

```error
KeyError: 100
```

الـ Error مقصود: `remove()` تفترض إن القيمة موجودة.

## `discard()` — حذف آمن عند الغياب

```python
numbers = {1, 2, 3, 4}

numbers.discard(2)
numbers.discard(100)

print(numbers)
```

```example-output
{1, 3, 4}
```

`2` اتحذفت، ومحاولة حذف `100` لم تفعل شيئًا ولم ترفع Error.

> [!COMPARISON]
> `remove(value)` يرفع `KeyError` لو القيمة غير موجودة.
> `discard(value)` يتجاهل غياب القيمة.
> اختار بناءً على هل غياب العنصر يُعتبر خطأ في منطق برنامجك أم حالة طبيعية.

## `pop()` — حذف عنصر غير محدد

```python
numbers = {1, 2, 3, 4}

print(numbers.pop())
```

```example-output
1
```

`pop()` تحذف **وتُرجع** عنصرًا من الـ Set، لكن بما إن الـ Set غير مرتبة فلا تعتمد على أي عنصر تحديدًا. الرقم `1` هنا مجرد Example Run ممكن يختلف.

ولو الـ Set فاضية، `pop()` ترفع `KeyError`.

## `update()` — إضافة عناصر Iterable إلى نفس الـ Set

```python
a = {1, 2, 3}

a.update([4, 5])
a.update({"A", "B"})

print(a)
```

```example-output
{1, 2, 3, 4, 5, 'A', 'B'}
```

`update()` تمشي على العناصر القادمة من List أو Set أو أي iterable مناسب، وتضيف كل عنصر إلى `a`. لو فيه تكرار، طبيعة الـ Set تمنعه.

> [!COMPARISON]
> `add(value)` تضيف object واحدًا.
> `update(iterable)` تضيف عناصر الـ iterable واحدًا واحدًا.
> الفكرة شبيهة بمقارنة `append()` و`extend()` في الـ List، مع اختلاف إن الـ Set لا تسمح بالتكرار.

## الصورة الذهنية السريعة

- فرّغ: `clear()`
- اجمع في Set جديدة: `union()` أو `|`
- أضف عنصرًا: `add()`
- أضف عدة عناصر: `update()`
- احذف بقوة: `remove()`
- احذف بأمان: `discard()`
- احذف عنصرًا غير محدد واستلمه: `pop()`
