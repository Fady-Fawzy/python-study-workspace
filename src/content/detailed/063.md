# 063 — Function Recursion

Recursion تعني أن Function تستدعي نفسها لحل نسخة أصغر من نفس المشكلة. لازم يوجد **Base Case** يوقف الاستدعاءات.

## Countdown والـ Base Case

```python
def countdown(number):
    if number == 0:
        print("Done")
        return

    print(number)
    countdown(number - 1)


countdown(5)
```

```output
5
4
3
2
1
Done
```

كل Call تطبع الرقم وتستدعي `countdown` برقم أقل. عند صفر، Base Case تطبع Done وتستخدم `return` حتى لا يحدث استدعاء آخر.

> [!WARNING]
> Recursion بلا Base Case، أو بلا خطوة تقرّب منها، تستمر حتى ترفع Python `RecursionError`.

## تنظيف الحروف المكررة المتجاورة

```python
def clean_word(word):
    if len(word) == 1:
        return word

    if word[0] == word[1]:
        return clean_word(word[1:])

    return word[0] + clean_word(word[1:])


print(clean_word("wwwooorrrlllddd"))
```

```output
world
```

لو أول حرفين متساويان، الدالة تتجاهل نسخة وتكمل من `word[1:]`. لو مختلفان، تحتفظ بالأول وتضيف إليه نتيجة تنظيف الباقي. عندما يتبقى حرف واحد، Base Case تعيده.

## تتبع الفكرة

- `www...` تختصر تدريجيًا إلى `w...`.
- بعدها نفس المنطق مع `ooo` ثم `rrr` وهكذا.
- تجميع الأحرف المختلفة يعيد `world`.

## الصورة الذهنية السريعة

Recursion = Base Case + خطوة تقلل المشكلة + استدعاء لنفس Function. لو جزء منهم ناقص، الحل غير مكتمل.
