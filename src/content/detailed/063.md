# 063 — Function Recursion

Recursion means a function calls itself to solve a smaller version of the same problem. There must be a **base case** that stops the calls.

## Countdown and the base case

```python
def countdown(number):
    if number == 0:
        print("Done")
        return

    print(number)
    countdown(number - 1)


countdown(5)
```

```output
5
4
3
2
1
Done
```

Each call prints the number and calls `countdown` with a smaller number. At zero, the base case prints Done and uses `return` so there is no further call.

> [!WARNING]
> Recursion without a base case, or without a step that moves toward it, continues until Python raises `RecursionError`.

## Clean adjacent duplicate characters

```python
def clean_word(word):
    if len(word) == 1:
        return word

    if word[0] == word[1]:
        return clean_word(word[1:])

    return word[0] + clean_word(word[1:])


print(clean_word("wwwooorrrlllddd"))
```

```output
world
```

If the first two characters match, the function drops one copy and continues from `word[1:]`. If they differ, it keeps the first and adds the cleaned remainder. When one character remains, the base case returns it.

## Trace the idea

- `www...` gradually shrinks to `w...`.
- The same logic then applies to `ooo`, `rrr`, and so on.
- Combining the different characters produces `world`.

## Quick mental model

Recursion = base case + a step that reduces the problem + a call to the same function. If one part is missing, the solution is incomplete.
