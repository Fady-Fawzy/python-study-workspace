# 062 — Function Scope

Scope determines where a variable name is visible and which value the code means. A variable inside a function is usually local; outside it, global.

## A local does not change a same-named global

```python
x = 100


def test():
    x = 50
    print(f"Inside Function: {x}")


test()

print(f"Outside Function: {x}")
```

```output
Inside Function: 50
Outside Function: 100
```

`x = 50` creates a local variable inside `test`. It temporarily shadows the global name inside the function, but does not replace `x = 100` outside it.

## Change a global with `global`

```python
x = 100


def change_number():
    global x
    x = 500
    print(x)


change_number()

print(x)
```

```output
500
500
```

`global x` tells Python that the following assignment targets the outer variable. After the call, the global value itself becomes 500.

> [!COMPARISON]
> Without `global`, an assignment inside a function creates a local name.
> With `global`, the assignment changes the name in the global scope.

> [!WARNING]
> Frequently changing global state makes functions harder to understand and test. `return` and passing parameters are usually clearer; use `global` only when it is an intentional choice.

## Quick mental model

Every function has an inner namespace. The same name does not mean the variables are the same place; `global` is an explicit declaration for crossing that boundary during assignment.
