# 062 — Function Scope

Scope تحدد أين يكون اسم المتغير مرئيًا وأي قيمة يقصدها الكود. المتغير داخل Function غالبًا Local، وخارجها Global.

## Local لا تغيّر Global بنفس الاسم

```python
x = 100


def test():
    x = 50
    print(f"Inside Function: {x}")


test()

print(f"Outside Function: {x}")
```

```output
Inside Function: 50
Outside Function: 100
```

`x = 50` أنشأت Local variable داخل `test`. هي تخفي الاسم Global مؤقتًا داخل Function، لكنها لا تستبدل `x = 100` خارجها.

## تعديل Global باستخدام `global`

```python
x = 100


def change_number():
    global x
    x = 500
    print(x)


change_number()

print(x)
```

```output
500
500
```

`global x` أخبرت Python أن Assignment التالية تقصد المتغير الخارجي. لذلك بعد Call أصبحت القيمة Global نفسها 500.

> [!COMPARISON]
> بدون `global`: Assignment داخل Function تنشئ Local name.
> مع `global`: Assignment تعدّل الاسم الموجود في Global Scope.

> [!WARNING]
> كثرة تعديل Global state تجعل Functions أصعب في الفهم والاختبار. غالبًا `return` وتمرير Parameters أوضح، واستخدم `global` فقط عندما يكون الاختيار مقصودًا.

## الصورة الذهنية السريعة

كل Function لها مساحة أسماء داخلية. تشابه الاسم لا يعني أن المتغيرين نفس المكان؛ `global` تصريح صريح لعبور هذا الحد عند Assignment.
