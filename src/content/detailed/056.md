# 056 — Function And Return

Function هي Block كود له اسم، تكتبه مرة وتستدعيه وقت الحاجة. ده يقلل التكرار ويقسم البرنامج إلى مهام واضحة.

## تعريف Function باستخدام `def`

```python
def say_hello():
    print("Hello")
    print("Welcome To Python")
```

`def` تسجل تعريف الدالة. السطران داخلها لا يعملان لحظة التعريف؛ Python تنتظر Function Call.

## تشغيل الدالة

```python
say_hello()
```

```output
Hello
Welcome To Python
```

الأقواس بعد الاسم معناها "شغّل الدالة الآن". كل Call تبدأ تنفيذ جسم الدالة من أوله.

## `return` تعيد قيمة

```python
def calculate():
    result = 10 + 20
    return result


number = calculate()

print(number)
```

```output
30
```

`calculate()` حسبت 30 ثم `return` أرسلتها لمكان الاستدعاء. لذلك `number` استقبلت 30.

## استخدام القيمة الراجعة في تعبير

```python
def get_number():
    return 100


number = get_number()

print(number * 2)
```

```output
200
```

القيمة الراجعة Data عادية؛ يمكن تخزينها أو ضربها أو تمريرها لدالة أخرى.

> [!COMPARISON]
> `print()` تعرض قيمة للمستخدم وتُرجع `None`.
> `return` تسلّم قيمة للكود الذي استدعى الدالة، فيقدر يستخدمها بعد ذلك.

> [!IMPORTANT]
> `return` تنهي تنفيذ Function فورًا. أي كود في نفس المسار بعدها لن ينفذ.

## الصورة الذهنية السريعة

- `def` = عرّف وصفة.
- `function()` = نفّذ الوصفة.
- `return value` = أرسل النتيجة للخارج.
