# 056 — Function And Return

A function is a named block of code that you write once and call when needed. This reduces repetition and divides a program into clear tasks.

## Define a function with `def`

```python
def say_hello():
    print("Hello")
    print("Welcome To Python")
```

`def` registers the function definition. The two lines inside it do not run at definition time; Python waits for a function call.

## Call the function

```python
say_hello()
```

```output
Hello
Welcome To Python
```

The parentheses after the name mean “run the function now.” Every call starts executing the function body from the beginning.

## `return` sends back a value

```python
def calculate():
    result = 10 + 20
    return result


number = calculate()

print(number)
```

```output
30
```

`calculate()` computes 30, then `return` sends it back to the call site. Therefore, `number` receives 30.

## Use the returned value in an expression

```python
def get_number():
    return 100


number = get_number()

print(number * 2)
```

```output
200
```

The returned value is ordinary data; it can be stored, multiplied, or passed to another function.

> [!COMPARISON]
> `print()` displays a value to the user and returns `None`.
> `return` hands a value to the code that called the function, so it can use it afterward.

> [!IMPORTANT]
> `return` ends function execution immediately. Code in the same path after it does not run.

## Quick mental model

- `def` = define a recipe.
- `function()` = run the recipe.
- `return value` = send the result outside.
