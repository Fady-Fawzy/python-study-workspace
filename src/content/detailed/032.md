# 032 — Dictionary Methods Part 2

الميثودز هنا تساعدك تنشئ قيمة افتراضية، تحذف آخر زوج وتستلمه، تتعامل مع المفاتيح والقيم كأزواج، أو تبني Dictionary جديدة من مجموعة مفاتيح.

## `setdefault()` — اقرأ الموجود أو أضف Default

```python
user = {
    "name": "Ahmed",
    "age": 25
}

print(user.setdefault("name", "Mohamed"))
```

```output
Ahmed
```

المفتاح `name` موجود أصلًا وقيمته `Ahmed`، لذلك `setdefault()` رجّعت القيمة الموجودة **ولم تستبدلها** بـ `Mohamed`.

```python
user.setdefault("country", "Egypt")

print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt'}
```

`country` لم يكن موجودًا، فالميثود أضافته بالقيمة الافتراضية `Egypt` ثم ترجع هذه القيمة لو استخدمت الناتج.

> [!COMPARISON]
> `update({"name": "Mohamed"})` تستبدل القيمة الموجودة.
> `setdefault("name", "Mohamed")` تحافظ على الموجود، وتستخدم الـ Default فقط عند غياب المفتاح.

## `popitem()` — حذف وإرجاع آخر زوج

```python
user["skill"] = "Python"

print(user.popitem())
print(user)
```

```output
('skill', 'Python')
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt'}
```

في Python الحديثة، `popitem()` تحذف آخر زوج تمت إضافته وتُرجعه كـ Tuple بالشكل `(key, value)`. آخر زوج هنا كان `skill: Python`.

لو الـ Dictionary فاضية، الميثود ترفع `KeyError` لأنه لا يوجد زوج يمكن حذفه.

> [!IMPORTANT]
> لاحظ وظيفتين في نفس العملية: `popitem()` تغيّر الـ Dictionary، وفي الوقت نفسه تعطيك الزوج المحذوف.

## `items()` — المفاتيح والقيم كأزواج

بعد حذف `skill`، محتوى `user` هو `name`, `age`, `country`:

```python
print(user.items())
```

```output
dict_items([('name', 'Ahmed'), ('age', 25), ('country', 'Egypt')])
```

`items()` تعرض View، وكل عنصر فيها Tuple مكوّنة من `(key, value)`. الشكل ده مهم جدًا عند الدوران على Dictionary لاحقًا، لأنك تقدر تستقبل المفتاح والقيمة معًا.

## `fromkeys()` — بناء Dictionary من مفاتيح جاهزة

```python
keys = ("name", "age", "country")
default_value = "Unknown"

new_dictionary = dict.fromkeys(keys, default_value)

print(new_dictionary)
```

```output
{'name': 'Unknown', 'age': 'Unknown', 'country': 'Unknown'}
```

`dict.fromkeys(keys, default_value)` مشت على المفاتيح الموجودة في الـ Tuple، وأنشأت لكل مفتاح نفس القيمة الافتراضية `"Unknown"`.

الميثود تُستدعى هنا على النوع `dict` لأنها Factory تبني Dictionary جديدة، مش تعديلًا لـ `user`.

> [!WARNING]
> كل المفاتيح تشير إلى نفس Default object. مع String ثابتة ده طبيعي، لكن استخدام List Mutable واحدة كـ Default قد يسبب مشاركة غير مقصودة بين المفاتيح. في المستوى الحالي استخدم قيمة ثابتة بسيطة مثل String أو Number لو ده المطلوب.

## مقارنة سريعة

| Method | تعمل ماذا؟ | تعدّل الـ Dictionary الحالية؟ |
|---|---|---|
| `setdefault()` | تقرأ الموجود أو تضيف Default | نعم، فقط لو المفتاح غائب |
| `popitem()` | تحذف وتُرجع آخر زوج | نعم |
| `items()` | تعطي View من `(key, value)` | لا |
| `dict.fromkeys()` | تبني Dictionary جديدة | لا |

## الصورة الذهنية السريعة

- عايز قيمة موجودة أو Default محفوظة؟ `setdefault()`.
- عايز تشيل آخر زوج وتستخدمه؟ `popitem()`.
- عايز المفتاح والقيمة معًا؟ `items()`.
- عندك مفاتيح جاهزة وDefault موحّد؟ `dict.fromkeys()`.
