# 032 — Dictionary Methods Part 2

These methods help you create a default value, remove and receive the last pair, work with keys and values as pairs, or build a new Dictionary from a group of keys.

## `setdefault()` — read the existing value or add a default

```python
user = {
    "name": "Ahmed",
    "age": 25
}

print(user.setdefault("name", "Mohamed"))
```

```output
Ahmed
```

The `name` key already exists with value `Ahmed`, so `setdefault()` returns the existing value and **does not replace it** with `Mohamed`.

```python
user.setdefault("country", "Egypt")

print(user)
```

```output
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt'}
```

`country` was missing, so the method adds it with the default `Egypt` and returns that value if you use the result.

> [!COMPARISON]
> `update({"name": "Mohamed"})` replaces the existing value.
> `setdefault("name", "Mohamed")` preserves the existing value and uses the default only when the key is missing.

## `popitem()` — remove and return the last pair

```python
user["skill"] = "Python"

print(user.popitem())
print(user)
```

```output
('skill', 'Python')
{'name': 'Ahmed', 'age': 25, 'country': 'Egypt'}
```

In modern Python, `popitem()` removes the last pair added and returns it as a Tuple in the form `(key, value)`. The last pair here is `skill: Python`.

If the Dictionary is empty, the method raises `KeyError` because there is no pair to remove.

> [!IMPORTANT]
> Notice two effects in one operation: `popitem()` changes the Dictionary and gives you the removed pair at the same time.

## `items()` — keys and values as pairs

After removing `skill`, `user` contains `name`, `age`, and `country`:

```python
print(user.items())
```

```output
dict_items([('name', 'Ahmed'), ('age', 25), ('country', 'Egypt')])
```

`items()` exposes a view, and each item is a Tuple made of `(key, value)`. This shape is especially useful when looping over a Dictionary because you can receive the key and value together.

## `fromkeys()` — build a Dictionary from ready keys

```python
keys = ("name", "age", "country")
default_value = "Unknown"

new_dictionary = dict.fromkeys(keys, default_value)

print(new_dictionary)
```

```output
{'name': 'Unknown', 'age': 'Unknown', 'country': 'Unknown'}
```

`dict.fromkeys(keys, default_value)` walks through the keys in the Tuple and creates the same default value, `"Unknown"`, for each key.

The method is called on the `dict` type because it is a factory that builds a new Dictionary, not an update to `user`.

> [!WARNING]
> All keys refer to the same default object. A fixed String is harmless, but using one mutable List as the default can cause unintended sharing between keys. At this level, use a simple fixed String or Number when appropriate.

## Quick comparison

| Method | What does it do? | Does it change the current Dictionary? |
|---|---|---|
| `setdefault()` | Read existing or add a default | Yes, only if the key is missing |
| `popitem()` | Remove and return the last pair | Yes |
| `items()` | Return a view of `(key, value)` | No |
| `dict.fromkeys()` | Build a new Dictionary | No |

## Quick mental model

- Need an existing value or a stored default? `setdefault()`.
- Need to remove and use the last pair? `popitem()`.
- Need the key and value together? `items()`.
- Have ready keys and one shared default? `dict.fromkeys()`.
