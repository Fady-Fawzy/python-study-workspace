# 050 — Password Guess

This example keeps asking for a password while the input is wrong and uses a counter plus `break` to control attempts.

## The continuation condition

```python
password = "python123"
tries = 4

input_password = input("Enter Password: ")

while input_password != password:
```

If the input equals the password, the `while` body does not run. If it differs, a wrong-attempt cycle begins.

## Decrease attempts and read a new guess

```python
tries -= 1
print(f"Wrong Password, {tries} Tries Left")

input_password = input("Enter Password Again: ")
```

The counter decreases each time the loop is entered, then a new value is read for the next condition check.

## The complete basic example

```python
password = "python123"

tries = 4

input_password = input("Enter Password: ")

while input_password != password:
    tries -= 1

    print(f"Wrong Password, {tries} Tries Left")

    input_password = input("Enter Password Again: ")

    if tries == 0:
        print("All Tries Finished")
        break

else:
    print("Correct Password")
```

The complete block is the runnable, copyable version. The shorter sections around it isolate each responsibility so the counter and exit are easier to follow.

## Success before attempts run out

```example-run
Enter Password: test
Wrong Password, 3 Tries Left
Enter Password Again: python
Wrong Password, 2 Tries Left
Enter Password Again: python123
Correct Password
```

When the value becomes correct, the `while` condition becomes False and the loop ends normally, so `else` runs:

```python
else:
    print("Correct Password")
```

## `break` when the counter reaches zero

```python
if tries == 0:
    print("All Tries Finished")
    break
```

`break` exits the loop immediately. Because the exit was not natural, the `while` `else` does not run.

> [!WARNING]
> In the source order, the program asks for `Enter Password Again` before checking `tries == 0`. When the counter reaches zero, it has already requested an extra input that will not be checked. This is a useful counter-design observation, not mysterious Python behavior.

## The simpler version

```python
password = "1234"

guess = input("Enter Password: ")

while guess != password:
    print("Wrong Password")
    guess = input("Try Again: ")

print("Correct Password")
```

```example-run
Enter Password: 1111
Wrong Password
Try Again: 1234
Correct Password
```

There is no attempt limit here; the loop continues until the condition becomes False.

## Quick mental model

- `while wrong` = repeat the question.
- Update the input inside the loop so the condition can end.
- A counter sets a limit.
- `break` is an early exit, while `while ... else` distinguishes early exit from natural completion.
