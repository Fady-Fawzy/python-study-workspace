# 050 — Password Guess

المثال يكرر طلب كلمة المرور طالما الإدخال خطأ، ويستخدم Counter و`break` للتحكم في المحاولات.

## شرط الاستمرار

```python
password = "python123"
tries = 4

input_password = input("Enter Password: ")

while input_password != password:
```

لو الإدخال يساوي كلمة المرور، جسم `while` لا ينفذ. لو مختلف، تبدأ دورة محاولة خاطئة.

## إنقاص المحاولات وقراءة محاولة جديدة

```python
tries -= 1
print(f"Wrong Password, {tries} Tries Left")

input_password = input("Enter Password Again: ")
```

العداد ينقص عند كل دخول للـ Loop، وبعدها تُقرأ قيمة جديدة ليتم فحصها في الدورة التالية.

## المثال الأساسي كاملًا

```python
password = "python123"

tries = 4

input_password = input("Enter Password: ")

while input_password != password:
    tries -= 1

    print(f"Wrong Password, {tries} Tries Left")

    input_password = input("Enter Password Again: ")

    if tries == 0:
        print("All Tries Finished")
        break

else:
    print("Correct Password")
```

البلوك الكامل هو النسخة القابلة للتشغيل والنسخ. الأجزاء القصيرة حوله بتفصل مسؤولية كل خطوة عشان تتبع الـ Counter والخروج بسهولة.

## نجاح قبل نفاد المحاولات

```example-run
Enter Password: test
Wrong Password, 3 Tries Left
Enter Password Again: python
Wrong Password, 2 Tries Left
Enter Password Again: python123
Correct Password
```

عندما أصبحت القيمة صحيحة، شرط `while` صار False وانتهت طبيعيًا، لذلك نفذت `else`:

```python
else:
    print("Correct Password")
```

## `break` عند نفاد العداد

```python
if tries == 0:
    print("All Tries Finished")
    break
```

`break` تخرج فورًا من Loop، ولأن الخروج لم يكن طبيعيًا لا تنفذ `else` الخاصة بالـ While.

> [!WARNING]
> في ترتيب المصدر، البرنامج يطلب `Enter Password Again` قبل فحص `tries == 0`. لذلك عند وصول العداد لصفر سيكون قد طلب إدخالًا إضافيًا لن يُفحص. دي ملاحظة منطقية مهمة عند تصميم Counters، وليست سلوكًا غامضًا من Python.

## النسخة الأبسط

```python
password = "1234"

guess = input("Enter Password: ")

while guess != password:
    print("Wrong Password")
    guess = input("Try Again: ")

print("Correct Password")
```

```example-run
Enter Password: 1111
Wrong Password
Try Again: 1234
Correct Password
```

مفيش حد للمحاولات هنا؛ Loop تستمر حتى يصبح الشرط False.

## الصورة الذهنية السريعة

- `while wrong` = كرر السؤال.
- حدّث الإدخال داخل Loop حتى يمكن أن ينتهي الشرط.
- Counter يضع حدًا.
- `break` خروج مبكر، و`while ... else` تفرق بين الخروج المبكر والنهاية الطبيعية.
