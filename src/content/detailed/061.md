# 061 — Packing & Unpacking Arguments Trainings

الدرس يجمع Parameter عادية مع `*skills` و`**skills_progress` في Function واحدة.

## استقبال الأنواع الثلاثة

```python
def show_skills(name, *skills, **skills_progress):
    print(f"Hello {name}")

    print("Skills Without Progress:")
    for skill in skills:
        print(f"- {skill}")

    print("Skills With Progress:")
    for skill, progress in skills_progress.items():
        print(f"- {skill} => {progress}")
```

- أول Positional Argument تذهب إلى `name`.
- باقي Positional Arguments تُحزم في Tuple اسمها `skills`.
- Keyword Arguments تُحزم في Dictionary اسمها `skills_progress`.

## تشغيل الدالة بقيم مباشرة

```python
show_skills(
    "Ahmed",
    "HTML",
    "CSS",
    Python="90%",
    JavaScript="80%"
)
```

```output
Hello Ahmed
Skills Without Progress:
- HTML
- CSS
Skills With Progress:
- Python => 90%
- JavaScript => 80%
```

المواضع قبل الـ Keywords اتوزعت بالترتيب، ثم النسب احتفظت بأسمائها داخل Dictionary.

## Unpacking بيانات جاهزة

```python
my_skills = ("HTML", "CSS", "Git")

my_progress = {
    "Python": "90%",
    "JavaScript": "80%"
}


def show_data(name, *skills, **progress):
    print(f"Hello {name}")

    for skill in skills:
        print(skill)

    for skill, value in progress.items():
        print(f"{skill} => {value}")


show_data(
    "Ahmed",
    *my_skills,
    **my_progress
)
```

```output
Hello Ahmed
HTML
CSS
Git
Python => 90%
JavaScript => 80%
```

`*my_skills` فكّت الـ Tuple إلى Positional Arguments، و`**my_progress` فكّت الـ Dictionary إلى Keyword Arguments.

> [!IMPORTANT]
> الترتيب في التوقيع يعكس رحلة البيانات: Parameter العادية، ثم `*args`، ثم `**kwargs`.

## الصورة الذهنية السريعة

Function واحدة تقدر تستقبل جزءًا ثابتًا، جزءًا موضعيًا متغيرًا، وجزءًا مسمى متغيرًا، وكل جزء له container واضحة داخليًا.
