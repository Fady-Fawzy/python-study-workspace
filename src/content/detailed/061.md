# 061 — Packing & Unpacking Arguments Trainings

This lesson combines regular parameters with `*skills` and `**skills_progress` in one function.

## Receive all three kinds

```python
def show_skills(name, *skills, **skills_progress):
    print(f"Hello {name}")

    print("Skills Without Progress:")
    for skill in skills:
        print(f"- {skill}")

    print("Skills With Progress:")
    for skill, progress in skills_progress.items():
        print(f"- {skill} => {progress}")
```

- The first positional argument goes to `name`.
- The remaining positional arguments are packed into a Tuple named `skills`.
- Keyword arguments are packed into a Dictionary named `skills_progress`.

## Call the function with direct values

```python
show_skills(
    "Ahmed",
    "HTML",
    "CSS",
    Python="90%",
    JavaScript="80%"
)
```

```output
Hello Ahmed
Skills Without Progress:
- HTML
- CSS
Skills With Progress:
- Python => 90%
- JavaScript => 80%
```

The positional values are assigned in order, and the progress values keep their names inside the Dictionary.

## Unpack ready-made data

```python
my_skills = ("HTML", "CSS", "Git")

my_progress = {
    "Python": "90%",
    "JavaScript": "80%"
}


def show_data(name, *skills, **progress):
    print(f"Hello {name}")

    for skill in skills:
        print(skill)

    for skill, value in progress.items():
        print(f"{skill} => {value}")


show_data(
    "Ahmed",
    *my_skills,
    **my_progress
)
```

```output
Hello Ahmed
HTML
CSS
Git
Python => 90%
JavaScript => 80%
```

`*my_skills` expands the Tuple into positional arguments, and `**my_progress` expands the Dictionary into keyword arguments.

> [!IMPORTANT]
> The signature order reflects the data path: regular parameters, then `*args`, then `**kwargs`.

## Quick mental model

One function can receive a fixed part, a variable positional part, and a variable named part, with a clear internal container for each.
