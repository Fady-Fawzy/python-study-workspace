# 064 — Lambda Function

Lambda is a small anonymous function written as one expression. It is suitable when the logic is short, clear, and does not need multiple statements.

## A regular function

```python
def say_hello(name):
    return f"Hello {name}"
```

The name, signature, body, and `return` are visible across several lines.

## The same idea with a Lambda

```python
say_hello = lambda name: f"Hello {name}"

print(say_hello("Ahmed"))
```

```output
Hello Ahmed
```

The syntax is:

```python
lambda arguments: expression
```

The expression result is returned automatically; we do not write `return` inside a Lambda.

## A Lambda with more than one argument

```python
addition = lambda num1, num2: num1 + num2

print(addition(10, 20))
```

```output
30
```

The two values bind to the arguments, and the expression returns their sum.

> [!COMPARISON]
> `def` is better for multi-line logic, clear naming, documentation, and reuse.
> `lambda` is suitable for a small expression often passed to another function such as `map()` or `filter()` in later lessons.

> [!WARNING]
> Do not turn complex logic into a Lambda just to reduce lines. Its main constraint is one expression, and clarity matters more than brevity.

## Quick mental model

Lambda = arguments on the left of `:`, with a computed result on the right returned automatically.
