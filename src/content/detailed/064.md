# 064 — Lambda Function

Lambda هي Function صغيرة Anonymous تُكتب كتعبير واحد. مناسبة لو المنطق قصير وواضح ولا يحتاج Statements متعددة.

## Function عادية

```python
def say_hello(name):
    return f"Hello {name}"
```

الاسم والتوقيع والجسم والـ `return` ظاهرين على عدة أسطر.

## نفس الفكرة بـ Lambda

```python
say_hello = lambda name: f"Hello {name}"

print(say_hello("Ahmed"))
```

```output
Hello Ahmed
```

الصيغة:

```python
lambda arguments: expression
```

نتيجة الـ Expression تُعاد تلقائيًا؛ لا نكتب `return` داخل Lambda.

## Lambda بأكثر من Argument

```python
addition = lambda num1, num2: num1 + num2

print(addition(10, 20))
```

```output
30
```

القيمتان ارتبطتا بالـ Arguments، والـ Expression أعادت مجموعهما.

> [!COMPARISON]
> `def` أفضل للمنطق متعدد الأسطر، الاسم الواضح، والتوثيق وإعادة الاستخدام.
> `lambda` مناسبة لتعبير صغير يُمرر غالبًا لدالة أخرى مثل `map()` أو `filter()` في الدروس القادمة.

> [!WARNING]
> لا تحول منطقًا معقدًا إلى Lambda لمجرد تقليل السطور. القيد الأساسي إنها Expression واحدة، والوضوح أهم من الاختصار.

## الصورة الذهنية السريعة

Lambda = Arguments على يسار `:`، ونتيجة محسوبة على اليمين تُعاد تلقائيًا.
