# 066 — Files Handling Part 2 — Read Files

طرق القراءة تختلف في كمية البيانات التي ترجعها ومكان File Cursor بعد العملية. الأمثلة التالية تفترض أن `data.txt` ملف نصي يحتوي:

```text
Hello Python
Second Line
```

## `read()` — اقرأ الباقي كله

```python
file = open("data.txt", "r")

print(file.read())
```

```example-output
Hello Python
Second Line
```

`read()` بلا Argument تبدأ من موضع الـ Cursor الحالي وتعيد باقي الملف كـ String واحدة. الناتج Example Output لأنه يعتمد على المحتوى الفعلي للملف.

## `read(5)` — عدد محدد من Characters

```python
file = open("data.txt", "r")

print(file.read(5))
```

```example-output
Hello
```

الـ Cursor بدأ من أول الملف، فقرأت أول خمسة Characters. بعد القراءة يصبح موضعه بعدها، وأي `read()` تالية تكمل من هناك.

## `readline()` — سطر واحد

```python
file = open("data.txt", "r")

print(file.readline())
```

```example-output
Hello Python

```

`readline()` تعيد سطرًا واحدًا، وغالبًا تحتفظ بحرف newline `\n` في نهايته. لذلك `print()` قد تظهر سطرًا فارغًا إضافيًا لأنها تضيف newline أخرى.

```python
print(file.readline())
print(file.readline())
```

```example-output
Second Line

```

كل Call تكمل من الـ Cursor الحالي؛ الأولى تقرأ السطر التالي والثانية تصل لنهاية الملف وترجع `""`. في مثال الملف هنا نفترض أن السطر الأخير لا ينتهي بـ `\n`؛ الـ `print()` الثانية الفارغة هي التي تترك السطر الفارغ الظاهر.

## `readlines()` — List من السطور

```python
file = open("data.txt", "r")

print(file.readlines())
```

```example-output
['Hello Python\n', 'Second Line']
```

كل سطر يصبح عنصرًا في List، وحرف `\n` يبقى جزءًا من String الأولى لأنه موجود في الملف، بينما السطر الأخير هنا لا ينتهي به.

## Loop مباشرة على File object

```python
file = open("data.txt", "r")

for line in file:
    print(line.strip())
```

```example-output
Hello Python
Second Line
```

الدوران يقرأ سطرًا في كل دورة بدل تحميل الملف كله كـ List. `strip()` أزالت newline والمسافات الخارجية قبل الطباعة.

## `close()` — إغلاق الملف

```python
file.close()
```

بعد الإغلاق لا تحاول القراءة من نفس File object؛ ستحتاج فتح الملف من جديد.

> [!WARNING]
> الـ Cursor مهم: لو استدعيت `read()` مرة حتى النهاية، فـ `read()` التالية ترجع String فارغة إلا لو أعدت فتح الملف أو حرّكت الموضع بـ `seek()`.

## الصورة الذهنية السريعة

- `read()` = باقي الملف.
- `read(n)` = حتى `n` Characters.
- `readline()` = سطر واحد.
- `readlines()` = List من السطور.
- `for line in file` = معالجة سطر بسطر.
