# 066 — Files Handling Part 2 — Read Files

Reading methods differ in how much data they return and where the file cursor is afterward. The following examples assume that `data.txt` is a text file containing:

```text
Hello Python
Second Line
```

## `read()` — read the rest

```python
file = open("data.txt", "r")

print(file.read())
```

```example-output
Hello Python
Second Line
```

`read()` without an argument starts at the current cursor and returns the rest of the file as one String. This is example output because it depends on the file's actual content.

## `read(5)` — a fixed number of characters

```python
file = open("data.txt", "r")

print(file.read(5))
```

```example-output
Hello
```

The cursor starts at the beginning, so the call reads the first five characters. After reading, the cursor is immediately after them, and a later `read()` continues from there.

## `readline()` — one line

```python
file = open("data.txt", "r")

print(file.readline())
```

```example-output
Hello Python

```

`readline()` returns one line and usually keeps its ending newline character, `\n`. As a result, `print()` may show an extra blank line because it adds another newline.

```python
print(file.readline())
print(file.readline())
```

```example-output
Second Line

```

Each call continues from the current cursor. The first reads the next line, and the second reaches the end and returns `""`. In this file example, the final line has no trailing `\n`; the second empty `print()` is what leaves the visible blank line.

## `readlines()` — a List of lines

```python
file = open("data.txt", "r")

print(file.readlines())
```

```example-output
['Hello Python\n', 'Second Line']
```

Each line becomes an item in the List. The `\n` character remains part of the first String because it is in the file, while the last line here does not end with it.

## Loop directly over the file object

```python
file = open("data.txt", "r")

for line in file:
    print(line.strip())
```

```example-output
Hello Python
Second Line
```

The loop reads one line per cycle instead of loading the whole file as a List. `strip()` removes the newline and outer spaces before printing.

## `close()` — close the file

```python
file.close()
```

After closing, do not try to read from the same file object; you need to open the file again.

> [!WARNING]
> The cursor matters: if one `read()` reaches the end, a later `read()` returns an empty String unless you reopen the file or move the cursor with `seek()`.

## Quick mental model

- `read()` = the rest of the file.
- `read(n)` = up to `n` characters.
- `readline()` = one line.
- `readlines()` = a List of lines.
- `for line in file` = line-by-line processing.
