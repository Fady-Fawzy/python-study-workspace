# 046 — Practical Membership Control

This example combines user input, text cleanup, membership, and control flow to build a small admin system.

## Check the admin name

```python
admins = ["Ahmed", "Mohamed", "Ali"]

name = input("Enter Your Name: ").strip().capitalize()

if name in admins:
    print(f"Welcome Admin {name}")

else:
    print(f"Sorry {name}, You Are Not Admin")
```

```example-run
Enter Your Name: ahmed
Welcome Admin Ahmed
```

`strip().capitalize()` converts the input to the form stored in the List, then `name in admins` returns True.

## Choose update or delete

In the larger application, if the name is an admin we read a second operation:

```python
option = input("Delete Or Update Your Name? ").strip().lower()
```

`lower()` turns `UPDATE` and `Update` into `update`, making the choice easier to test.

## The complete larger application

```python
admins = ["Ahmed", "Mohamed", "Ali"]

name = input("Enter Your Name: ").strip().capitalize()

if name in admins:
    print(f"Welcome Back {name}")

    option = input("Delete Or Update Your Name? ").strip().lower()

    if option == "update":
        new_name = input("Enter New Name: ").strip().capitalize()

        admins[admins.index(name)] = new_name

        print("Name Updated")
        print(admins)

    elif option == "delete":
        admins.remove(name)

        print("Name Deleted")
        print(admins)

else:
    print("You Are Not Admin")
```

The outer `if` controls access, and the inner `if/elif` chooses the type of change. A non-admin therefore never reaches the update/delete question.

## Update the name in place

```python
if option == "update":
    new_name = input("Enter New Name: ").strip().capitalize()

    admins[admins.index(name)] = new_name

    print("Name Updated")
    print(admins)
```

```example-run
Enter Your Name: ahmed
Welcome Back Ahmed
Delete Or Update Your Name? update
Enter New Name: omar
Name Updated
['Omar', 'Mohamed', 'Ali']
```

`admins.index(name)` finds the index of `Ahmed`, which is 0, and assignment replaces the item at that same position with `Omar`.

## Delete the name by value

```python
elif option == "delete":
    admins.remove(name)

    print("Name Deleted")
    print(admins)
```

```example-run
Enter Your Name: ali
Welcome Back Ali
Delete Or Update Your Name? delete
Name Deleted
['Ahmed', 'Mohamed']
```

`remove(name)` deletes the value `Ali` from the List. The previous membership check confirmed that the name exists, so the normal path does not encounter `ValueError`.

## The complete decision path

1. Clean the name.
2. Test membership.
3. If it is an admin, ask for the operation.
4. `update` changes an item by index, while `delete` removes by value.
5. If the name is missing, show `You Are Not Admin` and do not ask for another choice.

> [!WARNING]
> The code has no branch for a choice other than `update` or `delete`, so another input prints no result after the welcome. Adding feedback for that case would be a later logic improvement.

## Quick mental model

Membership is the access gate: allow update operations only after confirming that the value exists in the List.
