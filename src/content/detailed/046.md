# 046 — Practical Membership Control

المثال يربط User Input بتنظيف النص وMembership وControl Flow لبناء نظام Admins صغير.

## التحقق من اسم Admin

```python
admins = ["Ahmed", "Mohamed", "Ali"]

name = input("Enter Your Name: ").strip().capitalize()

if name in admins:
    print(f"Welcome Admin {name}")

else:
    print(f"Sorry {name}, You Are Not Admin")
```

```example-run
Enter Your Name: ahmed
Welcome Admin Ahmed
```

`strip().capitalize()` حولت الإدخال إلى الشكل المخزن في القائمة، ثم `name in admins` أعادت True.

## اختيار Update أو Delete

في التطبيق الأوسع، لو الاسم Admin نقرأ عملية ثانية:

```python
option = input("Delete Or Update Your Name? ").strip().lower()
```

`lower()` تجعل `UPDATE` و`Update` تتحولان إلى `update`، فيسهل فحص الاختيار.

## التطبيق الأوسع كاملًا

```python
admins = ["Ahmed", "Mohamed", "Ali"]

name = input("Enter Your Name: ").strip().capitalize()

if name in admins:
    print(f"Welcome Back {name}")

    option = input("Delete Or Update Your Name? ").strip().lower()

    if option == "update":
        new_name = input("Enter New Name: ").strip().capitalize()

        admins[admins.index(name)] = new_name

        print("Name Updated")
        print(admins)

    elif option == "delete":
        admins.remove(name)

        print("Name Deleted")
        print(admins)

else:
    print("You Are Not Admin")
```

الـ `if` الخارجية تتحكم في السماح بالدخول، والـ `if/elif` الداخلية تختار نوع التعديل. لذلك غير الـ Admin لا يصل أصلًا لسؤال Update/Delete.

## تحديث الاسم في مكانه

```python
if option == "update":
    new_name = input("Enter New Name: ").strip().capitalize()

    admins[admins.index(name)] = new_name

    print("Name Updated")
    print(admins)
```

```example-run
Enter Your Name: ahmed
Welcome Back Ahmed
Delete Or Update Your Name? update
Enter New Name: omar
Name Updated
['Omar', 'Mohamed', 'Ali']
```

`admins.index(name)` وجدت Index الخاصة بـ `Ahmed` وهي 0، ثم Assignment استبدلت العنصر في نفس المكان بـ `Omar`.

## حذف الاسم بالقيمة

```python
elif option == "delete":
    admins.remove(name)

    print("Name Deleted")
    print(admins)
```

```example-run
Enter Your Name: ali
Welcome Back Ali
Delete Or Update Your Name? delete
Name Deleted
['Ahmed', 'Mohamed']
```

`remove(name)` حذفت القيمة `Ali` من الـ List. الاختبار السابق ضمن أن الاسم موجود، لذلك الحذف لا يواجه `ValueError` في المسار الطبيعي.

## المسار الكامل للقرار

1. نظّف الاسم.
2. اختبر Membership.
3. لو Admin، اسأل عن العملية.
4. `update` تعدّل عنصرًا بالـ Index، و`delete` تحذف بالقيمة.
5. لو الاسم غير موجود، يظهر `You Are Not Admin` ولا يُطلب اختيار آخر.

> [!WARNING]
> الكود لا يحتوي فرعًا لاختيار غير `update` أو `delete`، لذلك إدخال آخر لا يطبع نتيجة بعد الترحيب. إضافة Feedback لهذا الاختيار تحسين منطقي لاحق.

## الصورة الذهنية السريعة

Membership هي بوابة الوصول: لا تسمح بعمليات التعديل إلا بعد التأكد إن القيمة موجودة في القائمة.
